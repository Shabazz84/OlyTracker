# Front Foot Landing First in the Split Jerk

## Analysis for This Athlete

**RELEVANCE: Moderate — athlete uses push jerk only (no split jerk yet)**

---

### 1. **Technique Cues (Split Jerk)**
- Front foot hitting first = forward balance shift (dip/drive/arm push)
- Weak/short drive → body compensates by pushing hips back, leaning chest forward
- Excessive chest lean → hips retreat, front leg can't reach forward
- **Fix:** Reach front foot forward (don't lean chest); maintain trunk angle overhead

### 2. **Exercise Recommendations**
- **Jerk balance drills** (learn split mechanics)
- **Behind-neck jerk** or complex with jerk (trunk angle overhead)
- **Push press + power jerk + split jerk complex** (drive power + balance + bar path)

### 3. **Athlete-Specific Notes**
- ⚠️ **Chronic back pain flag:** Before adding split jerk mechanics work, ensure lumbar stability in drive phase is solid. Heavy dip/drive demands may aggravate.
- **Current gap:** Push jerk only (65 kg) vs. OHS limiter (50 kg). Split jerk footwork should eventually help arm position but won't fix OHS deficit immediately.
- **Timeline:** Consider split jerk work later in hypertrophy block or during strength phase once core stability improves.

### 4. **Recovery/Mobility**
None mentioned in text.

---

**Bottom line:** Useful progression path, but sequence split jerk introduction cautiously given back pain history.
