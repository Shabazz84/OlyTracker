# Analysis: Programming Principles & Athlete Assessment

## Programming Principles
- **Cycle Duration**: 4-6 weeks (beginners) to 12-16+ weeks (advanced). *Relevance: Athlete's planned 6-week hypertrophy block fits beginner/intermediate framework.*
- **Periodization**: Macro cycles → mesocycles → weekly adjustments. Write one week at a time, not full cycles upfront.
- **Flexibility**: Build in rep/weight ranges and adjust week-to-week based on performance. Avoid rigid prescriptions for remote athletes.
- **Volume/Frequency**: Heavier athletes handle less volume/frequency than lighter counterparts. *Relevance: At 102.5 kg, consider conservative volume.*
- **Testing & De-load**: Include testing weeks and transition weeks between cycles (lighter version of upcoming cycle structure, not previous one).

## Key Assessment Framework (Directly Applicable)
**Critical for this athlete:**
- **Experience Level**: Intermediate → typically needs *least* individualization, but specifics matter.
- **Strength Imbalances**: If competition lift is <60% of supporting lift (e.g., snatch 50 kg vs. OHS 50 kg), focus on **technique/application**, not raw strength building. *Red flag: OHS is primary snatch limiter—don't over-squat.*
- **Mobility Limitations**: Identify which exercises are inaccessible/unsafe; select variations that serve active mobility work.
- **Lifestyle Integration**: Sleep quality, work schedule (night shift Wed–Sun), recovery capacity directly impact program design.
- **Mental/Emotional**: Assess coaching adherence, stress management, aggression in lift.

## Technique Cues
**None provided in text.** (General framework: identify specific technical issues—turnover mechanics, posture, timing, overhead stability, consistency—then program accordingly.)

## Exercise Recommendations
- **Avoid over-reliance on supporting lifts** if weak link is technical/positional.
- Select exercise variations based on mobility constraints (e.g., limit behind-neck work if shoulder/thoracic mobility poor).
- Bring up weak individual lifts (snatch, clean, jerk) with proportional emphasis.

## Recovery/Mobility Advice
- **Post-competition "Ladies Choice Week"**: 2–3 gym days/week, easy, different, fun work only.
- Transition weeks use next cycle's structure at reduced intensity (active recovery).
- Night shift sleep disruption = consider reduced volume/frequency relative to day-shift intermediate lifters.
