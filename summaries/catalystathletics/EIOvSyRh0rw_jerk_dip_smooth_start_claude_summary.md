# Jerk Dip - Smooth Start

# Analysis

**Relevant to this athlete: HIGH** (jerk technique directly applicable)

## Technique Cues for Jerk

1. **Rack position integrity**: Bar must stay connected to body throughout dip
   - Grip should be firm but not excessively tight
   - Arms shouldn't push up into bar (causes separation)
   - Let bar settle fully against shoulders/body

2. **Starting dip mechanics**:
   - Initiate smoothly (avoid abrupt start that causes bar separation)
   - Maintain tension in quads and glutes with legs straight (not hyperextended)
   - Avoid slack in the system—no passive hyperextension
   - This prevents "free fall" moment before muscles engage

3. **Why it matters for this athlete**:
   - Push jerk only → bar control in dip is critical for consistency
   - Chronic back pain → smooth, controlled movement patterns reduce stress
   - Weak overhead position (65 kg jerk vs 118 kg squat) → efficient bar connection during dip preserves momentum

## Key Actionable Points

- Check rack position before every rep
- Practice dip initiation drills emphasizing smooth tempo with tension
- Once dip starts, speed is acceptable—foundation must be stable first
