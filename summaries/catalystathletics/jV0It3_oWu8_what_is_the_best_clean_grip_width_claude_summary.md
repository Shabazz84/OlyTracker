# What is the Best Clean Grip Width?

**RELEVANT EXTRACTION FOR THIS ATHLETE:**

**2. Technique Cues — Clean Grip:**
- Starting grip: half fist to one fist width outside shoulders
- **Must test grip width with heavy weights** (not just light weights) to identify issues
- Wider grip benefits: higher contact point, quicker turnover, bar stays closer, easier squat posture
- Wider grip drawbacks: harder first pull, less secure rack position
- Narrower grip benefits: easier first pull, more secure rack position
- Narrower grip drawbacks: longer distance to pull, lower contact point, slower turnover, harder to keep bar close
- **Key point for this athlete:** Don't assume you need full grip in rack position; proportions limit mobility more than mobility alone
- Experiment to find individual optimal width rather than copying others

**RELEVANCE TO ATHLETE PROFILE:**
- Given 50 kg OHS as snatch limiter, overhead mobility is already restricted; grip width experimentation should prioritize what allows secure rack position + solid squat posture without forcing excessive mobility demand
- Back pain history: wider grip supporting "strong posture and bracing" may be beneficial for spinal stability in rack position
- Recommend testing grip variations with loads >80 kg (near current clean max) to reveal true rack security/comfort
