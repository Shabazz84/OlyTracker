# Snatch-Grip Overhead Carry + Squat | Olympic Weightlifting Exercise Library

**1. Programming Principles**
- Exercise structure: loaded walks → stabilization holds → prescribed reps/sets
- Intensity: moderate (overhead position load)
- Focus: continuous tension, active stability work

**2. Technique Cues**
- **Snatch OHS setup**: Lock bar forcefully in overhead position
- Maintain upper back, shoulders, arms, and bar motionless throughout
- Active, continuous effort to stay tight during steps and squats
- Emphasis on stability over movement quality

**3. Exercise Recommendations**
- Snatch overhead walks with OHS (loaded stability drill)
- Directly addresses OHS weakness (athlete's snatch limiter at 50 kg)

**4. Recovery/Mobility**
- None mentioned

**5. Athlete-Specific Relevance**
- **Highly relevant**: OHS is this athlete's primary snatch limiter; loaded stability work may improve overhead strength and positioning
- **Caution**: Night shift worker needs scheduled recovery; chronic back pain requires monitoring overhead load tolerance
- **Consider**: Light-to-moderate loading given back history; pair with anti-extension/anti-rotation core work
