# Single-Arm Overhead Cable Tricep Extension | Olympic Weightlifting Exercise Library

**Exercise Analysis: Single-Arm Overhead Cable Extension**

**Exercise Recommendation:**
- Single-arm overhead tricep extension (cable)
- Cue: High elbow position, minimize forward elbow drift, full ROM bend-to-extend

**Relevance to Athlete:**
- **Moderate relevance** — Tricep accessory could support jerk lockout strength (currently weak at 65 kg push jerk)
- **Back pain consideration:** Overhead unilateral work may aggravate chronic back pain if core stability is compromised; bilateral variations preferred
- **Hypertrophy block fit:** Suitable volume exercise for 6-week block if programmed cautiously

**Caution:**
Single-arm overhead work lacks stability for this athlete. Recommend **bilateral overhead pressing** (strict press, push press) to build jerk strength safely and avoid asymmetrical load on compromised back.
