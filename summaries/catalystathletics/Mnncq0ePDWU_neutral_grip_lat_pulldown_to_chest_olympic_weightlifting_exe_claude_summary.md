# Neutral-Grip Lat Pulldown to Chest | Olympic Weightlifting Exercise Library

**Exercise Recommendation:**
- **Overhead cable row** (horizontal rowing variation)
- Narrow grip, neutral spine, pull to chest while leaning back slightly
- Finish with shoulder blades retracted
- Controlled return to extended position

**Relevance to Athlete:**
- **Moderate relevance**: Upper back/shoulder blade pulling pattern supports clean/jerk mechanics and postural stability
- **Low priority for this athlete**: Given chronic back pain and weak OHS (50 kg), focus should prioritize front rack mobility, core stability work, and snatch-specific pulling before accessory rowing
- Better candidates: prone rows, seal rows, or strict chest-supported variations to avoid spinal load

**Not covered:** Programming, technique cues, recovery protocol.
