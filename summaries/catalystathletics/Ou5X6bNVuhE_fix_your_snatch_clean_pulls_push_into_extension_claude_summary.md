# Fix Your Snatch & Clean Pulls - PUSH into Extension

# Analysis: Pull Mechanics Coaching

## 1. Programming Principles
- **Warm-up structure**: Pulls always precede snatch/clean training
- **Sets/reps**: 3–5 total reps per set, "just a few sets"
- **Progression**: Power position → progressive hang positions → floor pulls (technical mastery before load)

## 2. Technique Cues: Snatch & Clean Pulls
**Setup (Power Position):**
- Knees bent, vertical trunk, bar against body, relaxed arms, balanced foot

**Extension:**
- Push *straight down* into floor (whole foot)
- Extend legs *vertically* (no back lean, no hip thrust through bar, no head throw)
- Bar slides *light and close* against body throughout

**Key Differentiator:**
- Snatch pull finishes at hips; clean pull at upper thigh
- Bar path differs from full lift finish—don't mimic snatch/clean extension exactly

**Cueing:** Trust body mechanics—if vertical leg drive, foot balance, and bar proximity are correct, forward knee motion happens naturally

## 3. Exercise Recommendations
- Snatch pulls (power position + progressive hangs)
- Clean pulls (power position + progressive hangs)
- Progression: Never load until motion is clean from that position

## 4. Relevant to Athlete Profile
**Directly applicable:**
- OHS 50 kg (snatch limiter) — strong pull mechanics likely prerequisite
- Chronic back pain — *vertical* leg drive (not forward knee/hip thrust) reduces shear stress vs. common compensations
- 6-week hypertrophy block — warm-up pull work fits; builds foundational patterns before intensity

**Not addressed:** Night shift recovery, push jerk limitations.
