# RDL Pulls

**1. Programming Principles**
- Exercise addition to accessory toolbox (RDL variant)
- Intensity: Load-dependent on grip choice
- Frequency: Not specified

**2. Technique Cues**
- **RDL with Pole Finish:**
  - Slight knee bend + hip hinge descent
  - Maintain rigid back throughout (critical for this athlete's chronic pain)
  - Change direction without lumbar rounding
  - Accelerate into pull once bar clears knees
  - Grip options: Clean grip (heavier loading) or Snatch grip (extended finish emphasis)

**3. Exercise Recommendations**
- RDL Pole Finish variant
  - Clean grip version: addresses strength
  - Snatch grip version: addresses extension/finishing position (relevant to OHS/snatch limitations)

**4. Recovery/Mobility Advice**
- None provided

**5. Athlete-Specific Relevance**
- **HIGH PRIORITY**: Emphasizes rigid back maintenance—directly addresses chronic back pain concern
- **Snatch grip RDL pole finish** particularly relevant: athlete's OHS (50 kg) is primary snatch limiter; this targets pulling extension and positional strength
- Suitable for night-shift recovery (accessory, not high CNS demand)
- Good fit for hypertrophy block if programmed 2–3x/week
