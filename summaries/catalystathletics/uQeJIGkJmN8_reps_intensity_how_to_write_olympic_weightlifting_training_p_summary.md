# Reps & Intensity - How to Write Olympic Weightlifting Training Programs | Part 4

**1. Programming Principles**
*   **Intensity/Rep Interdependence:** Higher intensity requires fewer reps; higher reps require lower intensity. The combination determines adaptation type (strength, hypertrophy, technique).
*   **Maximally Effective Dose:** Avoid "minimal effective dose" for performance athletes; aim for the greatest possible adaptation within recovery limits. Failure is a programming error, not a result of high effort goals.
*   **Specific Ranges:**
    *   **Strength:** 1–5 reps @ 80–100% (bias 1–3).
    *   **Speed/Power:** 1–3 reps @ 60–75%.
    *   **Technique:** 1–3 reps @ 50–70% (prioritize precision over fatigue).
    *   **Hypertrophy:** 5+ reps @ 60–80% (proximity to failure).
    *   **Recovery:** 2–3 reps @ <60%.
*   **Complexity Factor:** Technical lifts (Snatch/Clean/Jerk) require fewer reps at a given % than basic lifts (Squat) due to speed/technique demands.
