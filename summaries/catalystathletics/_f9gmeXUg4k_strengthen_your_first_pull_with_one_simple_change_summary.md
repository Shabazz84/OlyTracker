# Strengthen Your First Pull with One Simple Change

1. **Programming Principles:** Implement **static starts** (tight pre-set position) for all deadlifts and pulls; avoid dynamic starts to eliminate inconsistency and force the use of basic strength rather than rebounding off the floor. Use this to build a foundation before reintroducing dynamic elements in competition lifts.
2. **Technique Cues:** Focus on "setting that position tightly" before initiating any pull. The goal is to solidify the initial pull phase so the body naturally reverts to this consistent starting point during snatch/clean attempts, even when using a dynamic start later.
3. **Exercise Recommendations:** Deadlifts and pulls (specifically those utilizing a static start).
4. **Recovery/Mobility Advice:** None mentioned in the text.
5. **Profile Relevance:** This addresses the athlete's "intermediate" status by correcting foundational pull mechanics, which is critical given their chronic back pain (inconsistent positions often exacerbate spinal stress) and low Clean/Jerk numbers relative to squat strength.
