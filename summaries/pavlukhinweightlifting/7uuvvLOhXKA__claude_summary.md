# Тяжелая атлетика без химии

## Key Points
- Technical skill retention outlasts strength loss; neural adaptations persist longer than muscular ones—important for retraining after deconditioning
- Recovery timeline scales with detraining duration (1 year lost ≈ 1 year regain)
- Mobility neglect creates cascade dysfunction: sartorius tightness → piriformis → lower back compensation (relevant given chronic back pain)
- Body recomposition feasible at this athlete's level: strength maintenance/progression possible while managing weight via sound nutrition approach
- Core strength requires consistent stimulus (daily static tension work under load emphasized)
- Rest periods: 5–6 min between heavy squats; can be strategically reduced depending on fatigue tolerance and block goals

## Technique Cues
- Snatch: elbow turnover timing and foot placement critical to bar path consistency
- Jerk: current emphasis on technical proficiency over loading (athlete at 55–65 kg; OHS 50 kg is primary limiter)
- Core engagement: static tension maintenance under loaded positions

## Programming Principles
- Prioritize technique work before heavy loading, especially during transitions (e.g., split jerk development)
- Mobility work non-negotiable; address hip/posterior chain restrictions preventatively to protect lower back
- Macro tracking (~3,500 kcal, protein-focused) supports hypertrophy block and recovery
- Rest period manipulation available as fatigue management tool

## Athlete Relevance
**Directly applicable:**
- 6-week hypertrophy block should include daily core/anti-rotation work and mobility sequencing (sartorius → hip external rotators → lower back protection)
- OHS 50 kg limiter: mobility + overhead stability work essential before split jerk progression
- Night shift schedule demands consistent recovery protocol (sleep quality prioritized; magnesium supplementation noted)
- Chronic back pain: avoid heavy loading without mobility baseline; consider technique-first approach in early block

**Not addressed:** Specific split jerk progressions, back-pain-adapted squat variations, or night-shift periodization recommendations.
