**Key Content Extracted:**

2. **Technique/Muscle Function:**
   - Back extensor role: stabilization (static/isometric work) to maintain upright posture and spinal rigidity
   - Shoulder stabilization involvement
   - Dynamic back extension movement demonstrated separately from static postural holding

3. **Relevance to Athlete:**
   - **CRITICAL:** Direct application to chronic back pain management. Static spinal stability (emphasized here) is foundational—athlete should prioritize anti-extension stability work before heavy dynamic movements
   - Back extension placement late in session aligns with fatigue management for recovering athlete
   - Reinforces need for proper thoracic/lumbar bracing in squat/clean positions (currently limiting OHS at 50 kg)

**Recommendation:** Athlete should implement controlled back stability work (planks, dead bugs, bird dogs) early in session, then dynamic extensions late—NOT the reverse, given back pain history. This supports both hypertrophy block and injury prevention.
