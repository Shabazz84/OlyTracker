# Weightlifting Summary for Intermediate Athlete (102.5 kg, 6-Week Hypertrophy Block)

## Key Points

1. **Bar Selection Matters**: Olympic bar (whip/flex) vs. deadlift bar affects snatch/clean mechanics—select accordingly for the lift.

2. **Load Management Post-PR**: Reduce load 5–10% the week following a PR to allow recovery (e.g., if PR = 100 kg, next week = 90 kg).

3. **Fractional Plate Increments**: Use 0.5 kg plates instead of 1.25+ kg jumps to reduce fatigue accumulation and spasm risk, especially during hypertrophy blocks.

4. **Chronic Back Pain Protocol**: Avoid passive rest (bed rest increases inflammation rebound). Maintain low-intensity, continuous movement—light spinal extension work, walking, mobility drills—to prevent pain cycle recurrence.

5. **Active Recovery Over Immobility**: Controlled, gentle tension preserves function better than static rest; modern protocols favor movement even for herniated discs.

## Technique Cues

- **Front Squat Warm-Up** before snatch/clean work (establishes stability foundation).
- **Psychological Feedback**: "If you doubt, don't lift"—doubt signals organism resistance; trust intuitive readiness signals.
- **Spinal Mobility**: Include spinal extension mobility work to address OHS limiter (current 50 kg; back mobility constrains overhead position).

## Programming Principles

- Respect prescribed volume caps; exceeding plan increases injury risk.
- Avoid stacking both classics (snatch + clean) back-to-back if unplanned schedule conflicts arise.
- Plan rest structurally, not reactively.
- For hypertrophy block: maintain daily low-intensity active recovery despite night shift fatigue.

## Athlete Relevance

**Critical for your profile:**
- **Chronic back pain + night shift work**: Prioritize active recovery protocol (light movement, walking, extension mobility) over rest days.
- **6-week hypertrophy block**: Use fractional plates (0.5 kg) for smaller jumps; apply 5–10% deload week after any PR to manage accumulated fatigue.
- **OHS limiter (50 kg)**: Integrate spinal extension mobility into warm-ups—back stiffness is primary constraint, not leg strength.
- **Psychological resilience**: Fear about pain is normal; managed progressions build confidence and reduce catastrophizing.
