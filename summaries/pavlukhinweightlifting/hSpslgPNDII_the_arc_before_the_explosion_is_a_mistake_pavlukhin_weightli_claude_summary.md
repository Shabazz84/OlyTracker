# The arc before the explosion is a mistake #pavlukhin #weightlifting

**Weightlifting Content: YES**

**1. Technique Cues (Snatch/Clean Start Position)**
- **Low start position problem:** Forces knee circumduction (bar path curves around knees)
- **Solution:** Raise hips earlier in the pull to avoid unnecessary knee bending/bar deviation
- **Common error:** Athletes sit too long, then lift hips as a separate compensatory movement—eliminate this wasted motion
- **Better approach:** Achieve proper hip height from the start position to create direct vertical bar path

**2. Programming Notes**
- Group error correction mentioned as coaching method

**3. Relevance to This Athlete**
- **HIGH RELEVANCE:** OHS (50 kg) is stated as primary snatch limiter. Poor start position mechanics directly impact snatch pull mechanics and front-rack/overhead stability
- Back pain + chronic issues: Clean start position mechanics deserve scrutiny; low starts with poor hip position can aggravate spinal stress
- Night shift fatigue (Wed–Sun) makes efficient technique critical—avoid wasted movements

**Recommendation:** Prioritize start position drills and bar path correction before hypertrophy block to establish clean pulling mechanics; address any pain patterns during pull-under transitions.
