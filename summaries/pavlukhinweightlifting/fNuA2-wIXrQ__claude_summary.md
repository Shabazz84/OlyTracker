**Mobility/Equipment Advice:**
- Heel height in weightlifting shoes compensates for ankle flexibility limitations
- Higher heels help athletes lacking ankle dorsiflexion
- If ankle mobility is sufficient, heel height is irrelevant
- Speaker trains in both low and standard heel heights without preference

**Relevance to this athlete:**
- **Relevant to OHS limiter (50 kg):** Ankle mobility directly impacts overhead squat depth and stability. Given chronic back pain and OHS being primary snatch limiter, assess ankle dorsiflexion ROM. Consider higher-heeled shoes (standard ~0.75") if ankle mobility is restricted, as this may improve OHS position and reduce compensatory lumbar stress.
- **Practical:** Test current setup; upgrade to standard heel height if ankle stiffness is present.
