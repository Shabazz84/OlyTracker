# Отклоняться ли от плана тренировок? #тяжелаяатлетика

**Language:** Russian (coaching dialogue)

**Relevant Extracts:**

1. **Programming Principle:**
   - Default intensity: 80% (planned session)
   - Flexibility: Can increase if lift moves well, BUT understand that pushing now creates future fatigue/deload (undulating concept)
   - Recommendation: Stick to 80% weeks; if athlete performs exceptionally, add load but reduce volume next session

2. **Key Coaching Principle:**
   - "If it moves, you can lift it" — but consider individual tolerance (tendons/ligaments can't always handle extra load)
   - Physics applies: load addition now → subsequent performance dip later
   - Individualize based on athlete readiness

3. **Relevant to This Athlete:**
   - **Chronic back pain** → conservative 80% approach preferred over frequent intensity spikes
   - **Night shift worker** → fatigue variability likely; flexible intensity auto-regulation beneficial
   - Avoid aggressive overloading early; prioritize sustainable accumulation

**Application:** Use 80% as baseline for 6-week hypertrophy block. Permit intensity increases only if movement quality remains high AND follow with reduced volume to manage fatigue accumulation and back stress.
