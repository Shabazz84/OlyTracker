# Technique: PUSH JERK / A.TOROKHTIY (Weightlifting)

# Weightlifting Coaching Analysis: Push Jerk (Толчок с груди)

## 1. **Programming Principles**
- Movement breakdown into 4 phases for learning progression
- Mirror work recommended for technique drilling to automaticity
- Breathing: Full inhale before dip and drive (NOT exhale)
- Holds: 2-second lockout fixation emphasized

## 2. **Technique Cues: Push Jerk**

**Rack Position:**
- Bar on shoulders (NOT neck/chest)
- Elbows turned out (not parallel) → open chest
- Lumbar tension (slight posterior pelvic tilt)

**Dip & Drive (simultaneous):**
- Rise on toes → dip → explosive drive
- Legs AND arms move **simultaneously** (common error: sequential)
- Foot spacing: ~10-15cm wider than shoulder width for receiving position

**Receiving Position:**
- ~10-15cm stance width adjustment from dip
- Knees track out with toes
- Depth: ~105° knee angle (partial squat, NOT full depth)
- "Cup of water" cue: vertical torso, level hip positioning

**Lockout:**
- Shoulders elevated + scapulae retracted
- Arms fully extended

## 3. **Exercise Recommendations**
- Use broomstick/light bar for drill progression
- Practice in front of mirror
- Split jerk vs. push jerk: Coach recommends push jerk (simpler learning curve; personal example: progressed 190kg → 240kg classic jerk after switching)

## 4. **Recovery/Mobility**
- None mentioned
