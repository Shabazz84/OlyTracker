# The Clean: Explosion / Как улучшить подрыв штанги [ENG SUB] A.TOROKHTIY

**LANGUAGE NOTE:** Text is in Russian. Analyzing weightlifting coaching content on the pull (подрыв).

## EXTRACTED ANALYSIS

### 1. **Programming Principles**
- Pull work early in session (3-4 sets to start)
- Can progress to +40kg once technique solidifies
- Alternating approach: some sessions with straps, some without (allows grip recovery without strength loss)
- Pull work can precede main lifts (clean/jerk) or used as accessory work

### 2. **Technique Cues for Pull (Подрыв)**
- **Arm relaxation:** Relax arms maximally, let bar drift away slightly
- **Elbow drive:** Drive elbows high and forward as bar returns
- **Contact point:** First third of thigh (not full hip extension)
- **Stance:** Knees out, bar over shoulders, neutral spine, heels down (~90° ankle angle)
- **Grip:** Open hook or straps preferred to reduce hand tension
- **Feedback:** Bar should "ring/play" (audible feedback of proper acceleration)
- **Progression cue:** Early soreness/bruising indicates you're actually pulling hard (many athletes undertrain this)

### 3. **Exercise Recommendations**
- Loaded pulls with wide plate placement (eccentric loading, amplifies feedback)
- Strap use encouraged to decompress grip between sessions

### 4. **Recovery/Mobility Advice**
- Hand/grip: Alternate straps/no-straps to allow grip recovery
- Early training soreness normal; expect bruising in first month

### 5. **Athlete-Specific Relevance**
- **RELEVANT TO THIS ATHLETE:** Pull strength directly supports Clean (80kg) and Jerk (65kg). Weak pull often limits catch position stability. Early session pull work fits night-shift recovery needs.
- **RELEVANT TO THIS ATHLETE:** OHS limiter (50kg) partly driven by weak pull confidence. Stronger pull → better bar control overhead.
- **NOT DIRECTLY ADDRESSED:** Chronic back pain management (open-hand position may reduce spinal load vs. traditional hook grip).
