  - Snatch day: snatch + power clean + snatch pulls + front squats (8 total reps per set)
  - Jerk day: clean + jerk + snatch pulls + front squats
- **Rep ranges**: 3–10 reps per set, 2–4 sets per exercise
- **Frequency**: Daily training with rotating movement patterns

## 3. Exercise Recommendations
- **Mobility/stability**: Band work (shoulder health emphasis—anecdotally resolved shoulder pain)

- **Warm-up cardio**: ~2km running if available; exercise complexes otherwise

- **Massage**: 7–12 sessions planned over offseason
- **Stretching**: Pre/post-training, emphasizing problem areas (hips, back, shoulders)
- **Approach**: Treat offseason as "double recovery work, half loading"

- **Chronic back pain**: Hyperextensions + forward bends rotation aligns with back health focus
- **Recovery-focused approach**: Fits hypertrophy block phase (low intensity, high volume)
