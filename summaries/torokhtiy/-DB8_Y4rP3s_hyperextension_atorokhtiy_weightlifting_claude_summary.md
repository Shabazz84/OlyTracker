# HYPEREXTENSION / A.TOROKHTIY (Weightlifting)

**Language:** Russian (coaching demonstration)

**Relevant to this athlete:**

**1. Exercise Recommendations**
- Hyperextensions/good mornings over a box: core and posterior chain strengthening
- Load: 20 kg maximum (coach emphasizes moderate weight over heavy load)
- Lateral flexion work (side bends) to target obliques
- Applicable here: Excellent for chronic back pain management and core stability

**2. Programming Principles**
- Tempo: Fast concentric (up), pause at top, slow eccentric (down)
- Reps: ~10+ per set (coach notes >10 reps feels effective)
- No need for heavy loading; controlled movement with pauses prioritized over weight
- Breathing: Exhale on descent, inhale at bottom

**3. Technical Cues**
- Pause/hold at top position
- Smooth, controlled lowering (eccentric emphasis)
- Quality over quantity

**4. Recovery/Mobility Advice**
- Core strengthening reduces back discomfort
- Coach states athletes should "feel pleasant sensations in the back" afterward, not pain

**Application for this athlete:**
Given chronic back pain + weak OHS (50 kg limit), this core work is **highly relevant**. Moderate loading with controlled tempos suits night shift recovery constraints. Include 2–3x weekly in hypertrophy block.
