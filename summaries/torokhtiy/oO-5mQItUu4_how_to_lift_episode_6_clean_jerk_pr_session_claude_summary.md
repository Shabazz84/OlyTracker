# Analysis: Russian Jerk Training Session

## 1. Programming Principles
- **Structure**: Classic jerk session (power clean + front squat + jerk)
- **Intensity progression**: 15-20 kg warm-up → 50% threshold → work to 90% single → finisher (jerk pulls at 100% × 2 reps × 2 sets)
- **Frequency note**: Single jerk session format (athlete on split jerk, this uses full-foot drive)

## 2. Technique Cues (Jerk-specific)
- **Dip/Squat**: "Hip back, knees out" | "Even descent, explosive extension"
- **Drive**: "Full foot power" (толкаешь с полной стопы) | "Core tight"
- **Split mechanics**: "Catch quickly into split" (быстрее в ножницы) | "Shorter split depth" | "Stable catch hold"
- **Common faults corrected**:
  - Collapsing forward (using only lower back, not legs)
  - Exiting split too fast → missed lifts
  - Split too deep (should be shallower)
  - Push press-like position (avoid)

## 3. Relevant to This Athlete
- **Push jerk only**: This session assumes split jerk. Coach should adapt warm-up (skip scissors split drills #4) and modify depth/split demands—**critical for athlete's current capacity**
- **Back pain concern**: Cues emphasize "core tight" and avoiding forward collapse (lower back domination)—good for spinal stability
- **OHS weakness (50 kg)**: Jerk receiving position depends on overhead stability; jerk pulls + front squat work addresses this

## 4. Recovery/Mobility
- **Warm-up**: Arm circles, split squat, cluster, individual position drills
- No explicit recovery/mobility recommendations

**Key adjustment**: Athlete should perform *push jerk progressions* only; adapt split drills accordingly.
