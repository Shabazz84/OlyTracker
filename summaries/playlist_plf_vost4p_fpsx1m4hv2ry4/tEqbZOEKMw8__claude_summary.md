## Technique Cues

**Snatch:**
- Minimize foot spread during pull to enforce proper lower-body mechanics; feet adjust during catch
- Pull height prioritized; eyes forward throughout
- **Rigid receiving:** Core/postural rigidity when meeting bar overhead; prevents lumbar flexion under load ("no clucking" in bottom)
- Hip contact initiates pull (not bar-to-groin pulling)

**Jerk:**
- Dip position: knees out, hips slightly lower
- Straight-leg reception emphasized
- Bar placement naturally drifts to delts; upper back engagement corrects this
- Firm wrist positioning critical

## Programming Principles

- **Snatch pulls without foot spread** (technical refinement)
- **Snatch squats / overhead descents (уходы рывковые):** Build positional comfort overhead before loading
- Light weight (40 kg) touch-and-go reps for weak-point drilling
- Pause/static holds to ingrain catch positions
- Progression: Master pull → tight receiving → add complexity
