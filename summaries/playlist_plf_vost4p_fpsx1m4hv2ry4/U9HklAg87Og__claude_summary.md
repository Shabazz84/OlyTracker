# Merged Weightlifting Coaching Summary

## Key Points

- **Position-first, load-second approach**: Technical precision takes priority over weight lifted
- **Two-pull warm-up system**: Slow pull to power position + full pull to hip contact before competition lift reduces missed attempts and anchors positional awareness
- **Submaximal technical work**: 20–90 kg loads prioritize movement quality, not strength building
- **Single cue per lift phase**: Prevents cognitive overload; focus on one weak point per session
- **Catch position mastery**: High, rigid reception is the foundation for addressing weak OHS (50 kg limiter)

## Technique Cues

**Foot & Leg Drive:**
- Full foot contact maintained throughout (not on toes)
- "Press into floor" — active foot pressure during pull phase
- Consistent foot placement each rep
- Drive through full foot into extension

**Bar Path & Catch:**
- Receive bar high and rigid; avoid collapsing into excessive depth
- Meet weight above parallel (~90° hip angle)
- Slightly forward bar path acceptable if pull is strong

**Pull Mechanics:**
- Power position checkpoint: hips slightly elevated before final hip drive
- Contact point at hip crease/pubis
- Maintain knee angle; don't reduce it prematurely

## Programming Principles

- **Exercise sequence**: Two preparatory pulls → snatch lift (establishes positional anchors before full lift)
- **Set structure**: Multiple singles/low reps with technical focus, not volume-driven
- **Intensity**: Submaximal weights prioritizing position over load
- **Frequency**: Narrow focus on ONE weak point per lift
- **Emotional readiness**: Mental "charging" between attempts improves execution

## Athlete Relevance

| Issue | Application |
|-------|---|
| **Weak OHS (50 kg limiter)** | Extensive high-catch work; learning to receive loads rigidly without collapsing |
| **Chronic back pain** | Emphasize full-foot pressure & leg drive; avoid excessive early squat demand |
| **Frequent missed lifts** | Two-pull anchor system reduces technical errors mid-lift |
| **No split jerk capability** | Snatch/clean technical foundation takes priority; push jerk requires less positional demand |
| **6-week hypertrophy block ahead** | Current technical refinement session bridges into loading phase with improved mechanics |
