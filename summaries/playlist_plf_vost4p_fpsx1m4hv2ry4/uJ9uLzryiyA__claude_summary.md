## Key Points
- Back extension/lumbar arch emphasis during pulls is foundational; chest position ("lift chest up") must be maintained without postural shifts
- Pull height and power position consistency are critical technical focuses
- Pull mechanics vary by individual limb length—avoid prescriptive cues ("rip from groin")
- Grip width must accommodate comfortable squat reception in snatch
- Horizontal back extension machine recommended as pre-training mobility priority for athletes with chronic back pain/disc issues
- Simultaneous leg and back engagement generates explosive power in pulls
- Pull pauses below knee develop foot position awareness

## Technique Cues
**Snatch/Pull:**
- Maintain back extension and lumbar arch throughout pull
- Lift chest but preserve proper postural alignment
- Achieve maximum height in the pull without mid-lift positional shifts
- Perform pull pauses below knee for foot positioning feedback

**Squat Reception:**
- Grip width selection must allow comfortable snatch squat reception

## Programming Principles
- Pre-training horizontal back extension mobility work is essential (especially relevant for chronic back pain)
- Proper positioning on mobility work takes precedence over load
- Pull mechanics are individualized by limb length; coaching cues must account for structural variation
- Pre-competition/phase-transition taper strategies apply when transitioning from hypertrophy to technique blocks
