# Analysis: "A Potential Problem With Pulling Blocks" by Matt Foreman

**Relevant to this athlete: YES — directly applicable**

---

## 1. **Programming Principles**
- **Caution on block work frequency**: Blocks can be useful but risk creating technical compensation (jumping forward), especially for intermediate lifters
- Load management: Don't overload blocks; use appropriate weight to maintain proper mechanics

---

## 2. **Technique Cues**
- **Critical for this athlete**: Hip drive must be UP and FORWARD, NOT forward-dominant with shoulder pull-back
- Avoid "ramming hips forward" — this causes premature forward displacement and jump-forward in turnover
- Jumping forward is a technical flaw to eliminate (rare exceptions at elite level)

---

## 3. **Exercise Recommendations**
- Use blocks with caution given intermediate status
- If using blocks: prioritize staying **over the bar** with vertical hip extension
- Avoid blocks if jumping forward tendency develops

---

## 4. **Recovery/Mobility**
- Not addressed in text

---

## 5. **Athlete-Specific Relevance**
⚠️ **HIGH PRIORITY**: With OHS at 50 kg (snatch limiter) and no split jerk, this athlete needs technical precision. Block work carries elevated risk of reinforcing forward-jump mechanics. Recommend:
- Floor pulls prioritized over blocks initially
- If blocks used: strict cueing on vertical extension
- Monitor for jumping forward during snatch transitions (especially given low OHS baseline)
