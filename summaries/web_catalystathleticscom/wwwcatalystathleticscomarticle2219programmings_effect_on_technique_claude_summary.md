# Analysis: Programming's Effect on Technique by Greg Everett

## 1. Programming Principles
- **Technique-strength integration**: Program design directly impacts technical execution—not separate elements
- **Exercise specificity**: Load, volume, intensity, fatigue, and exercise order all affect technique development
- **Fatigue management**: Excessive fatigue degrades technical proficiency; if "95% of volume is done with less than average technical proficiency," expect poor technique
- **Exercise ordering flexibility**: Consider scheduling weaker lifts earlier in the week (more recovered) and stronger lifts later if beneficial

## 2. Technique Cues
- "Practice makes permanent" + "training makes stronger"—poor positions under load reinforce bad technique permanently
- Train positions/balance/posture that support optimal technique under heavy loads
- Example: If athlete tips forward in squat/pull, performing pulls with same wrong positions makes it worse, not better

## 3. Exercise Recommendations
- **Tailored variations**: Front squat emphasis (if forward tipping); squat without belt (weak trunk); pause variations; modified competition lifts
- **Competition lift specificity**: Use power, hang, or block variations strategically—but refine further (e.g., snatch/clean with no jump, from power position if athlete has foot-timing issues)
- Avoid generic lightweight technique drills if lacking specific strength to support loaded positions

## 4. Recovery/Mobility Advice
- Monitor sleep, nutrition, stress, overall recovery
- Fatigue → technical degradation; reassess program if consistently underperforming lifts

## 5. **Highly Relevant to This Athlete**
- **OHS 50 kg limiter + chronic back pain**: Squatting without belt may worsen pain; prioritize front squat emphasis, pause variations, and strict core positioning
- **Night shift (Wed–Sun)**: Schedule competition lifts earlier in week when fresher; consolidate strength work when fatigued
- **No split jerk**: Power/push jerk variations acceptable if hip/ankle mobility/drive insufficient for splits—address in accessory work
- **Clean-to-jerk gap (80→65 kg)**: May indicate front squat or pulling weakness; assess whether programming reinforces weak positions
