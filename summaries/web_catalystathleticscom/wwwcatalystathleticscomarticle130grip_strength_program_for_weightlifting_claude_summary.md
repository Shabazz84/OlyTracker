# Analysis: Grip Strength Program for Weightlifting (Greg Everett)

## 1. Programming Principles
- **Frequency:** 3x/week grip-specific work
- **Sets/Reps:** 
  - Day 1: Gripper 5×8-12 (moderate), No-Hook Hang Snatch 5×3
  - Day 2: Gripper 5×15-20 (light), Snatch Grip Hangs 3-5×10-30sec
  - Day 3: Gripper 5×3-5 (heavy), Farmer's Walk 3-5×20-30m
- **Intensity progression:** Heavy grippers with max hold on last rep

## 2. Technique Cues
- **Snatch:** No-hook hang snatch (mid-thigh) — don't drop bar; maintain grip on descent for grip stimulus
- **Snatch grip hangs:** Omit hook grip; forces hand positioning awareness and timing during turnover
- **Thumb pain mitigation:** Use elastic athletic tape if hook grip volume causes soreness

## 3. Exercise Recommendations
- **Eliminate straps** in snatch training except heavy hangs (multi-rep)
- **Warm-up sets:** Practice without hook grip/straps where possible
- **Accessories:** Gripper work, farmer's walks, snatch-grip hangs, pinch-plate carries
- **Accessory grip work:** Thumbless pull-ups, hanging leg raises

## 4. Recovery/Mobility Advice
- Tape thumbs (elastic athletic tape) to reduce pain and increase security sensation
- Trial lighter chalk or smoother-knurl bars to force tighter grip engagement

## 5. Relevance to This Athlete
**HIGHLY RELEVANT** — OHS at only 50 kg is primary snatch limiter; weak grip likely exacerbates hand insecurity overhead. This program directly addresses snatch grip security, critical for progression. Safe for night-shift recovery (3x/week accessory fits easily). **Caution:** Avoid overloading grip work given chronic back pain; farmer's walks and heavy hangs should use moderate loads to prevent systemic fatigue.
