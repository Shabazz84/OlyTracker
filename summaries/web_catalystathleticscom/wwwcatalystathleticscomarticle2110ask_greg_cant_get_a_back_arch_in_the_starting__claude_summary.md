# Analysis for Intermediate Athlete (102.5kg, Chronic Back Pain, Night Shift)

## 1. **Programming Principles**
None specified in this text.

---

## 2. **Technique Cues (Snatch/Clean Setup)**
- **Arch the entire spine** (not just scapular retraction alone)
- **Depress scapulae; keep neutral** protraction/retraction
- **Push knees out hard** inside arms → opens hips, effectively shortens leg length
- **Wider pulling stance** → easier back arch in floor position
- Maintain arch throughout first pull

---

## 3. **Exercise Recommendations** ⚠️ **RELEVANT TO THIS ATHLETE**
- **Mobility work**: Spiderman lunges, "Russian baby maker" (deep hip opener)
- **Hamstring/adductor/glute stretching**
- **Slow eccentric snatch/clean pulls** — maintain arch from top to floor
- **Good morning squats** — arch back, fight to maintain arch into squat depth
- **Floating pulls/hang position lifts** — build back strength while stretching hips
- **Back-specific**: Slow eccentrics strengthen back in arch position

**Critical Note**: Given chronic back pain, recommend medical clearance before aggressive back arching or good mornings. Consider pain-free ROM first.

---

## 4. **Recovery/Mobility**
- Hip mobility is primary limitation for floor setup
- Stretching > strengthening for this issue
- Specific stretches: spiderman lunge, Russian baby maker

---

## 5. **Athlete-Specific Relevance**
✅ **Highly applicable**: Back arch limitation directly impacts first pull → snatch technique → OHS (50kg limiter)
⚠️ **Caution**: Chronic back pain requires modifications; avoid aggressive arching without supervision
✅ **Night shift compatibility**: Mobility work (stretching, slow pulls) can be done lower intensity on recovery windows

---

**Actionable**: Widen stance, focus on hang position work, prioritize hip mobility work before aggressive back extension exercises.
