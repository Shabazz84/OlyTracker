# Analysis: "Weightlifting Program Design: Feelings vs. Planning" by Greg Everett

## 1. Programming Principles
- **Macro structure**: Long-term plan → mesocycle refinement (4-week blocks) → week-by-week detail
- **Flexibility within structure**: Pre-plan broadly, adjust weekly based on athlete's actual performance
- **Day-to-day adjustments**: Monitor during sessions; change weights/reps/exercises if needed, but ensure changes align with long-term goals
- **Avoid extremes**: Balance prescription with responsiveness

## 3. Exercise Recommendations
- **Avoid exercise selection by feel**: Athletes gravitate toward strengths (widening gaps in weaknesses)
- Athletes must be prescribed less-favored exercises to address limitations
