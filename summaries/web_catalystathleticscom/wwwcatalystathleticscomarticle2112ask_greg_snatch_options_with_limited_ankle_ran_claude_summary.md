# Analysis: Snatch Options with Limited Ankle ROM

## Relevant to This Athlete

**High relevance.** This athlete has chronic back pain and a weak overhead squat (50 kg—major snatch limiter), making ankle mobility constraints particularly problematic.

---

## Key Extracts

### Technique Cues (Snatch)
- **Landing mechanics matter more than ROM:** Landing on toes = forward balance issue, exacerbating ankle demands. Prioritize landing flat-footed with feet under center.
- **Receiving position alternatives:** Wider stance + toes turned out more + greater hip mobility reliance can partially compensate for ankle limitations.
- **Test via overhead squat/heeling snatch balance:** If these are significantly stronger than snatch, the ankle isn't the primary limiter—address positioning/balance first.

### Exercise Recommendations
- **Overhead squats** (high volume) – build hip mobility + strengthen position
- **Heeling snatch balances** – same goal; also diagnose whether ankle or positioning is limiting
- Gradually widen stance over time; build hip flexibility progressively

### Snatch Variations for Limited Ankle ROM
1. **Split snatch** – always viable; less ROM-dependent but lower absolute load
2. **Power snatch** – if explosive; comparable height to split if not perfecting split depth
3. **Squat snatch with modified stance** – wider, toes out, hip-dominant (requires gradual build-up)

### Recovery/Mobility Advice
- Experiment extensively; expect frustration
- Build margin for error given ROM constraint

---

## Recommendation for This Athlete
Given **50 kg OHS weakness + chronic back pain**, prioritize Greg's suggestion: extensive overhead squat work (especially during hypertrophy block) to build hip mobility and positional strength *before* determining if ankle truly limits snatch. May partially resolve 6-week block limiter.
