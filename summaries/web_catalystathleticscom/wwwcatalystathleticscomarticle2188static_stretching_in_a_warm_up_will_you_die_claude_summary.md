# https://www.catalystathletics.com/article/2188/Static-Stretching-in-a-Warm-up-Will-You-Die/

**Relevant Extracts for This Athlete:**

**1. Recovery/Mobility Advice (HIGHLY RELEVANT)**
- **Static stretching timing**: Do AFTER training when warm—most effective for improving baseline mobility/flexibility
- **Warm-up protocol**: Dynamic movements first (monostructural work, dynamic ROM drills, muscle activation), THEN static stretching if needed
- **Exception for this athlete**: Given "extreme mobility restrictions" (OHS 50 kg is primary limiter), static stretching between sets during warm-up is acceptable to progressively improve ROM
- **Hold duration**: 30–60 seconds per stretch; multiple sets accumulate better results
- **For overhead work**: Focus on shoulder girdle, lats, wrist forearm mobility—safe to include in warm-up without neurological cost

**2. Specific to Athlete's Profile**
- Chronic back pain + poor OHS (50 kg) = mobility is critical limiting factor
- Static stretching *between sets* during warm-up justified here given mobility deficits
- Avoid static stretching pre-lift for explosive lifts (snatch/clean/jerk)—use dynamic prep instead
- Post-session stretching (after training) should be prioritized for mobility gains

**3. Not Covered in Text**
- Programming principles, technique cues, hypertrophy block structure, night-shift recovery strategies

**Bottom Line**: Use dynamic warm-up, then targeted static stretching (shoulder/lat/ankle focus). Prioritize post-training static stretching for baseline mobility development to address OHS limitation.
