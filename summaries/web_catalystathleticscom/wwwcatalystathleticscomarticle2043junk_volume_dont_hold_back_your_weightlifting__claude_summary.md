# Analysis: "Junk Volume" by Greg Everett

## 1. Programming Principles
- **Volume Management**: Start conservative, gradually increase while monitoring progress. Dial back if progress stalls or athlete shows fatigue/disengagement.
- **Individualization**: No formula exists; volume varies by athlete. Age, gender, experience are starting guidelines only.
- **Periodization**: Volume generally increases with younger lifters; decreases with age. Adjust short-term only for major external stressors (job changes, travel, etc.).
- **Priority Hierarchy**: Distinguish spine exercises (snatch/C&J) from appendages (variations) from accessories. Never sacrifice primary lifts for accessory work.

None provided.

## 3. Exercise Recommendations
- **Identify Junk**: Remove exercises you *want* vs. *need.* Ask: Would I replace a priority lift for this?
- **Bodybuilding Work**: Useful post-competition to prepare joints; becomes junk if added for fear of looking weak.
- **Competition Variations**: Keep only if actively contributing; drop when benefit plateaus.
- **Key Principle**: Don't reduce snatch/C&J/squat/pull volume to accommodate low-priority accessories.
