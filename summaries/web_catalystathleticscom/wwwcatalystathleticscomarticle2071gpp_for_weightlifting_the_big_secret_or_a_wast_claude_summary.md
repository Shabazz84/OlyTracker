# Analysis: GPP for Weightlifting - Everett

## 1. **Programming Principles**
- **Periodization**: GPP heaviest post-competition (active rest phase), then reduced as cycle progresses toward competition
- **Frequency**: Start ~1 carrying/dragging exercise/week, 1-2 jumping exercises/week, 2-3 days bodybuilding work/week, daily ab work
- **Intensity/Volume**: Light-to-moderate; don't exceed 1 hour daily GPP on top of specific work
- **Note on athlete**: New lifters benefit from heavier GPP relative to SPP initially

## 2. **Technique Cues**
None provided in this text.

## 3. **Exercise Recommendations (GPP categories)**
- **Joint Stability**: Overhead carries (DB/KB), sled walks (esp. backward), farmer carries, sandbag work
- **Explosiveness**: Jumping, bounding, short sprints, throwing
- **Hypertrophy/Joint Prep**: Bodybuilding-style work (8-20 reps, lighter weight)
- **Grip**: Farmer carries, wheelbarrow walks, pinch lifts, hangs
- **Trunk Stability**: Ab/back direct work + loaded carries (PRIORITY #1)
- **Unilateral**: Lunges, step-ups, 1-leg RDLs, 1-arm pressing/pulling
- **Kinesthetic Awareness**: Gymnastics movements, calisthenics
- **Conditioning**: Low-intensity aerobic (walking, light cycling) only for mobility/active recovery—NOT required for sport

## 4. **Recovery & Mobility**
- Trunk stability is foundational (without it, "you can't accomplish much")
- Variety in movements reduces repetitive-use injuries/chronic pain
- Low-intensity aerobic activity prevents sedentary stiffness on rest days

## 5. **Relevance to This Athlete**
✓ **HIGHLY RELEVANT:**
- **Chronic back pain** → Prioritize trunk stability work (ab/back direct + loaded carries)
- **Weak OHS (50 kg)** → Joint prep/stability work will support shoulder/thoracic mobility and core control
- **6-week hypertrophy block planned** → Perfect window for bodybuilding-style GPP (8-20 reps)
- **New to Olympic lifting** → Should dose GPP heavier initially before specificity phase
- **Night shift (Wed–Sun)** → GPP variety offers mental relief from monotonous barbell specificity
- **No split jerk** → Unilateral work (lunges, step-ups) will build single-leg stability needed for split jerk progression

**Recommend**: Trunk stability + unilateral work as cornerstones given back pain and jerk limitation.
