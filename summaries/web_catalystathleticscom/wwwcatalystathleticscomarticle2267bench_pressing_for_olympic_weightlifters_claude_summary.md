# Analysis: "Bench Pressing for Olympic Weightlifters" by Greg Everett

## **Relevant to This Athlete:**

**1. Programming Principle**
- Bench press is optional, not necessary for OL. Push press/push press variations superior for jerk development (mobility + tricep strength + dip/drive mechanics).

**2. Exercise Recommendations**
- **AVOID bench press** — this athlete should skip it:
  - Chronic back pain + bench = spinal load concerns
  - OHS is primary limiter (50 kg) = mobility-dependent; bench compromises overhead mobility
  - Push jerk only (no split) = needs dip/drive position work, not bench
  - Better alternatives: push press, push press variations, dips
- **Pulling emphasis:** Maintain 2:1 pull-to-push ratio (vertical + horizontal pulling)
- Mobility work: pec/shoulder stretches, arm circles, CARs for overhead position

**3. Shoulder Health & Mobility (Critical)**
- If any pressing is used: narrow grip, elbows ~45° from body
- Adequate warm-up before overhead work
- Prioritize mobility maintenance given OHS weakness

## **Not Directly Addressed**
- Hypertrophy block structure
- Night shift recovery strategies
- Back pain management protocols

**Bottom line:** This athlete should avoid bench pressing and focus on push press variants + heavy pulling + mobility to address jerk development and OHS limitation.
