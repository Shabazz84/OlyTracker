# Analysis: Greg Everett on Clean/Snatch/OHS Ratios

## **1. Programming Principles**
- **Clean:Front Squat ratio** = 85-90% (athlete at 88%, acceptable)
- **Power Clean:Clean ratio** = 80-90% (athlete inverted—major issue)
- **Solution:** Increase squat frequency and emphasis; squat after every power clean
- **OHS Development (2-3 weeks per phase, 4-6 sets, add weight weekly):**
  - Phase 1: Snatch Push Press + OHS (5+3)
  - Phase 2: Snatch Push Press + OHS (3+2)
  - Phase 3: OHS (3) then Push Press (5)
  - Phase 4: OHS (2) then Push Press (3)
  - Phase 5: OHS (1)

## **2. Technique Cues**
- **OHS bottom position:** Hold 3 seconds on last rep of each set
- **Snatch:** Hold bottom 2-3 seconds; add OHS at end of each snatch set
- **Warm-up:** 3+ days/week OHS with empty bar or 50% best OHS (triples)

## **3. Exercise Recommendations**
- Increase back/front/overhead squat frequency
- Snatch Push Press + OHS pairing (per phases above)
- Post-power-clean squats (catch position → full squat)

## **4. Key Insight for This Athlete**
OHS weakness (50 kg) vs. snatch (80 kg) is **not necessarily a problem**—disparity likely reflects mobility/stability deficit in OHS, compounded by insufficient squat volume. Your chronic back pain + night shifts make the increased squat frequency recommendation challenging; prioritize controlled OHS work and mobility.
