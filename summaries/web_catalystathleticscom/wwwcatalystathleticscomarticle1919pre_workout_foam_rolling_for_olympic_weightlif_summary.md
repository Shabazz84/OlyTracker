# https://www.catalystathletics.com/article/1919/Pre-Workout-Foam-Rolling-for-Olympic-Weightlifting/

**1. Programming principles:** None (Text focuses solely on warm-up/prep).
**2. Technique cues:** None (Text contains no lifting technique cues).
**3. Exercise recommendations:** Pre-workout foam rolling series: Thoracic spine, underarms, glutes, hamstrings/adductors, quads/VMO/IT band.
**4. Recovery or mobility advice:** Use a dense black roller; perform 10–15 light passes per area (2 minutes total); keep it painless; save aggressive/deep work for post-workout or rest days.
**5. Athlete profile relevance:** 
*   **Chronic back pain:** The Thoracic Spine section specifically addresses T-spine mobility, which is critical for reducing lumbar strain during overhead movements (Snatch/Jerk).
*   **OHS limiter (50 kg):** Underarm and Thoracic rolling directly targets overhead mobility restrictions.
*   **Night shift worker:** The "painless," quick nature of the routine fits well with fatigue management, but the text warns against deep work which might exacerbate pain if performed while fatigued; stick to light pre-workout rolling only.
