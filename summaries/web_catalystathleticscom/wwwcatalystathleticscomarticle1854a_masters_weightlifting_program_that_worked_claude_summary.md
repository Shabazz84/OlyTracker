# Analysis: "A Masters Weightlifting Program that Worked" by Matt Foreman

## Relevant to This Athlete's Profile

**1. Programming Principles**
- **Frequency:** 2x/week (Tuesday light, Saturday heavy) — directly applicable to night shift worker (Wed–Sun schedule feasible with Mon/Tue + Thu/Fri adjustments)
- **Loading strategy:** Alternating light/heavy on same lifts across days (e.g., light snatch Tuesday, heavy snatch Saturday) to avoid overtraining
- **Volume:** Minimal but intentional; 80–90% intensity rule per Schemansky quote
- **Deloading:** 2 planned deload weeks in 14-week cycle
- **Periodization:** 14-week build to competition; first 4 weeks deliberately light (post-layoff easing)
- **Back squat frequency:** Heavy 1–2x/week; kept 2–3 weeks from competition

**2. Exercise Selection**
- Only programmed SN, C&J, BSQ (loaded lifts only; assistance like RDLs/core unprogrammed)
- **No front squats** — replaced with back squats due to wear-and-tear (relevant to athlete's chronic back pain; consider similar modifications)
- Emphasis on quality over quantity

**3. Recovery/Sustainability Notes**
- High work demands (60–70 hrs/week) necessitate minimal programming
- Age 36+: muscle memory allows fewer lifts to drive gains
- Avoid maxes in gym; limit max attempts to once every 3–4 weeks
- Proper sleep/nutrition "doubly important" as master's athlete (per Neil Kanterman comment)

## NOT Directly Addressed
- Hypertrophy block programming (athlete's 6-week goal) — this is strength/technique-focused
- Snatch technique cues or OHS development (athlete's primary limiter: 50 kg OHS)
- Push jerk progression (athlete has no split jerk)
- Specific recovery for chronic back pain

---

**Key Takeaway:** 2x/week structure aligns with athlete's schedule constraints; low-volume, high-quality approach may suit night-shift recovery limitations.
