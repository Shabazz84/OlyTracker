# Analysis: "My 5 Favorite Accessory Exercises for Weightlifters" by Greg Everett

## 1. **Programming Principles**
- Accessory work has value but isn't magical—effectiveness depends on athlete needs and training cycle phase
- **Time-capped approach preferred** (e.g., 15 min) over volume prescriptions to prevent workout bloat
- **Competition proximity protocol**: Reduce accessories as meet approaches; maintenance phase 2 weeks out, lighter/minimal final week
- Recovery cost of accessory work is typically low—can be added liberally outside competition taper

## 2. **Technique Cues**
None specific to snatch/clean/jerk techniques provided.

## 3. **Exercise Recommendations (5 Accessory Picks)**
1. **Turkish Get-up** (high-bridge variation) — glute work + hip flexor mobility; deliberate pace, constant tension
2. **Pull-ups** — upper body strength + shoulder mobility; **critical for balancing pressing/jerking dominance**
3. **Single-Leg RDL** — unilateral stability, posterior chain; controlled tempo, no bouncing; option to train barefoot
4. **Overhead Carries** (multiple variations: 2H barbell jerk/snatch grip, 1H KB/DB, bands/chains for instability) — scapular stability, wrist/hand positioning
5. **Step-ups** — superior unilateral hip stability vs. lunges; ego check required; tempo options (slow eccentrics)

## 4. **Recovery/Mobility**
- Turkish Get-up → hip flexor mobility
- Pull-ups → shoulder mobility preservation
- Single-leg work → foot training (barefoot option)

## 5. **Relevance to This Athlete**
✓ **High priority**: Pull-ups (address jerk-dominant pressing pattern; shoulder health)  
✓ **Moderate priority**: Overhead carries (wrist/scapular stability for OHS weakness)  
✓ **Consider carefully**: Step-ups/RDL (chronic back pain requires load management; unilateral leg work useful but monitor tolerance)  
⚠️ **Avoid Turkish Get-up** if back pain is spine-loaded sensitive  
✓ **6-week hypertrophy block**: Accessory work fits well; taper before strength phase
