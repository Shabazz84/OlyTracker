# Analysis: "Ask Greg: Cleans Crashing at Heavier Weights"

## 1. **Programming Principles**
- **Complex recommendation**: Power clean + clean (same session) to build consistency across rep heights
- Focus: receiving bar at same shoulder height regardless of pull height
- Alternative variations: high hang cleans, cleans from high blocks
- Emphasis: movement pattern stays identical; only force application changes with heavier weight

## 2. **Technique Cues for Clean**
- **Core issue**: Bar-lifter separation during turnover (not staying connected)
- **Key cue**: "Meet the bar with shoulders at whatever height you've pulled it to"
- **Chest positioning**: "Reach your chest up into the bar as you complete the turnover"
- **Pull mechanics**: Explosive, abrupt finish upward with quick direction change—no extended pull or lean-back at heavier weights
- **Common error at heavy weights**: Attempting to pull higher (over-pulling) + premature descent = late, slow turnover → crash

## 3. **Exercise Recommendations**
- Power clean + clean complex
- Tall cleans (mentioned but less effective than weighted variations for this problem)
- High hang cleans / cleans from high blocks
