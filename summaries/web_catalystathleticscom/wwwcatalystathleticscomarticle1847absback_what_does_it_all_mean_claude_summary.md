# Analysis: Abs/Back Work by Greg Everett

## 1. Programming Principles
- **Heavy back work** (stiff-legged deadlifts, good mornings, straight-legged deadlifts): counts toward training volume; 2–3 days/week; schedule on heavier training days
- **Light back work** (extensions, planks, reverse hypers, glute-ham raises): does NOT count toward volume; can be daily; schedule on lighter days
- **Ab work**: never counts toward total volume
  - **Trunk/hip flexion**: 10–30+ reps unweighted; 8–15 reps weighted
  - **Static/rotation**: planks 20–30 sec; add weight as needed
- **Weekly pattern example**: Heavy days (Mon/Wed/Sat) = harder ab exercise + static/rotation; Light days (Tue/Thu) = static/rotation only

## 3. Exercise Recommendations
**Relevant to this athlete's chronic back pain:**
- Prioritize **light back work** (back extensions, reverse hypers, planks) over heavy work initially
- Consider Everett's caveat: "in cases of existing lumbar problems I would feel differently" about aggressive spinal flexion (sit-ups)
- Include rowing/pull-ups regularly if capacity allows
- Follow prescribed work; don't self-prescribe heavy back volume without coaching guidance

## 4. Recovery/Mobility Advice
- Heavy back work impacts systemic fatigue/recovery significantly
- Light back work has minimal recovery cost
