# Weightlifting Coaching Analysis: Pressing for Weightlifters

## 1. Programming Principles
- **Macrocycle placement**: Pressing in BASE PREPARATION (6-14 weeks pre-competition); reduce in transitional phase (4-8 weeks out)
- **Weekly timing**: Schedule pressing on days followed by rest days; avoid heavy snatching the next session
- **Session placement**: End of session (exception: push press can substitute for jerk mid-session)
- **Variation**: Rotate exercises weekly (push press + bench one day, press + snatch grip press another); vary rep ranges (2-3 heavy vs. 5-6 moderate)
- **Rep schemes**: 5-7 reps to near-failure acceptable for hypertrophy; avoid daily high-fatigue protocols

## 2. Pressing Exercise Recommendations
- Push press, bench press, strict press, snatch grip press
- Push press can replace jerk in clean & push press complexes
- Bench press should drop completely in transitional phase

## 3. Rationale for This Athlete
- **OHS limiter (50 kg)**: Stronger shoulders → more comfortable lockout position
- **Push jerk only** (no split): Arm/shoulder strength directly supports jerk rack position
- **6-week hypertrophy block ahead**: Perfect timing for pressing work per Bondarenko's base prep recommendation
- **Night shift (Wed–Sun)**: Schedule pressing Wed (before rest day Thurs) or Sunday (if followed by days off)

## 4. Key Caution
Pressing soreness impairs speed/Olympic lift quality → strict timing essential given athlete's back pain and technique priorities.
