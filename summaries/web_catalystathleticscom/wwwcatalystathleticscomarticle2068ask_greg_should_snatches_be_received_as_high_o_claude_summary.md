# Analysis: "Should Snatches Be Received High or Low?"

## Relevant to This Athlete

**TECHNIQUE CUE — Critical for OHS limiter (50 kg):**
- Receive snatch as **high and as soon as possible**, not as low as possible
- This athlete's weak OHS (50 kg vs 80 kg clean) suggests instability overhead
- Everett's principle: secure bar overhead quickly → stay connected to it → avoid crashing down
- **Don't chase depth by reducing pull power** — maintain aggressive 2nd pull + aggressive 3rd pull always

**Key concept:** Receiving depth is determined by bar velocity/weight, not by choice. With lighter weights, maximal effort keeps the bar higher. Deliberately receiving low requires reducing pull effort, which creates bad habits.

---

## Practical Application

**For this athlete's transition:**
1. **6-week hypertrophy block**: Practice snatches with controlled receiving position (high/stable) rather than chasing depth
2. **Overhead stability work**: OHS weakness may improve by drilling secure bar positioning, not depth alone
3. **Snatch progressions**: Use power snatch variation initially to ingrain aggressive extension + secure overhead position
4. **Avoid**: Intentionally dropping under light weights to "get lower" — establishes poor mechanics before strength block
