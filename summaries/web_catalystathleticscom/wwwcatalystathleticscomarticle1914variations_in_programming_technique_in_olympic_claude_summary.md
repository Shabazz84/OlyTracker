**1. Programming Principles**
- Beginners: standard technique progressions, basic movements (snatch, clean, jerk, squats, push press), 3-4x/week
- Intermediates: add variations to address identified weaknesses; experiment to find individual responses
- Advanced: spontaneous adjustments based on self-knowledge; individual variation is expected

**2. Technique Cues**
- Weak back: pull with more upright torso, start with lower hips
- Weak legs: start with higher hips, stay over bar longer
- No specific snatch, clean, or jerk cues provided

**3. Exercise Recommendations for Specific Weaknesses**
- Weak legs: lunges, waiter squats, leg presses
- Weak pull: suitcase deadlifts, deficit pulls, upright rows, pull-ups, muscle snatches
- No recommendations for OHS limitation or back pain
