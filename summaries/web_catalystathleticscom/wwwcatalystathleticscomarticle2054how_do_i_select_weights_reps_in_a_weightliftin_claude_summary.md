# Analysis: Weightlifting Program Design by Greg Everett

## 1. Programming Principles
- **Three main approaches**: Bulgarian-style (daily maximal singles), All Max All The Time (varied reps/exercises, daily maximal), Planned Progression (prescribed intensities modulated over cycle)
- **Mix approaches** based on athlete needs and phase
- **Volume selection**: Must match individual athlete response—no universal formula
- **Rep ranges**: Some athletes respond better to lower reps, others higher reps, others mixed ranges
- **Intensity progression**: Week-to-week increases (start 70-75% for first mesocycle exposure; adjust by 2-3% if week 1 is heavy, up to 5% if lighter)
- **Volume-intensity inverse**: As intensity rises, reduce reps or sets (e.g., 5 triples → 3 triples by week 3)
- **Starting conservatively** is essential; refine via observation
