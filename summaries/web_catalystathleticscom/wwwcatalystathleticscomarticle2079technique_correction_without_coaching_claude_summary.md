# Analysis: "Technique Correction without Coaching" by Greg Everett

## 1. Programming Principles
- **Exercise selection over coaching cues** for technical development
- Use **isolation/accessory exercises** to teach movement patterns without the complexity of full lifts
- **Progressive loading** forces self-correction (e.g., empty bar allows sloppiness; load forces precision)
- Avoid relying solely on verbal cues; prioritize **motor learning through well-designed exercise selection**

## 2. Technique Cues & Teaching Method
- Coaching cues have limited value without prior context/understanding
- **Bypass conscious mind** — use targeted exercises instead
- Examples given:
  - **Weak third pull (bar swings)** → Tall snatches (isolates overhead positioning)
  - **Not staying over the bar** → Halting/segment deadlifts or pulls (strength + position practice)
  - **Forward dip in split jerk** → Power jerks or power jerk + split jerk complex

## 3. Exercise Recommendations
- Tall snatches
- Snatch from power position
- Snatch pull + snatch (or hang snatch)
- Hang snatch from knee or higher
- Halting/segment deadlifts and pulls
- Power jerks / power jerk + split jerk complex

## 4. Recovery/Mobility Advice
None provided in text.

## 5. Specific to This Athlete
**HIGHLY RELEVANT:**
- **OHS 50 kg limiter** → Use tall snatches and snatch from power position to build overhead confidence without back stress
- **Split jerk gap** → Power jerk + split jerk complex directly addresses this weakness
- **Chronic back pain** → Isolated exercises (tall snatches, power position work) reduce full-lift complexity; halting pulls allow controlled strength work without lumbar fatigue
- **Night shift work** → Shorter, focused sessions on targeted exercises are time-efficient
