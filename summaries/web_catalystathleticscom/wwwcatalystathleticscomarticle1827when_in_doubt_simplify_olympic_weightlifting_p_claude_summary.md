# Analysis: Greg Everett - "When in Doubt, Simplify"

## 1. Programming Principles
- **Exercise hierarchy**: Snatch/C&J → Squats → Pulls → Power variants (build around these; avoid premature accessory work)
- **Volume structure**: Alternate high/low volume days (e.g., 80 reps Mon/Wed/Sat, 40–60 reps Tue/Thu); count only reps ≥70% on main lifts
- **Intensity structure**: Pair high-intensity days with high-volume days; low-intensity days use power variants or overhead work to reduce leg tax
- **Periodization**: Avoid percentage-based dogma; prescribe based on desired outcome and feel/look; track percentages to identify patterns over time

## 3. Exercise Recommendations
- **Priority**: Snatch, Clean & Jerk, Front/Back Squats, Snatch/Clean Pulls
- **Lighter days strategy**: Use power variants or jerk variations to spare legs while maintaining intensity
- **Accessory rule**: Include only accessory work that meaningfully stresses the system (e.g., heavy SLDL yes; empty-bar Sots press no)

## 5. Relevance to This Athlete
- **Back pain + night shift**: Low-volume days with jerk/overhead emphasis aligns well (reduces spinal compression vs. heavy leg days)
- **OHS limiter (50 kg)**: Prioritize overhead work; Everett's recommendation for jerk/overhead on lighter days supports mobility/shoulder work without leg fatigue
- **Push jerk only**: Can be classified as lower-intensity day work per Everett's framework; split jerk development fits future blocks
- **6-week hypo block**: Baseline high-volume structure (80/40–60 reps) fits; adjust from there
