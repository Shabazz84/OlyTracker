# Analysis: "Do We Need the Magic Front Squat to Back Squat Ratio?"

## 1. Programming Principles
- **No universal ratio exists**—squat emphasis changes by training phase
- **Base Period**: 2:1 Back Squat (BS) to Front Squat (FS) ratio
- **Transitional**: 1:1 ratio
- **Competition Phase**: 1:2 BS to FS ratio

**Back Squat Protocol (Base/Heavy):**
- 3 sets × 5–7 reps, heavy, to failure
- Frequency: Every 7–14 days
- Light interim work: 1–2 sets × 2 reps at clean weight, or 3 × 5 at lighter weight

**Front Squat Protocol (Base):**
- 2–3 reps per set, to failure
- Competition phase: 2–3 reps, or singles at non-fatiguing weights for confidence

**Competition Phase**: 2–3 sets × 2 reps to maintain strength without soreness

## 2. Technique Cues
None provided.

## 3. Exercise Recommendations
- **BS advantages**: Handles heavier loads, less knee/shoulder/wrist stress, higher reps viable, ideal for strength base
- **FS advantages**: Specific to clean recovery; builds upper back tightness for jerk leg drive; emphasize in competition phase

## 4. Recovery/Mobility Advice
- Avoid heavy squat sessions on heavy clean days
- Defer front squats if knees are aching
- Competition phase reduces volume to minimize soreness

## 5. Relevance to This Athlete
**Highly relevant**:
- Chronic back pain → prioritize BS (less joint stress) in base block, but monitor load
- Weak OHS (50 kg) suggests weak front squat/upper back → FS work critical before competition phase to address jerk limitation
- 6-week hypertrophy block aligns with base period → 2:1 BS:FS ratio recommended
- Night shift (Wed–Sun) → plan heavy squats strategically to avoid fatigue on competition lift days
