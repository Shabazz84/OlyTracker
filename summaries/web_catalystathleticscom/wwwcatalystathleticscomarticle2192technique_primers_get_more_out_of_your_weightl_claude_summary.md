# Analysis: Technique Primers by Greg Everett

## 1. Programming Principles
- **Timing**: Technique primers performed **immediately before** the primary lift (same session)
- **Volume**: 4–8 sets of 2–3 reps
- **Intensity**: Light weights allowing best execution with minimal fatigue (no carryover fatigue)
- **Goal**: Prime nervous system and ingrain corrected motor pattern before primary lift

## 2. Technique Cues / Exercise Recommendations

**For Snatch (PRIMARY RELEVANCE—OHS is athlete's limiter):**
- Poor finish → **Snatch from power position** (isolates lockout/overhead stability)
- Poor turnover → **Muscle snatch, tall snatch**
- Poor pull → Lift-off, segment pull, high-pull

**For Clean:**
- Poor finish → Clean from power position
- Poor turnover → Muscle clean, tall clean

**For Jerk (athlete does push jerk only):**
- Forward dip/drive → Jerk dip squat, jerk drive, push press
- Forward push → Push press, power jerk
- **Note**: Improper split (not applicable; athlete lacks split jerk)

## 3. Key Principle Relevant to This Athlete
**"Breaking the total movement down and isolating the problem"** is critical given the athlete's weak OHS (50 kg). Snatch from power position or tall snatch immediately before snatches would directly address overhead lockout deficiency without high load on chronic back.
