# Analysis: Prilepin's Table for Olympic Weightlifting (Greg Everett)

## **1. Programming Principles**
- **Critique of Prilepin's Table:** Descriptive (historical analysis), not prescriptive. Based on 1975 Soviet data from limited 5-week mesocycles and snatch/C&J only.
- **Key limitations:**
  - 10% intensity ranges (80% vs 89%) are practically very different
  - Ignores individual variation (technical proficiency, training age, neurological efficiency, bodyweight)
  - Provides no guidance for weekly/mesocycle/macrocycle modulation
  - Doesn't account for accessory exercises (squats, pulls, presses)
  - No progression strategy within or across cycles

- **Takeaway:** General pattern (reduce reps/volume with increasing intensity) is useful; rigid adherence is ineffective. Requires context-specific experience.

## **5. Relevant to This Athlete**
⚠️ **Highly relevant:**
- **OHS limiter (50 kg):** Prilepin's Table doesn't guide pressing/overhead work—you need individualized accessory programming addressing mobility + strength
- **Back pain + night shift:** Requires micro-cycle flexibility (not rigid Prilepin prescriptions)
- **Split jerk absence:** Table assumes standard competition progression; your push jerk path needs custom intensity/volume design
- **6-week hypertrophy block:** Table doesn't address hypertrophy-focused periodization

**Bottom line:** Use Prilepin's conceptual pattern; don't dogmatically follow ranges. Customize for back health, shift work recovery, and competition lift deficiencies.
