# Weightlifting Analysis: Back Training for Weightlifting

## 1. **Programming Principles**
- **Frequency:** Weak backs = 2–3 days/week intense work; light work can be more frequent
- **Intensity/Reps:** Heavy work (5–8 reps); light work (8–15 reps)
- **Periodization:** 2–5 consistent exposures to same exercise before rotation (e.g., 3–4 weeks good mornings, then switch to RDLs)
- **Timing:** Heavy back work at *end* of heavy sessions; light work between sessions (recuperative)
- **Progressive overload:** Increase loading or volume each exposure within a block

## 2. **Exercise Recommendations**
- **Heavy:** Stiff-legged deadlifts, RDLs, good mornings
- **Light/Recuperative:** Back extensions, reverse hyperextensions, unweighted variants
- **Rationale:** Lighter exercises avoid systemic fatigue, allow recovery before next heavy session

## 3. **Recovery/Mobility Advice**
- Lower back is *slowest region to recover*—control volume carefully
- Light back work (8–15 reps) often proves *recuperative* for many lifters
- Balance recovery capacity against total training volume

## 4. **Relevant to This Athlete**
✓ **Critical:** Chronic back pain + night shift = severely limited recovery. Recommend:
- Minimal heavy back work; prioritize light extensions/reverse hypers (2×/week max)
- Place heavy back work at session *end* only
- Monitor OHS limiter (50 kg) alongside back capacity—may need posterior chain activation without spinal extension
- Light back work ideal for recovery windows between heavy nights
