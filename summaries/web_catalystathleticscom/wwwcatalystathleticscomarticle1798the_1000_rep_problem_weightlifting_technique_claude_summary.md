# Analysis: "The 1,000 Rep Problem" by Matt Foreman

## Relevant to This Athlete's Profile

**1. Programming Principles**
- Emphasis on **quality over quantity**: only correct reps count toward skill accumulation; poor reps reset progress
- Long-term development required (1,000+ correct reps); no shortcuts to technical mastery
- Consistency over intensity early: build correct pattern with lighter loads before progression

**2. Technique Philosophy**
- Distinction between "correct" vs. "perfect" technique—this athlete should target *correct* snatch/clean/jerk patterns first
- Motor learning requires massive repetition of the same correct movement
- Avoid alternating between different technical styles (relevant: night shift may limit consistency; prioritize quality sessions)

**3. Key Insight for This Athlete**
- **Critical for OHS limiter & back pain**: The text implicitly supports technical mastery before loading. This aligns with the 6-week hypertrophy block + technique focus. Light, perfect reps on snatch (currently 50 kg OHS) must precede intensity jumps.
- Patience required: even with intermediate strength base (118 kg BS), snatch/jerk mastery is a 2–3 year journey

**4. Caution**
- Inconsistent training (night shift Wed–Sun) may slow rep accumulation and pattern consistency—schedule lighter technical work on fatigue days
