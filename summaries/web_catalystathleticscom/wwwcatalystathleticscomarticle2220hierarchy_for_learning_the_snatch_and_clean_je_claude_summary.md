# Analysis: Everett's Learning Hierarchy for Snatch & Clean & Jerk

## Programming Principles
**Progression hierarchy (Position → Movement → Speed → Load):**
- Position first: establish starting/receiving positions with 2–3 sec holds
- Movement: string positions together; perform slowly initially to feel mechanics
- Speed: introduce only after proficiency; continue returning to reduced-speed work as needed
- Load: final step; heavy loads reinforce poor patterns if applied too early

**Frequency/Structure within session:**
- Use abbreviated movements in warm-up (muscle snatch, pressing snatch balance, slow pulls, etc.)
- Don't train like advanced lifters; build broad foundation first

## Technique Cues (Snatch/Clean/Jerk)
- Hold starting position 2–3 sec before movement
- Hold receiving position 2–3 sec before standing/dropping bar
- Slow movements expose balance/tension issues; light loads (PVC/empty bar) mask errors
- Return to reduced-speed work when fast lifts break down

## Exercise Recommendations
**Abbreviated/accessory movements listed:**
- Slow pull to hold
- Muscle snatch
- Pressing snatch balance
- Muscle clean
- Press / push press
- Jerk balance
- Slow pull snatch/clean

*Relevant to athlete:* Pressing snatch balance, muscle snatch, and slow pulls critical given 50 kg OHS (snatch limiting factor).

## Recovery/Mobility Advice
None provided in text.

## Athlete-Specific Relevance
**High relevance:**
- Back pain + weak OHS → prioritize position/movement proficiency before loading
- No split jerk → push jerk emphasis aligns with building position foundation
- Night shift worker: structure sessions around progressive cue sequencing (position → movement → speed) rather than volume-heavy days

**Key takeaway:** Don't rush to load; establish OHS/receiving position quality first.
