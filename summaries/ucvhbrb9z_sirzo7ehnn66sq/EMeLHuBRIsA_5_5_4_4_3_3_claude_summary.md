# "5  5", "4  4", "3  3",

## Key Points

- **Wave loading preferred over linear progression**: Vary rep schemes within sessions (3×3, 4×4, 5×5) rather than fixed rep ranges to prevent accommodation and maintain stimulus
- **Micro/meso-cycling structure**: 4-week blocks with progressive intensity (75% → 80% → 85%) aligns with your 6-week hypertrophy block
- **Acidotic stimulus option**: Add one higher-rep/lactate set per session if hypertrophy plateau occurs
- **Flexible rest periods**: Use RPE/feel instead of timing; wait until HR settles and you feel ready before next set
- **Individualization over rigid formulas**: Training response varies by person and lift

## Programming Principles

1. **Varied rep schemes within same session** prevents "accommodation" and mental staleness
2. **4-week block progression** (75% → 80% → 85%) manageable for night-shift schedule
3. **Wave loading adaptable to hypertrophy block**: Use rep variation (e.g., 5×5 → 4×4 → 3×3) across weeks rather than fixed sets/reps
4. **Exercise-specific recovery**: Compound lifts recover slower; singles/doubles faster — structure session order accordingly
