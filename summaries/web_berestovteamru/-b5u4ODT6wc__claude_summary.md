# Analysis: Push Press (Швунг Жимовой) Technique Guide

**Language:** Russian (Berestov Team weightlifting channel)

---

## Relevant to This Athlete:

### 1. **Programming & Exercise Purpose**
- Push press is an **accessory exercise** to improve the jerk (clean & jerk)
- Develops: leg drive explosiveness + shoulder pressing strength
- **Critical for this athlete:** PRIMARY value = address weak jerk (65 kg push jerk) and shoulder stability (low OHS 50 kg)

### 2. **Technique Cues for Push Press**

| Element | Cue |
|---------|-----|
| **Grip** | Shoulder-width or slightly wider (consistent with jerk position) |
| **Bar Position** | Fully in palm on shoulders/clavicle; NOT on fingertips |
| **Elbows** | Turned out/slightly forward; maintain shoulder support (don't drop too low) |
| **Core Setup** | Raise diaphragm, brace, slight hip retraction (imagine chair behind you) |
| **Head** | Slightly back, chin tucked (create vertical bar path overhead) |
| **Dip** | **Smooth & controlled downward; powerful upward** |
| **Drive Timing** | **Synchronize leg extension → arm press (critical)** |
| | *Too early press* = loses leg drive power |
| | *Too late press* = bar drops during arm finish |
| **Trajectory** | Bar travels **vertically**, NOT arced away from body |
| **Heel Position** | Can rise onto toes OR stay flat-footed (both valid) |

### 3. **Common Errors** (Especially Relevant)
- ❌ Bar on fingertips only (compromises stability)
- ❌ Excessive backward lean (back pain risk **← key for this athlete**)
- ❌ Elbows dropped too low (loses shoulder support)
- ❌ Re-bending knees mid-press (becomes split jerk—different lift)
- ❌ Bar drifts forward during press

### 4. **Recovery/Injury Prevention**
- **CRITICAL for chronic back pain:** Maintain upright torso; avoid excessive backward lean
- Emphasize leg drive over arm pressing to reduce lumbar stress

### 5. **Recommendation for This Athlete**
Push press should be **staple in 6-week hypertrophy block** for jerk development and shoulder stability (addresses OHS limiter).
