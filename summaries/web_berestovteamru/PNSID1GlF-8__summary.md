**2. Technique cues**
*   **The Error:** Do not start the pull by raising the hips (squatting up with the back). This throws the bar off the correct trajectory.
*   **The Cue:** The movement must initiate from the **legs**, while the spine remains rigid and neutral.
*   **Spine Check:** If you cannot maintain a straight back (no rounding in thoracic/lumbar regions) at a specific platform height, that height is too high.
*   **Bar Path:** Ensure the bar stays close; if the hips rise first, the bar will drift forward.

**3. Exercise recommendations**
*   **Primary Drill:** Snatch Pulls from blocks (Ryovok s podstavki).
*   **Secondary Drills:** Clean Pulls from blocks, Hang Snatches/Cleans starting from the block position.
*   **Allowed Combinations:** Block pulls + Snatch/Clean; Block Cleans + Push Jerk/Shove.
*   **Prohibited:** Split Jerks (Jerk in "nizhnykh" or split style) performed *from* blocks due to safety/instability risks mentioned in the text.

**4. Recovery or mobility advice**
*   **Psychological Safety:** If using weight plates as makeshift platforms, stack multiple plates and place a board on top to prevent fear of falling off (psychological barrier).
*   **Mobility Limitation:** Platform height is dictated by individual flexibility; taller athletes or those with longer limbs may require lower heights.

**5. Specifically relevant to this athlete's profile**
*   **Chronic Back Pain:** The text explicitly warns that if a platform height forces the spine to round ("hunch" in thoracic region) to maintain tension, it is **too high**. This is critical for an athlete with back pain; they must find the *lowest* effective height where the spine stays neutral.
*   **Push Jerk Only:** The text advises against doing Split Jerks from blocks but allows Clean & Press/Shove combinations. *   **Night Shift/Recovery:** While not explicitly mentioned in the text, the "psychological" aspect of lifting lighter weights on blocks to build confidence is useful for a shift worker who may have fatigue management issues.
*   **OHS Limiter (50kg):** The text suggests using blocks to force leg engagement. For an athlete with a weak Overhead Squat, this drill reinforces the "legs first" principle needed to stabilize heavy loads overhead later.
