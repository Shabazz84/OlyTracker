# Analysis: 4-Day Olympic Weightlifting Program

## Relevance to Athlete Profile
**Moderate fit with significant concerns.** Program targets "experienced lifters" but athlete is intermediate transitioning to OLY with specific limiters (weak OHS, push jerk only, chronic back pain, night shift recovery constraints).

---

## 1. Programming Principles
- **4-day split:** 3 main lifting days + 1 optional technical day
- **Load prescription format:** % of 1RM with set/rep schemes (e.g., 50% 1/4; 65% 3/4; 75% 1/4)
- **Periodization:** 16-week macro (Weeks 1-4 technique; 5-8 strength; 9-12 power; 13-16 peak)
- **Frequency:** Flexible (athlete adjusts sessions per recovery)
- **Recovery:** Deload weeks scheduled; emphasize sleep/nutrition

**⚠️ Mismatch:** Program is NOT a hypertrophy block (athlete's stated need). Weeks 1-4 prioritize technique over volume.

---

## 2. Technique Cues
- **Snatch:** Muscle snatch + OHS pairing (Day 1); snatch from blocks with intensity progression
- **Clean:** Power clean variations; pauses emphasized (Day 2: pause jerk)
- **Jerk:** Pause jerk + full jerk pairing; split-position work (Day 2)
- **Day 4:** Low-intensity clean & jerk technical work (≤40%)

**Relevant to athlete:** Snatch from blocks could address weak OHS (50 kg limit). However, no explicit OHS accessory progression outlined—critical gap given stated limiter.

---

## 3. Exercise Recommendations
**Main lifts:** Snatch, Clean, Jerk, Back Squat  
**Accessory/Supplemental:**
- Reverse hyperextension (back health)
- Abs, core work
- Sots press (OHS mobility/strength)
- Good mornings + squats (posterior chain)
- Bench press (upper body stability)
- Reverse planks (core endurance)
- Grip strength drills

**Strength for athlete:** Reverse hyperextension + core work align with chronic back pain management. **Gap:** Limited OHS/overhead positioning accessory work.

---

## 4. Recovery & Mobility
- Dynamic warm-ups: 7–12 min (shoulders, hips, ankles, wrists)
- Day 4 dedicated mobility/stretching (10 min)
- Weekly deload scheduling recommended
- Emphasis on sleep/nutrition quality
- Workout journal tracking

**Night shift relevance:** No accommodation for Wed–Sun night shift fatigue; program assumes standard recovery windows.

---

## 5. Athlete-Specific Gaps
1. **No hypertrophy block focus** (athlete's stated 6-week priority)
2. **Weak OHS not directly addressed** (core limiter at 50 kg vs. BS 118 kg)
3. **Push jerk only—no split jerk progression** pathway
4. **Back pain:** Good inclusion of reverse hyperextension; could expand lumbar stability work
5. **Night shift:** No load/volume deload guidance for circadian disruption

---

## Recommendation
Use **Days 1 & 3 structure** (snatch + squat; clean + squat) but:
- Add 2–3 dedicated OHS/snatch accessory sets (weighted holds, pause OHS, tall snatches)
- Front-load hypertrophy (higher reps, 65–75%) before intensity phases
- Monitor back tolerance; consider RPE caps for round-the-clock shifts
