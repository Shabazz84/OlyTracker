# Analysis: Mobility Routine for Lifters (Torokhtiy)

## Relevant to This Athlete

**Recovery & Mobility Advice:**
- **Critical for chronic back pain**: Mobility work targets hips, shoulders, spine, ankles, wrists, and core stability—all relevant to this athlete's back issues and OHS limitation (50 kg).
- **Pre-workout timing**: Use dynamic stretching only (avoid static >30 sec pre-lift; causes 4–5% strength loss). Save static stretching (30–60 sec) for post-workout recovery.
- **Post-workout protocol**: Static stretching 2+ minutes post-session to maximize flexibility gains (Golgi tendon reflex).

**Recommended Exercises (Directly Applicable):**
1. **Foam rolling** — post-workout recovery (useful for night shift recovery)
2. **Wall slides** — shoulder mobility (critical for jerk lockout & OHS)
3. **90/90 PAILs & RAILs** — hip mobility (supports squat depth & back stability)
4. **Deep squat with single-arm overhead reach** — functional OHS mobility + thoracic rotation
5. **"27 squats"** — varied foot positions for proprioception (addresses squat mechanics)

## Not Addressed
- No programming frequency/volume for a 6-week hypertrophy block
- No specific snatch/clean/jerk technique cues
- No night-shift recovery strategy beyond mobility

**Bottom line**: Implement dynamic warm-up + post-workout static stretching routine focusing on hip, shoulder, and thoracic mobility to address back pain and OHS deficit.
