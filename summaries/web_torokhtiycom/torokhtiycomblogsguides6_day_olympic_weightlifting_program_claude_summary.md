# Weightlifting Coaching Analysis

## 1. Programming Principles
- **6-day split** with intensity/volume structure (50–90% 1RM ranges)
- **Progression**: +2–2% load weekly/bi-weekly
- **Deload**: Every 4–6 weeks (reduce 40–50%)
- **Volume-Intensity trade-off**: Reduce volume when raising intensity
- **Day 6**: Active recovery (light cardio 20 min + stretching 20 min)
- **Warm-up/Cool-down**: 10–15 min each session

## 2. Technique Cues
- **Snatch Balance, Snatch Pull, Hang Snatch** emphasized as progression tools
- **Pause squats, hang variations** introduced after basics mastered
- **Self-assessment**: Film and review lifts regularly

## 3. Exercise Recommendations
- Heavy squat focus (back, front, pause variations; 50–90%)
- Accessory work: Good mornings, hyperextensions, box/depth jumps, band work
- PVC mobility drills (muscle snatch, snatch balance, hip drills)
- **Rotate accessories every 4–6 weeks**

## 4. Recovery/Mobility
- Active recovery day (Day 6)
- Stretching/flexibility emphasis post-session
- Deload every 4–6 weeks

## 5. **Athlete-Specific Relevance** ⚠️
- **OHS limiter (50 kg)**: Program emphasizes snatch balances and overhead squat progressions—**aligned**
- **No split jerk**: Program uses front squat + jerk (power emphasis), compatible with push jerk
- **Chronic back pain**: Heavy back squat (75% days) + pause squats + good mornings may aggravate; **needs mobility/load adjustment**
- **Night shift (Wed–Sun)**: Program requires 6 days/week—**incompatible** with recovery needs; compress to 4–5 days
- **Hypertrophy first**: This template is strength/technique-focused; **not optimal for 6-week hypertrophy block**
