# Analysis: Snatch Balance Coaching Breakdown

## Relevant to This Athlete

**Exercise Recommendation:**
- **Snatch balance** — excellent for this athlete given weak OHS (50 kg limiting snatch). Develops receiving position strength/stability without requiring full snatch technique complexity.

**Technique Cues (Snatch Balance):**
1. Set grip before lifting; minimal pre-tension
2. Feet positioned inside shoulder width initially → promotes natural outward foot movement into catch
3. Elbows tucked directly under bar (speeds lockout)
4. Glute squeeze → neutral spine (critical: chronic back pain management)
5. Drive primarily from quadriceps through knee bend
6. Controlled descent to bottom; stand up using legs
7. Bar path stays vertical on same contact point

## Programming Notes
- Emphasis on **control** over load
- Natural fit for **hypertrophy block** (volume/technique pairing)
- Accessory work addressing OHS weakness

## Key For This Athlete
- **Back-friendly**: glute engagement + neutral spine cue helps manage chronic pain
- **OHS development**: directly strengthens snatch receiving position
- **Lower complexity**: suitable for night-shift fatigue (Wed–Sun schedule)

**Recommendation:** Include 3–4x/week at moderate intensity during hypertrophy block; progress conservatively.
