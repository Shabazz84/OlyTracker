## 1. **Programming Principles**
- **Tonnage progression model**: Keep volume (sets/reps) constant across 12-week blocks; increase load incrementally (e.g., 60kg 5x3 → 62.5kg 5x3)
- **Rep scheme progression**: Cycle through 5s → 3s → 2s → 1s, then reset higher
- **Minimal volume increase for non-elite**: Increase in *intensity/load*, not volume, drives progress
- **Meticulous tracking**: Document work to monitor tonnage accumulation
- **Injury/fatigue adjustments**: Plan deloads when hitting PRs; expect obstacles

---

## 2. **Exercise Recommendations** (Relevant to Profile)
- **Lower block snatches + pulls**: Reduces chronic back strain vs. low-hang (GOOD for this athlete's back pain)
- **Low block rows**: Better contractile connection than strict barbell rows; improves thoracic extension carryover to snatch/clean positions
- **Mobility focus**: External rotation drills + soft tissue work for overhead position (overhead squat limiter)

---

## 3. **Recovery/Mobility Advice**
- Active mobility drills preferred over passive soft tissue work alone for external rotation
- Hip flexor mobility emphasis (for bottom squat position)
- Tricep soft tissue + mobility reducing pain (relevant to jerk development)

---

## 4. **Relevant to This Athlete**
✅ **Back pain management**: Lower block work reduces lumbar stress  
✅ **OHS limiter (50kg)**: Mobility (external rotation, hip flexors) and positioning drills prioritized  
✅ **Push jerk only**: Low block rows improve thoracic/back strength needed for split jerk transition later
