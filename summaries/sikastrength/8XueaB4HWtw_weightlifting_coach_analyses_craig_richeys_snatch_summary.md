## Technique Cues for Snatch

**Primary Issue: Hungarian Start (very low hips)**
- **Disadvantages for intermediate lifters:**
  1. Loses dynamic start benefits → can't pre-stretch muscles or use stretch-shortening cycle
  2. Long "dead zone" before barbell moves (hips/shoulders shift before bar acceleration)
  3. Forces knees too far forward → shins very inclined → barbell tips forward instead of back
  4. Requires massive leg extension (full flexion→165-170°) in very short window → inconsistency
  5. Results in barbell chasing (swinging forward/behind) and missed lifts

- **Optimal start position:**
  - Hamstrings parallel to floor (or slightly above, anatomy-dependent)
  - Even tension distribution: quads + back + legs
  - More consistent, mechanically advantaged position

**Note on comfort:** Position should feel uncomfortable initially if quads are weak relative to squat strength—this is normal and correct.

## Relevant to This Athlete

**CRITICAL:** Your 50 kg OHS (snatch limiter) + chronic back pain + weak snatch (80 kg) strongly suggests start position issues. If you're using a low-hip start:
- **Switch to hamstrings-parallel start immediately** 
- This will reduce shear forces on your back and improve consistency
- Expect discomfort initially (your quads need work)

**Back pain context:** Lower hip start *feels* comfortable because it reduces shear force on joints, but it's self-defeating for strength development. Address root causes (quad/core strength) instead.
