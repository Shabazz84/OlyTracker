# Powerlifters doing Weightlifting, where to start?

# Analysis: Weightlifting Coaching Transcript

## 1. **Programming Principles**
- **Progression pathway**: Mobility → empty bar movement → positioning → technical cueing → loading
- **Frequency**: High-frequency, low-intensity overhead squats "every time you do squats before or after"
- **Intensity**: Start with empty bar (20-40 kg), avoid aggressive loading during positioning phase
- **Session placement**: Olympic movements after main lifts when "well warmed up but not completely pumped"
- **Duration**: ~15 minutes of barbell movement practice mid-session

## 2. **Technique Cues**
- **Overhead squat**: Full depth, wide grip (outside rings), barefoot initially to identify mobility deficits
- **Front rack position**: Practice holding barbell in jerk grip; address front rack tightness early
- **Jerk positioning**: Introduce strict press (chin level → ~90° elbow flexion) before split jerk progression
- **General cue**: Spend time in positions feeling uncomfortable—normalize novel positions before loading

## 3. **Exercise Recommendations**
- Empty bar snatches & cleans/jerks (mid-session)
- High-frequency overhead squats (very light: 20-40 kg)
- Unweighted squat jumps (low-intensity, separate session)
- Mobility work: hips, ankles, overhead/pulling positions (reference: Squat University, Kelly Starrett)

## 4. **Recovery/Mobility Advice**
- **Mobility prerequisite**: Full-depth overhead squat with barefoot practice
- **Footwear progression**: Transition to weightlifting shoes after establishing positions barefoot
- **Deficit areas likely for powerlifters**: Hip/ankle tightness, overhead position, front rack tightness
- Avoid plyometric intensity early; use low-intensity jumps for neurological adaptation only

## 5. **Relevance to This Athlete**
- ✅ **OHS limiter (50 kg)**: Directly addresses—high-frequency, light overhead squat work is primary intervention
- ✅ **Push jerk only**: Strict press progression recommended before split jerk introduction
- ✅ **Back pain**: Barefoot positioning work + mobility emphasis aligns with conservative approach
- ⚠️ **Night shift (Wed–Sun)**: No specific guidance; mobility work should fit recovery window
- ⚠️ **6-week hypertrophy block stated**: This transcript emphasizes positioning/technique first—may conflict with stated goal sequencing
