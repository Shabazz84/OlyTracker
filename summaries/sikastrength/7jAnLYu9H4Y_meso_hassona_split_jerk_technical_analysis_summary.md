# Analysis: Split Jerk Technical Breakdown

**Relevance to Athlete:** Moderate-High. Athlete currently does push jerk only (no split jerk) and needs jerk progression. This content is directly applicable but requires adaptation for current capability.

---

## 1. **Programming Principles**
- **Jerk as speed/plyometric exercise** — dictated by velocity, not just load
- **Push press**: treat as speed derivative (not max effort). If bar slows significantly, weight is too heavy
- **Front squat emphasis**: Practice 2-3x weekly at similar weights to clean & jerk attempts, moving explosively
- **Frequency**: 2 sessions/week jerk-specific work (via Seek Strength app model)
- **General principle**: "You have to move fast to be fast"

---

## 2. **Technique Cues: Split Jerk**

**Aggression/Extension:**
- Explosive vertical extension in drive phase
- Maximum effort on barbell acceleration (not just positioning)
- Bar should vibrate from speed/aggression in split position

**Hip/Lower Back Control (Critical):**
- **Zero or minimal hip flexion during dip-drive** — hips stay behind/level with heels
- Avoid "buttwink" (lower back tucking): causes forward torso shift → bar drifts forward → loss of power
- Monitor pelvic position side/rear view during splits
- Cue options: "overarch lower back," "maintain bracing while dipping"

**Progression Path (for push jerk → split jerk):**
- Develop front squat strength as prerequisite
- Practice unweighted dips first to assess mobility vs. technical deficit
- Use pause jerks (slow eccentric) to reinforce lower back position
- Address mobility (hamstrings, hip flexors, hip extension) if buttwink appears unweighted

---

## 3. **Exercise Recommendations**

| Exercise | Purpose | Notes |
|----------|---------|-------|
| **Front Squat** | Strength reserve for jerk speed | 2-3x/week; move explosively at jerk-training weights |
| **Push Press** | Jerk speed/extension development | Speed-dictated; drop weight if lockout slows drastically |
| **Pause Jerks** (slow eccentric) | Hip/lower back position work | Use lighter weight; focus on neutral spine control |
| **Unweighted/barbell-only dips** | Mobility assessment + position practice | Before adding load if buttwink issues present |

---

## 4. **Recovery/Mobility Advice**
- **Daily mobility work** (like Miso does): hamstrings, hip flexors, hip extension/flexion
- Options: physio, mobility apps, video programs
- Address mobility *before* heavy split jerk training if baseline mobility deficit exists
- For night-shift worker (Wed–Sun): prioritize consistent mobility timing despite fatigue

---

## 5. **Specific to This Athlete**

| Factor | Consideration |
|--------|---|
| **Back pain history** | Lower back control emphasis is critical; avoid excessive lumbar flexion in dip. Pause jerks may help reinforce neutral spine. |
| **Push jerk only** | Front squat & push press are prerequisite developers before attempting split jerk; need mobility screen first (unweighted dip test). |
| **OHS weakness (50 kg)** | Suggests mobility/position issue (not just strength). Address hamstring/hip mobility before progressing jerk. |
| **Night shift (Wed–Sun)** | Jerk work should cluster early in session; mobility non-negotiable for recovery. |
| **Hypertrophy block (6 weeks)** | Front squat frequency aligns well; push press can be moderate intensity speed work alongside; defer heavy split jerk teaching until strength block. |

---

## **Summary Recommendation**
Delay split jerk intro until strength block. Use hypertrophy block to build front squat base, assess hip/lower back mobility, and reinforce push press speed mechanics. Test unweighted dip position to diagnose mobility vs. technique work needed.
