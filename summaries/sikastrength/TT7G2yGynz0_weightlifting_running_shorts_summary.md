# Weightlifting & Running #shorts

**Relevant to this athlete:**

**Programming/Recovery:**
- Running is contraindicated for amateur weightlifters due to joint stress and interference with lifting sessions
- **Better alternatives:** stationary bike, rowing, stair climber
- Exception: If aerobic conditioning is poor, brief conditioning work *before* starting the hypertrophy block is beneficial

**Practical application for night-shift athlete:**
- Given Wed–Sun schedule and chronic back pain, prioritize low-impact conditioning (bike/rowing) over running
- Any conditioning should support (not compete with) the 6-week hypertrophy block

**Not addressed:** Specific cues, exercise selection, mobility work for OHS limiter or back pain management.
