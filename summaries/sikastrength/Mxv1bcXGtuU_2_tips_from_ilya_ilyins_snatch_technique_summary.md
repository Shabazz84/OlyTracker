# Analysis: Ilia Iliashev Snatch Technique Breakdown

## 1. **Programming Principles**
- Snatch volume: ~30 meaningful reps/week at ≤100% intensity is baseline; can double via pulls
- Pulls programmed multiple times weekly (skill + strength practice)
- Strength foundation: heavy front squats (reference: Ilia at 270kg) + frequent pulls
- Speed work: intentional acceleration required; no variation improves speed without conscious intent

## 2. **Technique Cues (Snatch-Specific)**

**Shoulder-Barbell Relationship (Floor → Hip):**
- Keep shoulders **in front of barbell** throughout pull until explosive position
- At hip contact: shoulders transition **on top of** barbell (covering the bar)
- Knees must clear back just enough to allow barbell runway without blocking path

**Second Pull (Knee → Extension):**
- Initiate speed acceleration **at/above knee** (not from floor, not at last second)
- Speed buildup is gradual; contact point *costs* speed (unavoidable)
- Target: reach minimum "launch velocity" required for load

**Position to Avoid:**
- Knees forward + shoulders back = worst position (bar blocked, pushed away)

## 3. **Exercise Recommendations**
- Heavy front squats (emphasis: leg strength for extension power)
- Pulls (multiple weekly): treat as skill + strength practice, matching snatch reps/weight
- Execute pulls with intentional speed (critical for speed development)

## 5. **Athlete-Specific Application**
**Critical for this athlete:**
- **OHS at 50kg is primary snatch limiter** → back strength/stability deficit suggested; pulls + back work essential before hypertrophy block
- **Chronic back pain** → overhead position weakness likely; emphasize torso stability via pulls & back strength before loading OHS
- **Night shift (Wed–Sun)** → plan heavy squat/pull days around energy peaks
- **Push jerk only** → split jerk work should complement 6-week hypertrophy block before this block
- **102.5kg BW vs. 80kg clean** → suggests proportionally stronger lower body; snatch technique (not just strength) is bottleneck
