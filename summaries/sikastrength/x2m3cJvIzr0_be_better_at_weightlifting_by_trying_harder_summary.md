# Analysis: Weightlifting Coaching Transcript

## 1. **Programming Principles**
- Weight, volume, frequency are controllable variables but **effort quality is equally critical**
- Programming provides structure to train productively, but isn't a substitute for intensity/intent
- Example: 3 sets of 2 reps on snatch at 130 kg (coach's own work)
- Template-based approach acceptable if it enables harder training

## 2. **Technique Cues**
- **Snatch**: Keep chest up from ground and throughout pull (primary example given)
- Cues don't need frequent revision; lifters should retain cues across sessions
- Technical adherence not required at 100% every session; aim for incremental improvement across preceding sessions

## 3. **Recovery/Coaching Philosophy**
- In-person coach's value: accountability/non-verbal feedback (eye contact, silence) when lifter misses expected rep
- Coach enforces *effort standards*, not just technical corrections
- Mental/attitudinal shift matters as much as program changes

## 4. **Relevance to This Athlete**
- **Most relevant**: Chronic back pain + weak OHS (50 kg) = likely posture/chest position issues in snatch pull
- Chest-up cue directly addresses his limiting factor
- Night shift fatigue = effort quality will fluctuate; needs accountability structure
- 6-week hypertrophy block can build postural stability before technical focus

**Key takeaway**: Prioritize intent and posture discipline over volume.
