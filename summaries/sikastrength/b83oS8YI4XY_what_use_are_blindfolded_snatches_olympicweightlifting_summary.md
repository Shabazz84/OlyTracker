# What Use Are Blindfolded Snatches? #olympicweightlifting

**Not directly applicable to this athlete's immediate needs.**

The blindfolded snatch drill is a *proprioceptive tool* for experienced lifters with solid technique. This athlete's primary limiters are:
- **OHS 50 kg** (snatch bottleneck)
- **No split jerk** (incomplete technique)
- **Chronic back pain** (contraindication for proprioceptive experimentation)

**Relevant for 6-week hypertrophy block:**
- Blindfolded work requires established movement patterns; better to build strength/stability first via conventional work
- Night shift worker needs predictable, recoverable programming—novelty drills add fatigue management complexity

**Better priority:** OHS strength work, split jerk introduction, back-friendly positioning cues before exploring proprioceptive drills.
