# Stop Making These Snatch Technique Mistakes!

# Weightlifting Coaching Analysis

## 1. **Programming Principles**
- **Tempo/rhythm concept**: "Two-beat rhythm" — first pull fast, second pull *faster*. Emphasizes acceleration through the lift, not maximal effort off the floor.
- **Practice-based fixes**: Arm bend issues resolve only through repetition of *correct* reps (slow pull snatches, pause reps) — no mobility/strength shortcut.
- **Sequential problem-solving**: Fix issues in order of causation; early fixes may eliminate downstream problems, reducing total intervention points.

---

## 2. **Technique Cues for Snatch**

| **Problem** | **Cue/Fix** |
|---|---|
| **Shoulders behind barbell** | "Keep shoulders over barbell off floor" OR "pull barbell back toward you" (barbell converges to hip, not vertical path). |
| **Barbell drifts forward** | Start position: barbell over base of big toe; hips higher (hamstrings ~parallel, taller athletes slightly higher). |
| **Early hip rise / knee slide forward** | Hips too low at start → knees travel too far forward → barbell forced forward. Raise hips; reduce knee bend angle. |
| **Arm bend at hip** | Actively practice reps *without* arm bend; arms stay straight until turnover (traps pull → arms follow). |
| **Excessive jump back** | Patience with hips; extend second pull as long as possible before hip contact. Keep shoulders in front longer. |
| **Too-fast pull-off floor** | Pull smoothly off floor to allow acceleration *into* the knee and hip. Aggressive floor pull loses back/leg position and limits speed capacity. |
| **Big barbell swing** | Reduces margin for error; creates inefficiency (longer path if drawn straight). Stricter bar path = more consistency. |

---

## 3. **Exercise Recommendations**
- **Slow pull snatches** — fix arm bend
- **Pause reps** — reinforce correct positions without momentum
