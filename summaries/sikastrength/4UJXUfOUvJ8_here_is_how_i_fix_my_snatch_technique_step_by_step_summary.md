# Weightlifting Coaching Analysis

## 1. Programming Principles
- **Loading strategy**: Heavy day (100% intensity, 135kg snatch) followed by lower weight/higher volume day (110kg) in weekly split
- **Volume progression**: Volume stays high across weeks; weight increases weekly
- **Exercise sequencing**: Technical work → pulls (for position reinforcement & extra reps)

## 2. Technique Cues (Snatch-Specific)
- **Primary issue**: Shoulders pulling forward off floor → loss of extension power + unstable catch
- **Correction**: Pull shoulders back; adjust dynamics so chest/shoulders sit correctly over bar
- **Setup approach**: Start from light weights; progress slowly into start position to focus on untrained shoulder-back position
- **Progression pace**: Acknowledge long-term refinement (training since March)

## 3. Exercise Recommendations
- **Snatch pulls**: High priority for reinforcing positions, strengthening technical weak points, accumulating extra reps
- Progressive loading from light → heavy within session
