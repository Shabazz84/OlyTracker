# Lu Xiaojun 180kg Snatch Analysis #olympicweightlifting

**RELEVANT TO THIS ATHLETE:**

**Technique Cue - Snatch First Pull:**
- At knee position: maintain shin angle perpendicular to floor with shoulders positioned *in front* of the bar
- This ensures correct bar path (traveling back/sweeping toward you), converging toward center of mass for optimal power expression
- Critical feedback for this athlete since OHS (50 kg) is primary snatch limiter—efficient first pull mechanics reduce reliance on overhead strength

**Application:** Use this knee-position checkpoint during snatch technique work to diagnose bar path issues before investing hypertrophy work.
