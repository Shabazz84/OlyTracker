## 2. Technique Cues (Snatch-Focused)
- **Back arch**: Maintain excellent arch throughout pull → setup → extension → catch
- **Extension**: Aim for "super straight extension" — keeps bar closer to body, reduces travel distance, faster into overhead position
- **Rep quality**: Second rep often better than first; seek one "perfect feeling snatch," then 1-2 confirmatory sets
- **Overhead position**: Primary limiter (athlete notes hips feel tight but aren't; actually shoulder/thoracic mobility issue)
- **Philosophy**: "Perfect technique is the answer" — 7-10 years + experienced coach needed; technical model dying out

## 3. Exercise Recommendations
- **Upper body superset work**: Deficit rows + overhead press; barbell rows + strict press (tempo-controlled)
- **Accessory**: Single-arm dumbbell rows + suitcase side bends (targets grip, obliques, thoracic mobility)
- **Track work**: Deliberate speed practice (60-70% effort, 8-10 x ~60m with 1.5 min rest), three-point start focus; treats spikes/track sprinting as new skill
