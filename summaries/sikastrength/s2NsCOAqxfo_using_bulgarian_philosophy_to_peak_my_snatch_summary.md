## 1. **Programming Principles**
- **Hyperspecific peaking phase**: Heavy singles only in snatch for several weeks (not entry-level)
- **Prerequisites**: Requires substantial prep work, variation, volume-building phases before entering
- **Intensity management**: Minimum 135 kg, target 140+ kg; adjusts expectations session-to-session based on bar feel
- **Duration**: Short (can't sustain long); followed by reset and rebuild
- **Requirements**: Significant lifter experience + sophisticated programming knowledge needed

**⚠️ NOT suitable for this athlete's current stage** (Clean 80 kg; needs technique/OHS work first)

---

## 2. **Technique Cues**
- **Arm tension**: Keep arms **relaxed** during aggressive dynamic start (tension slows bar, disrupts timing, compromises turnover)
- **Second pull**: Emphasize **fast second pull**
- **Timing**: Fine-tune chest position and extension sequencing
- **Bar feel assessment**: Gauge each session's "interest of the barbell"—controls attempt selection

---

## 3. **Exercise Recommendations**
- **Back Squat variation**: Coach uses 230–240 kg triples for maintenance
- **Soft tissue work**: Primary recovery tool for joint tightness (knee flare-up management)

- Extensive soft tissue work + load reduction prevented chronic knee issue worsening
