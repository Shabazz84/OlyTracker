# Post-Records Workout: Kristina and Weightlifting

# MERGED SUMMARY: Russian Weightlifting Coaching Session

## Key Points

- **Frequency progression model**: Begin 3 sessions/week → incrementally add sessions per cycle → target 5–6 short, focused sessions/week for adaptation
- **8-week training cycles** with averaging protocols for working athletes
- **High intensity prioritized over 75% intensity sessions**: Coach believes higher loads develop faster adaptation; risk managed via tendon monitoring and technique fidelity
- **Bulgarian model validation**: Accumulated volume across frequent sessions (short, single-exercise workouts) safer and more effective than single high-volume sessions
- **Sport-specific warm-up essential**: Rowing (500m free + 25m sprints) superior to general cardio for lat/back activation
- **Tendon adaptation principle**: High frequency safer than chronic low-intensity inflammation; vertical mechanics reduce injury risk

---

## Technique Cues

**Snatch / Clean Pull from Blocks:**
- Vertical path emphasis; no forward lean during extension
- Cue: "Vertical stance, don't lean the body forward"

**Front Squat (Olympic vs. Powerlifting):**
- Olympic preference: knees first (not hips back)
- Bar on traps → forward torso angle
- Sequence: Angle *then* knee bend (not simultaneous)
- Aligns receiving position with pulling mechanics

**Split Jerk:**
- "Turn feet fast, don't fear the weight"
- Eyes open during foot split (closing eyes blocks muscle contraction & creates psychological block)
- Feet forward → acceptable forward bail
- Adductor fatigue normal post-split work; resolves with repetition

**General Principle:**
- Maintain vertical extension under load across all positions
- Pulling angles must match squat/receiving positions to prevent tendon stress

## Programming Principles

| Element | Application |
|---------|-------------|
| **Session structure** | Heavy lift + accessory + recovery between exercises |
| **Squat-to-pull ratio** | Heavy squats → lighter pulls (faster recovery from squats) |
| **Belt usage** | Only if core weaker than legs; start at 80% of max |
| **Accessory selection** | Front Squat (primary), Bulgarian Split Squats (2×9 @ 30kg each leg), Romanian Deadlifts (DB at pull angle), Rip from blocks |
| **Volume progression** | Add sessions, not load jumps; individualize weekly by feel |
| **Tendon monitoring** | Frequent hard work safer than prolonged moderate-intensity sessions |

## Athlete Relevance

| Athlete Factor | Coaching Solution |
|---|---|
| **Night shift (Wed–Sun)** | Program uses averaging; adjust weekly volume by RPE/fatigue signals |
| **Chronic back pain** | Olympic squat form (vertical torso) preferred; heavy squats strengthen posterior chain; avoid over-bracing |
| **OHS 50kg (limiter)** | Address via Front Squat + Snatch Pull work; mobility not explicitly prioritized—may need supplemental shoulder/thoracic work |
| **Push jerk only (no split)** | Split jerk technique cued via eye-open cue + frequent rep exposure; coach expects athlete to overcome fear |
| **6-week hypertrophy block goal** | Program uses higher-rep accessories (Bulgarian 2×9, RDLs) + heavy squats + frequent sessions = volume + strength stimulus |
| **Back Squat 118kg vs. Clean 80kg gap** | Suggests weak pulling/rack position; Snatch Pull + Clean Pull work needed but underspecified in source |

**Recommendation for this athlete**: Prioritize split jerk exposure (3–4 reps × 3–4 sets, 2–3x/week) and pulling volume to close the clean/squat ratio gap before hypertrophy block begins.
