# This is Vital To A Good Power Clean #trackandfield

**ANALYSIS:**

**2. Technique Cues (Snatch/Clean/Jerk):**
- **Hang Power Clean focus:** Upper back extension + thoracic extension + lower back extension are foundational
- **Shoulder positioning:** Set shoulders rigidly BEFORE pulling begins—avoid forward movement or vertical raising of shoulders at initiation
- **Rigid upper back position** enables:
  - Better lower body utilization
  - Stronger overall body tension
  - Faster bar acceleration
  - Heavier loads moved faster

**3. Exercise Recommendations:**
- Hang power clean emphasized as tool for upper back extension work

**4. Recovery/Mobility:**
- None mentioned

**5. Athlete-Specific Relevance:**
- **CRITICAL FOR THIS ATHLETE:** Upper back/thoracic extension directly addresses his snatch limiter (OHS 50 kg). Poor thoracic mobility restricts overhead position and snatch lockout capacity
- **Back pain consideration:** Rigid upper back work must be balanced against chronic back pain; lower back extension should be monitored carefully during hypertrophy block
- **Recommendation:** Prioritize hang power clean variations and thoracic mobility work (coachies, banded shoulder dislocates) to build extension strength while managing lumbar strain
