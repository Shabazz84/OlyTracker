# TYR L1 Weightlifting Shoe Review

**Not about weightlifting coaching or athlete analysis.**

This is a product review of Tier L1 weightlifting shoes. While it mentions weightlifting contexts (snatch, clean & jerk, squat), it contains no coaching principles, programming, technique cues, or personalized athlete advice relevant to the intermediate lifter profile provided.

**Potentially useful detail for the athlete:** The reviewers note that ~80% of lifters benefit from *higher* heel heights when transitioning shoes, while ~20% (like those moving from Reebok Legacies/Nike Romaleos) might suit lower heels. The Tier L1 has a ~¾" heel—potentially relevant if this athlete needs heel height optimization for back pain or dorsiflexion limitations, but this requires separate assessment.
