# Analysis: Ilia Alenov Clean Technical Breakdown

## Programming Principles
- **Strength focus**: Back squat prioritized over front squat for intermediate lifters (more closely linked to clean ability than front squat)
- **Concept over ratios**: Assess if leg strength "feels enough" contextually rather than chasing specific numbers
- **Plyometrics**: Minimal necessity for intermediate athletes; snatch/clean practice with strength focus trains explosiveness adequately. Use sparingly (depth jumps) to avoid excessive fatigue
- **Practice structure**: Deliberate, intelligent technical work > variations. Perfect positioning reps before adding load

## Technique Cues: Clean

**Two-beat rhythm (Fast → Faster)**
- First pull: Aggressively fast off floor (faster than snatch), but NOT max velocity
- Second pull: Deliberately accelerate HARDER into extension/contact point to overcome natural barbell deceleration
- Rationale: Heavier weights + shorter barbell path = naturally slow down; speed in second pull counteracts this

**Avoid Over-pulling**
- No extended hip opening; minimize horizontal hip distance from start → extension
- Reason: Over-extension = barbell drifts away + inefficient hip retreat to catch position = timing issues
- Cue: "Enough extension is enough" — full extension unnecessary; prioritize getting under fast
- Result: No barbell crash, efficient catch near quarter squat

## Exercise Recommendations
- **No-contact cleans**: 50–60% load, warm-ups only; reinforces pull-under timing without overextension
- **Hand cleans**: High risk of technical degradation (over-pulling, arm-pulling); only if perfect technique maintained
- **Back squat work**: Critical leg strength; front squats secondary

## Relevance to This Athlete
- **Back pain + push jerk limitation**: Clean speed work (aggressive first pull) demands core stability; over-extension likely exacerbates chronic pain. Cue restraint in hip opening.
- **OHS 50 kg limiter**: Poor extension mechanics + over-pulling directly impair overhead stability. Focus on controlled, efficient extension angles.
- **Night shift**: Recovery-demanding programming (plyometrics minimal, back squat priority) suits fatigue constraints better than Bulgarian model.
- **Clean 80 kg vs BS 118 kg**: Leg strength adequate; technical refinement (two-beat rhythm + no over-pull) likely yield immediate gains.
