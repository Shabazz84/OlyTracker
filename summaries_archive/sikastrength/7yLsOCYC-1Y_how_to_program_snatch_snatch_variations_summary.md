# How To Program Snatch & Snatch Variations

# Analysis: Weightlifting Programming & Periodization Transcript

## 1. PROGRAMMING PRINCIPLES
**Frequency & Duration:**
- Target: 3-4 quality sessions/week (not 6-7+)
- Block length: 12-14 weeks maximum (plan around life constraints)
- Quality over quantity—one consistent 12-week block beats sporadic high-frequency training
- Program around known disruptions (holidays, shift work, travel)

**Loading Structure:**
- Start blocks at 65-70% (very light)
- Progress via weight increments (1-3 kg jumps), not volume increases
- Keep volume bands consistent across blocks (e.g., 5×3 → 5×3 → 4×3 → doubles)
- Heavy work (90%+) is mandatory for 1RM progress; accumulate reps here
- Typical progression: 5×3 (70%) → 5×3 (73%) → 4×3 (80%) → 5×2 (80%) → 5×2 (83%) → heavy single (90%+) → max attempt week 14

**Key Metric for Lifts:**
- Snatch triple = ~15kg above best snatch
- Clean/jerk triple = ~20kg above best C&J
- Heavy doubles: snatch +10kg, C&J +15-20kg

---

## 2. TECHNIQUE CUES
- **Snatch pull focus:** If second pull is slow → use block snatches
- **Knee position:** If knees too far forward → pause/knee snatches
- **Extension:** If insufficient → snatch high pull + snatch complex
- Avoid heavy singles/doubles on variations (keep light)
- Selection principle: variations solve technical issues, not become standalone goals

---

## 3. EXERCISE RECOMMENDATIONS
- **Structure:** 2 snatch sessions/week + 1 full C&J session + 1 variation work
- One session snatch (full), one snatch + hang/block variation
- Variations must support the main lift; don't let variation maxes exceed floor maxes
- Drop variations if not addressing the technical issue after 4-6 weeks

---

## 4. RECOVERY & LIFE INTEGRATION
- **Shift work consideration:** Plan blocks when you can guarantee 12+ uninterrupted weeks (night shift Wed–Sun requires careful planning)
- December ≠ block start; plan around holidays/obligations
- Don't sacrifice life quality for small training gains; year-on-year consistency matters more
- Accept disruptions (illness, travel) as normal; focus on stringing together multiple blocks over years, not perfection within one block

---

## 5. RELEVANCE TO THIS ATHLETE

| Factor | Application |
|--------|-------------|
| **OHS 50kg (snatch limiter)** | Build with snatch variations addressing technical deficit; 6-week hypertrophy block helps (posterior chain, core stability for overhead) |
| **Push jerk only** | Clean strength adequate (80kg) for intermediate; jerk block should address split mechanics if competing |
| **Chronic back pain** | Start block at 60-65% (not 70%), prioritize movement quality over load; avoid high-fatigue sessions; consider pause/tempo work |
| **Night shift (Wed–Sun)** | Pick a 12-14 week block avoiding major holidays; expect 3-4 sessions/week realistic; plan around fatigue windows |
| **BSq 118kg vs. Snatch 80kg** | Squat capacity sufficient; OHS (50kg) is true bottleneck—prioritize overhead positioning & thoracic mobility |

**Actionable:** Start hypertrophy block at 65-70%, reset to 67-70 mid-block, use snatch variations that address OHS deficit (pause snatches, tall snatches, OHS drives).
