# When To Make Changes To Your Weightlifting Program

# Analysis: Seek Strength Coaching Transcript

## 1. Programming Principles
- **Periodization structure**: Offseason → Prep Phase → Main Training Phase → Peak (4-week taper)
- **Offseason**: GPP focus, work capacity, lean tissue gain, address weak points (e.g., strict press, back squat)
- **Prep Phase**: Increase snatch/clean/jerk volume; build work capacity across lifts with shorter rest; "earn the right" to train heavy
- **Main Training Phase**: Triples/doubles/singles progression; refine technique; most flexible for adjustments
- **Peak Phase** (final 4-6 weeks): Sensitive period; minimize major changes; converge technical focus
- **Key principle**: Dynamic programming allows variation adjustments, but timing and context matter critically

## 2. Technique Cues
- Gabriel Syranyan example: ingrain technique so deeply it becomes automatic (e.g., aggressive bar pull from floor)
- Small cues are valuable throughout career; major technique shifts risk acute injury and disrupt timing
- Cuing strategy near peak: use verbal/visual/kinesthetic cues; defer heavy corrections to next strength phase

## 3. Exercise Recommendations
- **Low-risk swaps** (any block): assistance exercise substitutions (dumbbell vs. barbell press, dumbbell vs. seal rows)
- **Mid-block swaps** (weeks 1-6): variation changes acceptable if attributes/loading remain similar (e.g., low-hang to low-block snatch early)
- **High-risk swaps** (weeks 10+ of 12): avoid variation changes with different eccentric load or timing
- Recommendation: defer major changes to next block if near peak

## 5. Athlete-Specific Relevance
**Critical for this athlete:**
- **Chronic back pain + OHS limiter (50 kg)**: Offseason/prep phase ideal for addressing posterior chain weakness; avoid unnecessary variation changes that irritate back (e.g., premature low-block snatch switches)
- **Night shift (Wed–Sun)**: Plan work capacity work during offseason; manage fatigue accumulation near peak
- **Push jerk only**: Strength phase (post–6-week hypertrophy block) should include aggressive dumbbell/machine pressing to build overhead stability before split jerk introduction
