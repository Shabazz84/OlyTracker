# Snatch - Stabilize in the Bottom

# Analysis for This Athlete

## Technique Cues (Snatch)
- **Full squat depth is critical** for snatch stability overhead—partial depth increases horizontal knee/hip motion, amplified in overhead position
- **Lock overhead position aggressively** once in bottom position
- **Relax legs in bottom**—don't actively hold yourself up; sit as low as mobility allows rather than staying high

## Directly Relevant to This Athlete
**OHS at 50 kg is primary snatch limiter.** This cue addresses a likely root cause:
- If athlete lacks OHS mobility to sit fully, they're compensating by staying high → unstable overhead → depressed snatch numbers
- **Action**: Prioritize OHS mobility/strength work in hypertrophy block. Test if aggression + relaxation in bottom improves stability without needing to add load initially

## Recovery Note
- Given **chronic back pain**: full OHS depth requires thoracic mobility + core stability. Pair this with anti-rotation/bracing work during hypertrophy block
- Night shift (Wed–Sun) complicates recovery—ensure depth work doesn't aggravate back; consider eccentric OHS emphasis on days with better sleep

**Core insight**: The 30 kg gap between Clean (80) and OHS (50) suggests technique/stability, not strength. This snatch-position guidance directly addresses that.
