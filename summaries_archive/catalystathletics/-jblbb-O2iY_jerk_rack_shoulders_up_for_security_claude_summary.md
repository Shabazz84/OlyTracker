# Weightlifting Analysis: Jerk Rack Position

## Technique Cues (Jerk)

**Rack Position Clarification:**
- Shoulders: protract (push forward) + slightly elevate to block forward bar motion
- Bar placement: behind the highest point of the upward curve of collar bones/sternum (non-negotiable)
- Purpose of shoulder elevation: adds stability/protection against forward bar drift—NOT to change bar position
- Common error: misinterpreting "up" as changing bar placement (it doesn't)

## Relevance to This Athlete

**Direct application:** Athlete uses push jerk only (no split jerk). This rack position clarity is foundational for consistent jerk setup. Given chronic back pain, solid rack positioning reduces spinal stress during jerk dips and drives.

**Note:** No programming, mobility, or recovery content in this extract.

---
**Recommendation:** Apply this rack position cue to strengthen jerk consistency before split jerk introduction (if pursued).
