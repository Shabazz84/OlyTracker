# Bar Position for the Jerk Rack

**1. Programming principles:** None mentioned.

**2. Technique cues for jerk:**
- Bar position in rack: light contact with throat, behind collar bone curves, behind highest point of shoulders.
- Relevant to athlete: Critical for push jerk mechanics; proper rack position may help address chronic back pain by improving stability.

**3. Exercise recommendations:** None mentioned.

**4. Recovery/mobility:** None mentioned.

**5. Athlete-specific relevance:**
- Directly applicable: Athlete only performs push jerk (no split jerk). Secure rack position is foundational for power transfer and reducing unnecessary spinal stress given chronic back pain history.
