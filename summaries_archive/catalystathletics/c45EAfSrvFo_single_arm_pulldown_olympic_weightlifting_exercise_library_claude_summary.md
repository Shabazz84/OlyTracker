# Analysis: Single-Arm Cable Pull (Overhead)

**Exercise Recommendation:**
- Single-arm cable shoulder pull with emphasis on scapular retraction (shoulder blade down/back)
- Neutral spine maintenance throughout

**Relevant to Athlete:**
- **Back pain consideration**: Unilateral loading requires robust anti-rotation core stability. Given chronic back pain, needs careful progression and core bracing cue emphasis.
- **OHS limiter (50 kg)**: This addresses shoulder blade positioning/strength, which directly supports overhead stability in snatches and jerks.
- **Technique cue**: "Shoulder blade down and back forcefully" is relevant for OHS stability and jerk lockout positioning.

**Programming note:** No sets/reps/intensity specified in text. For hypertrophy block, suggest 3–4 sets × 8–12 reps, controlled tempo (2-sec pull, 2-sec return). Unilateral work fits well as accessory; monitor for asymmetrical loading effects with existing back pain.
