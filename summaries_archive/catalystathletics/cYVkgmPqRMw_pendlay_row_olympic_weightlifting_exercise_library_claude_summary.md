# Pendlay Row | Olympic Weightlifting Exercise Library

**Relevant Content:**

1. **Exercise Recommendation:**
   - **Penley Row**: Bent row variation emphasizing upper back flexion/extension
   - Clean-width grip, trunk braced (floor-pull position), hinge forward with slight knee bend to ~horizontal
   - Allow upper back to soften (flexion) lowering bar to floor; extend upper back pulling to abdomen with scapular retraction
   - Full ROM each rep (floor contact)

2. **Relevance to Athlete:**
   - **Strong fit for chronic back pain + OHS limiter**: Upper back mobility/extension work addresses thoracic stiffness that restricts overhead position
   - Scapular retraction reinforces pulling mechanics (clean/snatch)
   - Controlled flexion under load can build resilience if pain-free
   - **Caution**: Night shift may affect recovery; monitor fatigue before adding volume

3. **Programming Gap:**
   - No sets/reps/intensity/frequency specified in text
   - **Suggestion for context**: Likely accessory work (3–4 sets × 6–8 reps) in hypertrophy block; pairs well with snatch pulls or overhead work

**Bottom line:** Penley rows are well-suited to this athlete's OHS limitation and back issues—add as upper back/mobility accessory, but monitor load tolerance given chronic pain.
