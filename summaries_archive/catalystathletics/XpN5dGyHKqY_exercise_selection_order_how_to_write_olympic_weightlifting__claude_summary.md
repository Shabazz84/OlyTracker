# Weightlifting Analysis: Program Design & Exercise Selection

## 1. Programming Principles
- **Early cycle (hypertrophy block)**: High volume, high exercise variety; progress to lower variation/fewer exercises as cycle advances
- **Typical 5-day structure**: Mon (snatch/pull/squat), Tue (jerk/snatch technique/overhead), Wed (clean/pull/squat), Fri (heavy total/squat), Sat (technique/overhead)
- **Volume distribution**: Less clean volume than snatch (clean more taxing); spread exposure evenly across week for skill & balanced physical stress
- **General rule**: Group competition lift exercises with matching pull type (e.g., snatch pulls with snatch sessions)
- **Adjustable to 4 or 3 days** by dropping/consolidating sessions; maintain lift frequency when possible

## 2. Technique Cues
- **Staying over the bar/balance in pull**: Halting deadlifts, pause pulls (floor to knee), segment complexes, slow pull snatches
- **Jerk lockout issues**: Jerk behind neck ± regular jerk complex with 3-sec receiving holds; overhead carries
- **Clean finish/turnover**: Power cleans, explosive pulls
- **Dip & drive**: Power jerk work; vertical dip emphasis

## 3. Exercise Recommendations (Key Selections)
- **For OHS limiter (50 kg)**: Snatch balance + overhead squat complexes, snatch push press + OHS, slow pull snatches
- **Squat variety**: 2× back squat (1 high-rep/low-intensity with eccentric/pause work; 1 heavy), 1× front squat (pause all reps for mobility/control)
- **Early cycle emphasis**: Pauses, holds, tempo work to reinforce positions
- **Clean vs. Clean+Jerk**: Separate days early if jerk lags; clean+jerk dip squat drills to work jerk without full lockout demand

## 4. Recovery/Mobility
- **Pause squats** (esp. front squat) for mobility & postural control
- No specific recovery guidance given beyond exercise selection for fatigue management
- **Implication for chronic back pain**: Emphasis on tempo work, pauses, position control early in cycle

## 5. Athlete-Specific Relevance

| Factor | Action |
|--------|--------|
| **OHS weakness (50 kg)** | Prioritize snatch overhead work: snatch push press, snatch balance, OHS complexes; progress through cycle |
| **Push jerk only** | Focus Tuesday/Saturday jerk work on dip strength, vertical drive, lockout via behind-neck jerks + holds |
| **Squat strength adequate (118 kg)** | Can reduce squat volume slightly; prioritize snatch/clean technical work instead |
| **Chronic back pain** | High emphasis on pausing/tempo work early in cycle is appropriate; avoid aggressive loading early |
| **Night shift (Wed–Sun)** | Must schedule recovery strategically; Wed session may need lower intensity given Tue–Wed overlap |
| **6-week hypertrophy block** | Use described high-volume, high-variety approach with pauses/holds; defer heavy singles |

**Key:** Address OHS and split jerk development explicitly via dedicated overhead/jerk exercise selection before generic volume increases.
