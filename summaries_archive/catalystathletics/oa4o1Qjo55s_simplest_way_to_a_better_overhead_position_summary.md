# Simplest Way to a Better Overhead Position

1. **Programming principles**: Use snatch push presses as warm-up drills (low intensity, high frequency) to reinforce overhead stability; no specific sets/reps provided for the main block.
2. **Technique cues**: Squeeze upper inside edges of shoulder blades together; keep head pushed forward; drive bar straight up without moving head/trunk; imagine supporting weight with upper back by locking shoulder blades down.
3. **Exercise recommendations**: Snatch push press (for actual snatches, power snatches, or muscle snatches).
4. **Recovery or mobility advice**: None mentioned in this excerpt.
5. **Profile relevance**: The "lock" cue for the overhead position directly addresses the athlete's primary limiter (OHS strength) and chronic back pain by emphasizing a stable upper-back base to reduce lumbar strain during overhead holds.
