# Neutral-Grip Low Cable Row | Olympic Weightlifting Exercise Library

**Exercise Recommendation:**
- **Seated Cable Row** (neutral grip): Core-bracing row variant emphasizing scapular retraction/protraction control. Useful for back strength with minimal spinal loading.

**Relevance to Athlete:**
- **Directly applicable** — chronic back pain makes this a safer rowing option vs. bent-over rows. Seated position eliminates shear stress on lumbar spine while building back/scapular stability needed for overhead stability (OHS is primary snatch limiter).
- Fits hypertrophy block programming (moderate rep ranges, controlled eccentrics).

**Cue Summary:**
- Brace trunk, minimal back/hip motion
- Retract scapulae forcefully
- Control eccentric (protraction phase)

**Note:** No periodization/loading details given; coach should specify sets/reps for 6-week hypertrophy block (likely 3×8–12 or 4×6–8).
