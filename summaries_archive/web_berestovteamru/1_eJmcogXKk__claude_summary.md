**RELEVANT EXTRACTS FOR THIS ATHLETE:**

**1. Programming Principles**
- Snatch/clean on discs: Use lighter weights (40-50 kg), NOT near max effort
- Progression: Jump on discs → Jump + bar → Snatch/clean on discs (full movement)
- Positioning: Slightly wider than shoulder-width stance; focus on technical execution over stance width variations

**2. Technique Cues**
- **Snatch on discs (above-knee pull):**
  - Powerful leg drive + back extension to full hip extension
  - Land on *straight legs* (not "tucking" knees early)
  - Common error: Athletes reduce knee extension mid-pull and "collapse" onto discs instead of jumping
  - Fixative: Practice jumping onto discs with straight legs first (no bar), then add barbell

- **Clean on discs (similar progression):**
  - Pull from above-knee position
  - Powerful leg extension → fast knee flexion transition
  - Land on straight legs before receiving position
  - Reinforces: Explosive finish + fast turnover under bar

**3. Exercise Recommendations**
- **Snatch/clean on discs ladder:** Progress disc height incrementally; forces harder leg drive each level
- Use straps for disc pulls (safer, cleaner feedback)
- Can perform in "quarter squat" or full squat catch depending on goal
