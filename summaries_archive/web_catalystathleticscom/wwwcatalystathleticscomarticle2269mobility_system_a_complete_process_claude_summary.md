# Analysis: Mobility System: A Complete Process by Greg Everett

## 1. **Programming Principles**
- Mobility is systemic, not single-solution; requires consistent multi-element approach
- Frequency: Daily integration across morning, pre-training, training, post-training, and pre-bed windows
- Varies by individual need and changes over time

## 2. **Technique Cues**
None provided in this text.

## 3. **Exercise Recommendations**

| Timing | Work |
|--------|------|
| **Morning** | Arm circles, leg swings, trunk rotations, flow sequences |
| **Pre-Training** | Soft tissue (foam roll/ball work), dynamic ROM, prep movements, static stretches (shoulders) |
| **During Training** | Full ROM lifting; static stretches between sets on priority areas; avoid stretching muscles being used |
| **Post-Training** | Flow work (cooldown), then aggressive static-passive stretching |
| **Pre-Bed** | Light foam rolling, flow, static stretching |

## 4. **Recovery & Mobility Advice**
- Static passive stretching works; misconception it's "only" method
- Post-training is best time for aggressive stretching (warm, baseline established)
- Between-set stretching efficient for priority/limiting areas
- Address stress reduction alongside mobility work
- Mobility work ineffective if fixated on single "cure"

## 5. **Relevance to This Athlete**

**Highly applicable:**
- **Chronic back pain**: Systematic soft tissue + dynamic + static approach needed; not just one stretch
- **OHS limiter (50 kg)**: Mobility-integrated training critical; between-set stretching on shoulder/thoracic mobility during snatch work
- **Night shift (Wed–Sun)**: Morning mobility routine helps after poor sleep/shortened muscles
- **Hypertrophy block**: Full ROM training during sets preserves/builds mobility long-term

**Actionable:** Implement complete system with emphasis on thoracic/shoulder mobility and posterior chain to address back pain and OHS deficit.
