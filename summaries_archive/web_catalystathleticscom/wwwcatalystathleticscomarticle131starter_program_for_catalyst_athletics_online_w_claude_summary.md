# Merged Summary: Olympic Weightlifting Starter Program for Intermediate Athlete

## Key Points

- **Program structure**: 4-week introductory block (volume weeks 1–2, intensity weeks 3–4), then transition week or new cycle
- **Frequency**: 4 days/week; flexible scheduling (Mon/Wed/Thu/Sat standard, but Mon/Tue/Thu/Fri viable if recovery managed)
- **Load selection**: Weight-by-feel (no percentages); same weight across all sets per exercise; increase weekly as technique permits
- **Rest periods**: 2–3 min between Olympic lifts; 3–5 min between squats/pulls; complete reset between reps (no touch-and-go)
- **Session duration**: 1–2 hours
- **Periodization**: Can repeat 4-week block before advancing to classic/rep cycles

---

## Technique Cues

**Receiving positions:**
- Receive bar at its highest point; pull down under the bar rather than catching high in power position
- Full squat version mandatory for snatch/clean (unless power variant specified); ride high catches to bottom for stability
- Overhead squat: High turnover and good arm position before full-depth squat; if arms bend or chest folds → mobility/mechanics issue, not inflexibility

**Execution standards:**
- Reset completely between reps; stop and set before each rep (applies to snatches, cleans, jerks)
- Pulls: Abbreviated versions emphasizing hip extension and posterior chain; distinct from high pulls (continued upward momentum)
- Jerk: Split jerk is standard; push jerk acceptable as variant but split jerk required for competitive totals
- Drop bar from top acceptable for snatch/clean/jerk; control descent for pulls/deadlifts
- Avoid heavy pulls that compromise posture/balance/speed

---

## Programming Principles

**Weekly structure example:**
- **Monday**: Clean & Jerk, Clean Pull, Back Squat
- **Wednesday**: Snatch, Snatch Pull, Front Squat
- **Thursday**: Power Snatch, Power C&J, Overhead Squat (lighter/recovery day)
- **Saturday**: Heavy singles—Snatch, C&J, Front Squat

**Rep/intensity progression:**
- Weeks 1–2: 3–5 rep sets (volume emphasis)
- Weeks 3–4: Singles emphasis (heaviest for day; max 3 misses per weight)

**Accessory & supplemental work** (3–4 sets, 8–12 reps; add after main work or on lower-volume days):
- **Daily**: Ab work + lower back (extensions, hyperextensions)
- **Upper body** (Tue/Thu): Bench, rows, pullovers, weighted dips, pull-ups
- **Lower body hypertrophy**: SLDL, good mornings, weighted lunges (5–8 reps max), RDL variants, extra squat sets (8–10 reps), reverse hypers, physio ball curls
- **Core**: Rotate heavy back work (SLDL/RDL/good mornings), light back work (extensions), weighted variations (sit-ups, crunches, planks, weighted core)
- **Conditioning**: Optional 2x/week maximum; ≤5 min; avoid leg-intensive work; rowing acceptable (short duration); upper-body/pulling emphasis only
- **Shoulder stability/mobility**: 3x/week post-workout (external rotation work, dynamic/static stretching)

**Key programming notes:**
- Squat every snatch/clean rep for positioning and tempo
- Front squat 2x/week to build quad/trunk strength; can substitute cleans into rack if no squat rack
- OHS prioritized over split-jerk work for positional improvement; snatch grip split push press (behind neck) suggested for balanced split development
- Clean pulls based on clean max (not C&J max); snatch pulls based on snatch max
- Don't combine with CrossFit metcons or other demanding programs
- Transition week after 4-week block: repeat week 1 easy or take recovery week if fatigued

## Athlete Relevance

| Factor | Program Fit | Action Items |
|--------|-------------|--------------|
| **Chronic back pain** | ⚠️ Caution | Heavy posterior chain work (SLDL, good mornings, RDLs) may aggravate. Prioritize light back extensions/hyperextensions; monitor squat form closely; start weights causing *zero* pain, progress conservatively by feel. Use belt only if necessary. Distinguish training soreness from injury; consult medical professional if persistent. |
| **OHS 50 kg (snatch limiter)** | ✅ Directly addressed | 3–5 OHS sessions/week built into program; high-volume front squat (2x/week) + overhead work will improve overhead strength. | **Push jerk only (no split)** | ⚠️ Limitation | Program permits power jerk early; substitute push jerk as needed.
