# Analysis: Competition Lift Variation Ratios

## Relevant to This Athlete

**1. Programming Principles**
- Hang/block lifts typically should be lighter than full lifts from floor
- Exception: If a variation exceeds full lift weight, it signals a technical problem in the pull phase (positioning, postural weakness, speed/rhythm)
- Keep effective variations in program even if ratios are atypical—supports confidence and enjoyment
- Use variation strength disparities diagnostically to address root issues

**2. Technique Cues**
- **For this athlete (OHS 50 kg limiting snatch):** Problems in floor pull → blocks/hangs may show better technique. His low OHS suggests mobility/stability issues, but pull mechanics also matter.
- Poor positioning, inconsistent setup, or weak early pull are common culprits when partials exceed fulls

**3. Exercise Recommendations**
- Add **pull or deadlift variations** to address floor pull weaknesses
- Use **snatch/clean complexes with pulls before the lift**
- Implement **floor pull technique primers**
- Keep the athlete's strongest variation in rotation for confidence/enjoyment

**4. Recovery/Mobility**
- Not covered

## Key Insight for Profile
Given his chronic back pain + weak OHS (50 kg) + early-lift issues likely present, diagnostic block work could identify whether his limiting factor is pull mechanics vs. overhead stability. Address pull positioning before aggressive hypertrophy block.
