# Analysis: Equipment for Olympic Weightlifters (Foreman)

## Relevant to This Athlete's Profile

**BACK PAIN & BELT USE:**
- Use belt only above ~80% intensity (Clean: 64kg+, Squat: 94kg+)
- Belt strengthens core when training without it — beneficial for chronic back issues
- Recommend Olympic lifting belt (4-inch, buckle-style like Valeo), not thick powerlifting belts
- Avoid bulky equipment that compromises positioning

**WRIST WRAPS:**
- Use only if wrist pain prevents training; otherwise skip
- Choose thin, flexible wraps (not bulky) to maintain hand closure on bar catch
- Relevant: athlete's OHS weakness (50kg) may benefit from wrist stability work *after* addressing mobility/technique, not equipment reliance

**KNEE SLEEVES:**
- Use only if needed for pain/warmth; avoid relying on them for strength
- Thin sleeves preferred over bulky Rehbands
- **Key principle:** If legs aren't strong enough to stand up with cleans, sleeves mask weakness

**STRAPS:**
- Use ONLY on assistance pulls (snatch pulls, clean pulls, deadlifts)
- Never on actual snatches/cleans unless hands are severely damaged
- Can cause wrist injury in clean turnover if they compromise speed

## Core Principle
**Minimize equipment use.** Train unbraced/unsupported as long as possible to build genuine core and joint stability — especially important for this athlete with chronic back pain.
