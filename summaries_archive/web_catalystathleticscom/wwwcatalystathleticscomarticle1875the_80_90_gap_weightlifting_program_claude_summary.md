# Analysis: 80-90% Gap Program by Matt Foreman

## 1. **Programming Principles**
- **Structure:** Singles-based program for competition lifts (snatch, clean, jerk, variants)
- **Loading:** Athletes lift 80–90% of 1RM per workout; exact weight determined by daily readiness
- **Flexibility within boundaries:** Hit minimum 80% to maintain work quality; cap at 90% to prevent overtraining
- **Rep scheme:** Singles only (can do multiple singles at 90%, not sets of 5)
- **Duration:** Best for 6+ weeks; transition to exact peaking 4–5 weeks before competition
- **Accessory work:** Pulls and squats programmed separately (sets of 3–5)

## 2. **Relevance to This Athlete**

**Well-suited:**
- **Hypertrophy block (6 weeks):** Could use 80–90% for competition lifts, then add volume on pulls/squats
- **Night shift schedule:** Daily flexibility aligns with variable recovery/fatigue
- **Back pain:** Singles format safer than heavy sets; lower volume reduces spinal load
- **Jerk weakness:** Can pair 80–90% push jerks with lower-intensity split jerk practice

**Caution:**
- OHS at 50 kg (49% of squat) is severe limiter—needs dedicated mobility/technique work *outside* this framework
- Athlete lacks split jerk—must build this separately; program addresses competition lifts, not skill acquisition

## 3. **Key Limitation**
Doesn't address technique development or mobility—critical for this athlete's snatch and jerk issues.
