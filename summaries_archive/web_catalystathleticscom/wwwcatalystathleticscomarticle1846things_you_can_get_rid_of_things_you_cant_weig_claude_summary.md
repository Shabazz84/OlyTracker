# Analysis: Foreman's "Things You Can Get Rid Of & Things You Can't"

## 1. **Programming Principles**
- **Priority hierarchy for time-constrained athletes:**
  - Must keep: Full lifts (Snatch, C&J) + Squats (Front & Back)
  - Second tier: Pulling exercises (Snatch pulls, Clean pulls)
  - Drop first: Variety/novelty assistance (deficit lifts, YouTube trends)
  - Drop second: Competition-specific assistance (OHS, Push Press) if forced
- **Core insight:** 3-exercise minimum = Snatch + C&J + Squat (no fluff)
- Tailored for busy adults with 3–4 sessions/week, 60–90 min per session

## 3. **Exercise Recommendations**
- **Essential:** Snatch, C&J, Front Squat, Back Squat, Snatch/Clean Pulls
- **Secondary:** OHS, Push Press, block work, hang variations
- **Eliminate:** Deficit snatches, stone loading, low-bar BS, power variations (unless targeting specific weakness)

## 5. **Relevance to This Athlete**
✅ **Highly relevant:**
- **Back pain + night shift + intermediate level** = must prioritize essential lifts only
- **Low OHS (50 kg) = primary snatch limiter** → OHS belongs in secondary tier, but worth retaining as competition-specific assistance given weakness
- **Push jerk only** → eliminate split jerk complexity; focus C&J + squats + pulls
- **Recommendation:** Strict 3–4 session structure: Snatch + Front Squat, C&J + Back Squat, Pulls + OHS (prioritize minimal, high-ROI work)
