# Analysis: "Weightlifting Programming: Consistency or Variation?" by Greg Everett

## 1. Programming Principles
- **Consistency approach (primary recommendation)**: Same exercises for 2–4 weeks per mesocycle (3–5 weeks), varying only intensity/reps/sets week-to-week
- **Rationale**: Improves skill proficiency, reduces adaptation fatigue, enables faster intensity progression, minimizes soreness
- **Common structure**: Progress intensity weeks 1–3, back off week 4
- **Variation approach**: Different exercises each week within same category (e.g., different squat variation each Monday); only for technically proficient athletes or those stalled
- **Hybrid model**: Consistency in competition lifts/variations + variation in strength work (squats, pulls, accessories)
- **Maximal effort method** (Dr. Kyle Pierce): Work to rep max, then 1–2 back-off sets at 90–95% of that max; use 2–3 week loading blocks followed by deload

## 3. Exercise Recommendations
- Use pull variations (hangs, blocks, powers) alongside competition lifts
- Strength/accessory work: back squats, front squats, pin squats, pulls, pressing
- Progress from easier variations (hangs/blocks) → more demanding (floor work, complexes) across mesocycles

## 4. Recovery/Mobility Advice
- Consistency reduces soreness and improves "movement, speed and mobility day to day"
- Deload weeks: light pulls (70–80%), light competition lifts (60–70%), light squats (60–70%)

## 5. Relevant to This Athlete
- **Intermediate status**: Should use **consistency approach**—NOT high variation—to build snatch/jerk proficiency before hypertrophy block
- **Low OHS (50 kg)**: Prioritize consistent overhead/squat variations for 2–4 weeks to improve mobility/strength ceiling
- **Push jerk only**: Maintain jerk consistency week-to-week during current block before introducing split jerk technique
- **Chronic back pain + night shift**: Simpler, predictable programming (consistency model) likely better for recovery and managing fatigue from irregular sleep
