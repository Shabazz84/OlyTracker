# Analysis: Weightlifting Complexes Article (Greg Everett)

## 1. **Programming Principles**
- **Timing**: Complexes used in preparatory mesocycles (early training phases), dropped approaching competition
- **Progression**: Move from higher volume/reps → lower volume/higher specificity as cycle progresses
- **Purposes**: Error correction, volume accumulation, element emphasis, pre-fatigue, efficiency

## 2. **Technique Cues**
- Pull + lift complexes: Work balance, bar path, aggression, posture in pull
- Power jerk + jerk: Reinforce dip/drive balance, bar path, height of drive, timing
- Power snatch/clean + hang snatch/clean: Teach staying connected to bar, proper turnover height (avoid dropping under bar)

## 3. **Exercise Recommendations (Key for this athlete)**
**Highly relevant given chronic back pain + weak OHS (50 kg):**
- **Snatch + Overhead Squat** — Additional overhead stability/strength without extra exercises
- **Power Snatch + Hang Snatch** — Improves turnover mechanics, reduces crash
- **Pull + Snatch complex** — Addresses pull quality before attempting snatch

**For weak jerk (65 kg push jerk only):**
- **Power Jerk + Jerk complex** — Builds dip/drive mechanics (prerequisite for split jerk transition)

**For clean strength (80 kg):**
- **Clean + Front Squat + Jerk** — Addresses leg strength limiting factor; pre-fatigues legs

## 4. **Recovery/Mobility**
None addressed in text.

## 5. **Athlete-Specific Relevance**
✓ **OHS weakness (50 kg)**: Snatch + OHS complex ideal for hypertrophy block  
✓ **No split jerk**: Power jerk + jerk complex essential for dip/drive mechanics before split progression  
✓ **Chronic back pain**: Complexes reduce rep volume per lift (e.g., clean + front squat > multiple cleans)  
⚠ **Night shift**: Article doesn't address fatigue management—complexes are higher CNS demand
