# Analysis: Complexes for Snatch & Clean Pull Focus

## 1. Programming Principles
- **Complex structure**: Pull/deadlift variation + lift (snatch/clean) in sequence
- **Intensity**: 70–80% for technical work; 90%+ for heavy training
- **Rep schemes**: Variable (3+1, 1+3, 2+1, 1+2, 2+2) depending on goal
- **Purpose-driven**: Each complex targets specific weaknesses at specific training phases

## 2. Technique Cues
- **Pull + Lift**: Emphasizes pulling mechanics; fatigue encourages aggression
- **Deadlift + Lift**: For balance/shift issues; slower tempo allows position corrections
- **Halting Deadlift + Lift**: Strengthens second-pull entry; pause at mid-to-upper thigh (1–3 sec) to improve bar contact, balance, timing
- **Segment Pull (multi-pause)**: Pauses at 1" off floor, knee, mid-thigh; reinforces posture and balance
- **Power + (Hang) Lift**: Encourages speed/aggression in full lift by mimicking power movement tempo

## 3. Exercise Recommendations (Relevant to Athlete)
- **Halting Deadlift + Snatch**: Strong fit for weak OHS (50 kg). Strengthens second-pull position to improve bar positioning overhead.
- **Segment Pull + Snatch**: Addresses chronic back pain via controlled isometric work; lower-back strength/stamina builder.
- **Deadlift + Clean**: Simpler for technical refinement given intermediate level.

## 5. Athlete-Specific Relevance
- **Hypertrophy block**: Segment pulls provide high isometric volume (lower-back conditioning for back pain management).
- **OHS limiter**: Halting deadlift + snatch directly addresses pulling/positioning deficit limiting snatch.
- **No split jerk**: Clean/snatch complexes don't require jerk variations—focus stays on pulling mechanics.
