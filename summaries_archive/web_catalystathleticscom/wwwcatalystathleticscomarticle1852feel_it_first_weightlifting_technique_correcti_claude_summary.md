## Analysis: "Feel it First: Weightlifting Technique Corrections" by Greg Everett

**1. Programming Principles**
- Use abbreviated complexes (drill + lift segment) to embed motor patterns
- Sequence: feel → execute within same session before cognitive interference
- No specific sets/reps/intensity given—philosophy-focused

**2. Technique Cues**
- **Snatch hip extension issue:** Snatch deadlift from knee (3 reps) → simulated finish (legs vertical, hips slightly hyperextended, shoulders behind hips, bar sliding up thighs at slow tempo) → snatch from knee
- **General approach:** Identify what the body fails to do, isolate it in a drill, then perform the full lift immediately
- Emphasis: Feel the position/orientation before lifting to establish body awareness

**3. Exercise Recommendations**
- Snatch deadlift variations (from knee)
- Static positional holds (pre-lift body positioning)
- Abbreviated complexes tailored to individual limiters

**4. Recovery/Mobility**
- None provided

**5. Relevance to This Athlete**
- **High relevance for OHS/snatch limiter (50 kg):** The snatch deadlift + position drill approach directly addresses weak hip extension and bar path control—likely contributors to poor OHS position. Consider snatch deadlift from floor/knee with slow bar contact + overhead positioning work.
- **Back pain consideration:** Slow-tempo snatch deadlifts could serve as low-risk technical work before progressing to full snatches
- **Applicable across 6-week hypertrophy block:** Use complexes to reinforce technique while building capacity
