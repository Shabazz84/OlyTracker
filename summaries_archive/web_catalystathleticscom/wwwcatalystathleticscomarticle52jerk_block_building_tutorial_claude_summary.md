# https://www.catalystathletics.com/article/52/Jerk-Block-Building-Tutorial/

## Key Points
- Jerk block work enables multiple reps at heavier weights when full lowering is limited by elbow positioning, upper/lower body strength disparities, or poor eccentric technique.
- Rep work in the jerk is limited by how much weight an athlete can bring back down to the shoulders—a key constraint for this athlete.
- Blocks are supplemental, never replacement for all lowering phases of jerk training.

## Technique Cues
None provided in source material.

## Programming Principles
- Jerk blocks allow heavy dip/drive reps without demanding eccentric strength or split mechanics—suitable for hypertrophy block work.
- Can complement rack jerk work during strength phase to bypass split jerk limitation and build overhead capacity.

## Athlete Relevance
**High relevance to jerk development:**
- Push jerk only (65 kg) paired with weak OHS (50 kg) indicates overhead strength is the primary bottleneck.
- Jerk block work could efficiently build upper body/dip strength during the 6-week hypertrophy block without requiring split jerk capability.
- **Caution for chronic back pain:** Discuss block placement and eccentric loading with coach to ensure safety during night-shift recovery window.

**Recommendation:** Incorporate jerk blocks or rack jerks strategically in strength phase to address overhead weakness while respecting split jerk avoidance.
