## 2. Technique Cues: Snatch & Clean

**Primary Cue — First Pull (Floor to Knees):**
- **Accelerate speed from the floor, NOT pull slowly**
- Top lifters intentionally build speed as soon as the bar leaves the floor
- Apparent "slowness" in elite lifts = heavy absolute weight, not deliberate deceleration
- The speed *change* between first and second pull is relative, not absolute

**Common Error Pattern to Avoid:**
- Slow first pull causes secondary position breakdowns (rounded back, butt shooting up, lunging forward)
- Fix these with position-specific cues ("Keep your back tighter") rather than "slow down"

**Coaching Principle:**
- Don't tell beginners to "go slower"—teach proper positions first, then layer in speed
- As lifter develops, speed should increase throughout the entire pull

## 5. Relevance to This Athlete's Profile

**HIGHLY RELEVANT:**

| Factor | Application |
|--------|------------|
| **Chronic back pain** | Rounding/position breakdown in first pull is likely a contributor. Foreman's cue strategy ("keep back tighter" vs. "slow down") fits—focus on positional integrity, not deceleration. |
| **Clean 80 kg / Jerk 65 kg gap** | Suggests possible speed/power generation issue in the pull phase. Building accelerated first-pull speed could improve clean output. |
| **OHS 50 kg (snatch limiter)** | May indicate weak receiving position or speed issues in snatch. Speed off the floor is critical for consistent snatch technique. |
| **Intermediate status** | This athlete is past "absolute beginner"—ready to layer speed cues after positional foundations are solid. |

**Practical cue for this athlete:** Rather than "slow down," use "stay tall through your back" or "drive your knees forward" to correct position while preserving bar acceleration.
