# Everett Volume Squat Cycle: Merged Summary

## Key Points

- **10-week periodization:** Hypertrophy (Weeks 1–4, 6 reps), transition (Weeks 5–7, 5 reps), strength (Weeks 8–10, 2–4 reps)
- **Volume peak:** Weeks 3–4 (10×70% squat)
- **Intensity climb:** Weeks 5–10 (70% → 95%)
- **Squat frequency:** 4x/week (front or back squat, Mon–Thu); 3–5 min rest between sets
- **Transition weeks reduce soreness and allow CNS recovery**
- Progressive bodyweight gain target: 102.5 kg → 105 kg

## Technique Cues

**Snatch & Clean:**
- Segment pulls with 1-inch pauses (knee, hip, finish) for neuromuscular groove work
- Snatch/clean pulls 65–90% intensity (pulling strength without heavy load)
- Flat-foot pulls emphasized later in cycle
- Blocks work Week 8+ (mid-thigh starts)

**Jerk:**
- Jerk behind neck with 5-second hold in split position (core/stability emphasis)
- Power jerk preferred (accommodates back issues; no split jerk development in this block)

## Programming Principles

**Main Lifts:**
- Front squat & back squat (volume anchors)
- Stiff-legged deadlift + shrug (posterior chain, back strength)

**Accessory Structure (2–3 min rest; GPP-focused):**
- **Back health:** Weighted back extensions, GHD reverse crunch, reverse hyperextensions
- **Grip:** Gripper work 3x/week (5-sec holds) — addresses snatch grip limitation
- **Core:** Hanging leg raises, ab wheel, jack knives, planks
- **Neck machine:** Front/back/sides (postural support)
- **Box jumps** final weeks (speed/power maintenance)
- Avoid heavy deadlifts; use ring rows/pushups for scapular stability over plyometrics

**Deload:** Easy sessions when fatigued (Week 8 example: reduce volume if sick)

## Athlete Relevance

| Athlete Constraint | Program Solution |
|---|---|
| **Chronic back pain** | No split jerk; jerk behind neck; back extension emphasis; RDLs over heavy deadlifts; flexibility on rest periods (may need 3–5 min) |
| **OHS 50 kg (snatch limiter)** | 3x/week gripper work; snatch push press; snatch pulls at high intensity (65–90%) |
| **Push jerk only** | Power jerk/behind-neck work (no split jerk technical development; address post-block) |
| **Night shift (Wed–Sun)** | 10-week short cycle limits fatigue accumulation; consider light classic lift complexes 2x/week post-block for motor pattern maintenance without overload |
| **Intermediate level** | Segment pulls + position work bridge technical and strength focus before strength/technique block |

**Verdict:** This is an optimal **squat-focused hypertrophy block** preceding your 6-week hypertrophy goal, with accessory work strategically protecting your back and addressing grip weakness before snatch progression.
