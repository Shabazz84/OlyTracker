# Analysis: Warm-Up Protocol Article by Greg Everett

## Relevant to This Athlete's Profile

**1. Programming Principles**
- Universal warm-up structure: empty bar → first weight (30-40% max) for 2-5 sets → progressive smaller jumps
- Back squat example: Bar → 30% → 50% → 65% → 75% → 80%
- Snatch/C&J require smaller increments (down to 2kg)
- Competition approach: minimize sets to reduce fatigue; training can add more sets for practice/volume

**2. Technique Cues for Snatch**
- Empty bar drill sequence addressing weaknesses:
  - Snatch high-pull from below knee
  - Tall muscle snatch
  - Snatch press
  - Drop snatch
  - Overhead squat
  - Snatch from power position
- *Highly relevant*: OHS is primary limiter at 50kg—these drills target that directly

**3. Exercise Recommendations**
- Use complexes in warm-up (snatch pull + snatch) for practice + preparation
- Spend adequate time at first warm-up weight—rushing is common mistake
- Vary weights in training to build mental resilience if confidence is an issue

**4. Recovery/Mobility Advice**
- No explicit mobility guidance in this excerpt (focused on warm-up structure)

## Key Takeaway for This Athlete
Emphasize **OHS-specific warm-up drills** given 50kg limitation. Build mental consistency with snatch via varied warm-up weights on night shift schedule to combat fatigue/inconsistency.
