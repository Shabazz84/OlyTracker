# Analysis: "The 1 Kilo Rule" by Greg Everett

## 1. Programming Principles
- **PR Strategy**: Pursue 1 kg PRs instead of larger jumps; more frequent measurable progress beats infrequent big attempts
- **Warm-up jumps**: Use decreasing increments as you approach maximal weight (e.g., 4 kg, then 3 kg jumps rather than consistent 5 kg jumps)
- **Confidence threshold**: Only attempt weights you're 99%+ confident in; missing repeatedly is demoralizing
- **Plan ahead**: Map your exact jump sequence *before* starting; reduces overthinking between lifts
