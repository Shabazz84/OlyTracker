# Analysis: "Ask Greg: Hang Snatch Better Than from Floor"

## 1. Programming Principles
- **Progression method**: Top-down complexity (hang → floor)
- **3-position snatch complex**: Mid-thigh → knee → floor (1 rep each)
- **2-position snatch complex**: Mid-thigh → floor
- **Segment snatch protocol**: Halting snatch deadlift (3-sec pause mid-thigh) + snatch from that position; follow with normal snatch to avoid hitching
- **Tempo**: Controlled speed between pauses; avoid rushing
- **Pause holds**: 3 seconds at each position

## 2. Technique Cues for Snatch (Floor Position → Mid-Thigh)
- **Mid-thigh (initiation position)**: Shins vertical, shoulders slightly *in front* of bar (not over), back arched tight, head/eyes forward, weight *slightly behind midfoot* (NOT on heels)
- **1-inch/knee positions**: Shoulders directly above bar, weight slightly toward heels
- **Common error**: Weight too far back → forward shift compensation → jumping back → toe landing

## 3. Exercise Recommendations
- **Snatch segment deadlifts** (pauses: 1", knee, mid-thigh @ 3 sec each)
- **Halting snatch deadlifts** (pause mid-thigh)
- **Slow-pull snatch** (no pause, gradual entry to mid-thigh, then lift)
- **3/2-position snatch complexes** (progressively adding floor range)

## 4. Relevance to Athlete Profile
**High priority**: OHS is limiting snatch (50 kg). This drill focuses on pull mechanics, not receiving position. Consider pairing with dedicated OHS work.
**Concern**: Chronic back pain + controlled eccentric/pauses = manageable, but monitor fatigue on night shifts (Wed–Sun). Start light, perfect positions.
**Fit**: Intermediate athlete, hypertrophy block pending—these drills build positional awareness without extreme load.
