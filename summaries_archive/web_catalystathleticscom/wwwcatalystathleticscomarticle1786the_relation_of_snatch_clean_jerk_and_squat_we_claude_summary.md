# Analysis: Everett on Lift Ratios

## Relevant to This Athlete's Profile

**1. Programming Principle – Diagnostic Framework**
- Use lift ratios as diagnostic tools, not rigid targets
- **This athlete's gaps:**
  - Clean 80 kg / BS 118 kg = 68% (target: 74–80%) → **BELOW range**
  - Snatch 50 kg / Clean 80 kg = 62.5% (target: 78–83%) → **SIGNIFICANTLY BELOW range**

**2. Reasons for Athlete's Snatch Deficit (from Everett)**
Snatch falls below range if:
- ✓ Poor snatch bottom position mobility (OHS 50 kg confirms this is **primary limiter**)
- ✓ Less explosive than strong (likely given BS/Clean ratio)
- Possibly incomplete elbow extension (related to push jerk-only)

**3. Programming Strategy (Directly Applicable)**
Everett states: *"Are they really strong squatters who aren't snatching and clean & jerking as much relatively? Then emphasizing technique, speed and maybe pulling strength is a more appropriate strategy."*

→ **This fits perfectly.** Before the planned 6-week hypertrophy block, prioritize:
- Snatch-specific mobility (OHS work critical)
- Snatch technique refinement
- Speed/explosiveness work

**4. Clean Ratio Note**
- 68% is borderline; improving clean technique/speed could unlock squat strength better
