# Analysis: "When to Move on, and When to Punch Your Missed Lift"

## 1. Programming Principles
- **Mistake vs. Failure distinction**: Technical errors warrant retries; physical failures warrant stopping
- **Program integrity**: Added attempts disrupt intended volume/intensity; frequent misses signal program is too ambitious
- **Exercise intent matters**: Strength work (heavy singles/doubles) → stop on miss; technical work → reduce weight for proper execution; volume phases → reduce weight to finish prescribed reps
- **Remainder sets strategy**: For technical + strength hybrids (e.g., 5×3 snatches), convert missed sets to doubles + add a set to maintain volume at same weight

## 3. Exercise Recommendations

- **Remainder sets adjustment**: Example given—5×3 snatches missing rep 3 of set 3 → finish as 5×2 + 1 extra set at same weight

## 5. Relevance to This Athlete
**Highly relevant:**
- **OHS limiter (50 kg)**: Technical work takes priority over load; reduce weight for proper execution rather than grinding failed lifts
- **Chronic back pain + night shift**: Frequent missed lifts = program too ambitious; must communicate with coach before disrupting training cycle
- **6-week hypertrophy block**: Stay disciplined on volume; don't accumulate extra reps chasing misses
- **Push jerk only**: If split jerk introduction planned, technical priority means proper execution > load; use remainder sets strategy to maintain volume
