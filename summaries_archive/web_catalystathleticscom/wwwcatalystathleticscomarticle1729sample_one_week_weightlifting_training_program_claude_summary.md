# Analysis: Foreman's 1993 Training Week Sample

## 1. Programming Principles
- **Frequency**: 6 days/week (Mon, Tue, Wed, Thu, Sat) with structured exercise sequencing
- **Intensity**: Daily max effort work (singles, doubles) after volume work
- **Structure**: Olympic lift → pulling variation → squat → accessory (consistent pattern)
- **Volume**: High—snatch/clean worked 3–4x weekly; pulls 3x weekly
- **Periodization**: Rigid, repeatable weekly structure; peaked into competitions
- **Notes**: "Program was pretty rigid, not a lot of variety" but successful (US National Team Championship 2000)

## 2. Technique Cues
- None explicitly provided; coach references technique analysis as separate from programming

## 3. Exercise Recommendations
- **Pulls**: Clean pulls, snatch pulls (3×3 standard)
- **Squats**: Back squat, front squat, pause squat (stop squat), rack jerk
- **Accessory**: Seated good mornings (back health emphasis)
- **Jerk work**: Rack jerks on dedicated day (Tuesday)

## 4. Recovery/Mobility Advice
- Not addressed in this article

## 5. Relevance to This Athlete's Profile
⚠️ **Limited direct relevance**:
- Foreman's 1993 example uses elite-level volume (snatch 125kg PR; athlete's 80kg clean)
- **High frequency (6 days)** conflicts with night-shift fatigue (Wed–Sun worker)
- **Back squat emphasis** without accommodation for chronic back pain (no pause/tempo work mentioned)
- **No split jerk training** despite it being standard—matches athlete's current deficit
- **OHS limiter**: Program doesn't isolate OHS; good mornings don't directly address overhead position strength

**Recommendation**: This template works for full-time, pain-free lifters. Requires major modification for night shift + chronic back issues.
