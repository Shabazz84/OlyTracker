# Analysis: Kyphosis & Shoulder Mobility (Robb Wolf)

## Relevance to This Athlete
**HIGH.** This athlete has chronic back pain + weak OHS (50 kg — significant limiter) + night shift work (postural stress). Kyphosis/shoulder mobility directly addresses root causes.

---

## 1. **Programming Principles**
- **Mobility work frequency:** 3–5 sets × 10 reps mixed into *every* strength session (not optional)
- **Progression:** Start with easy hand widths (dowel/PVC); narrow grip OHS as mobility improves
- **Discontinuation markers:** OHS 5–10 reps bodyweight, L-sit pull-ups (10), kipped pull-ups (30+) = mobility sufficient

---

## 2. **Technique Cues**

**Shoulder Dislocates (dowel):**
- Start hand-width where bar passes hips to back with firm grip
- **KEY:** Shrug traps HARD forward & backward
- Slow, patient movement—not explosive

**Overhead Squat (mobility focus):**
- Narrow grip (narrowest allowing upright torso + dowel over ear & heel)
- Hip-to-shoulder-width stance
- Neutral/slightly forward chin → allows full shoulder activation
- Full depth; discomfort in mid-back/spinal erectors is *expected* and indicates progress
- **Every rep should be uncomfortable**

**Glide Kip (mobility mobilization):**
- Dead hang → push bar away + raise toes forward (hollow position) → pull forward + drive legs back
- **Cue:** "Push away, raise the toes! Pull under the bar!"
- Forward position is hardest for mobility-limited athletes—ease in

---

## 3. **Exercise Recommendations**
- **3–5 × 10 daily circuit:**
  - Shoulder dislocates (dowel)
  - OHS (light load)
  - Glide kips
- **Avoid heavy deadlifts/cleans** until thoracic stability improves (Greg Everett comment: "do not overload it")
- Upper back strength work concurrent with mobility (scapular retractors/lower traps)

---

## 4. **Recovery/Mobility**
- Kyphosis → rotated shoulder girdle → impedes overhead work & predisposes to rotator cuff issues
- Night shift + keyboard work exacerbate postural failure
- **Mobility work is therapeutic**, not supplemental—addresses pain source
- Real-world case: 60-year-old gained ~1" height after correcting kyphosis

---

## 5. **Athlete-Specific Application**
| Issue | Intervention |
|-------|--------------|
| Weak OHS (50 kg) | Daily 3–5×10 OHS mobility work + upper back strength |
| Chronic back pain | Kyphosis correction (thoracic mobility) likely root cause |
| Night shift (postural stress) | Prioritize daily mobility circuit before strength work |
| Push jerk only (no split) | Strong shoulder girdle stability first; OHS foundation critical |

**Action:** Implement 3–5 min shoulder dislocate + OHS + glide kip circuit *before every session* for 4–6 weeks, then reassess overhead mechanics.
