# Weightlifting Analysis: On The Minute Training by Greg Everett

## 1. Programming Principles
- **On-The-Minute (OTM) structure**: Sets performed every 60 seconds (allows consistent pacing, mental focus, high volume in short time)
- **20/20 Program**: 5 singles × 3 increasing weights (15 sets OTM), then max 5 singles off-clock; increase all weights once all 20 completed successfully
- **Variations**:
  - Progressive weight increases each session regardless of heavy single outcome
  - Reduce set volume approaching competition (e.g., 5-4-3 pattern)
  - Single weight × 10-15 sets, increasing week-to-week
  - Moderate weight (70%) + small increments (2-3kg) per set
  - 5-6 OTM sets as warm-up before heavy singles
  - Drop sets post-heavy single
- **Clean & Jerk modification**: 1-minute rest (vs. strict OTM) closer to competition due to metabolic demand
- **Doubles/triples OTM**: Early cycle only for volume/conditioning

## 3. Exercise Recommendations
**Most relevant to this athlete:**
- OTM snatch work directly addresses technical consistency and OHS limiter (50kg)
- Clean/jerk separation feasible given 15kg disparity; consider OTM clean singles + jerk singles separately early in 6-week block
- OTM work builds competition-speed conditioning (useful night-shift recovery window)

## 4. Recovery/Mobility Advice
- OTM drop sets post-heavy single minimizes pre-fatigue (good for chronic back pain management)

## 5. Athlete-Specific Relevance
⚠️ **Caution**: High-frequency OTM work may aggravate chronic back pain; prioritize conservative starting weights and perfect early reps. Split jerk limitation suggests clean strength adequate—focus OTM work on snatch/OHS consistency.
