# Analysis: "Can't Receive the Snatch Low with Heavier Weights" by Greg Everett

## 1. Programming Principles
- **Confidence-building progression**: Build OHS and snatch balance strength *above* current snatch max before returning to heavy snatches
- **Exercise sequencing**: Warm-up with OHS + snatch balances before snatches
- **Volume/intensity approach**: Focus on snatch variants (high-hang, tall, high-block) to emphasize pull mechanics
- **Holding positions**: 2–3 second holds in receiving position (bottom squat) to normalize it mentally and physically

## 2. Technique Cues (Directly Relevant to Athlete)
**Snatch receiving issue (athlete's primary limiter—OHS 50 kg):**
- Problem is *confidence under load*, not flexibility
- Cues: aggressive pull with elbows, minimize leg drive in dip, focus on speed punching under the bar
- Snatch variants: high-hang, tall, high-block snatches to build pull-under aggression
- If unintentionally power snatching, squat it down after catch

## 3. Exercise Recommendations
- **Overhead squats** (warm-up emphasis)
- **Snatch balances** (slow dip, minimal push, deep catch, 2–3 sec hold)
- **Snatch pulls** & **snatch pull + snatch complexes**
- Eliminate power snatches; only full snatches
- High-hang/tall/high-block snatch variants

## 4. Recovery/Mobility
- Mobility not the limiter (assuming OHS is accessible)
- If OHS mobility is restricted: Sotts press work needed

## 5. Athlete-Specific Relevance
⚠️ **Critical**: Athlete's OHS is 50 kg (limiting snatch reception). This article directly addresses the root issue. Implement snatch balance + OHS emphasis before heavy snatch work. Back pain requires load management in receiving positions.
