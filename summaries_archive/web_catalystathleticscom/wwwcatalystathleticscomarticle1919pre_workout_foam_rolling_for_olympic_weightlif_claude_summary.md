# https://www.catalystathletics.com/article/1919/Pre-Workout-Foam-Rolling-for-Olympic-Weightlifting/

**RELEVANT TO ATHLETE PROFILE:**

**Recovery/Mobility Advice:**
- **Pre-workout foam rolling protocol** (2 minutes total, light 10-15 passes per area)
  - Use dense black foam roller only—no PVC/balls/aggressive tools pre-workout
  - Sequence: thoracic spine → underarm → glutes → hamstrings/adductors → quads
  - Should be painless; save aggressive work for post-training/rest days
  - Perform before dynamic ROM and barbell warm-up

**SPECIFIC TO THIS ATHLETE:**
- **Chronic back pain**: T-spine mobility work directly relevant. Thoracic extension (arms overhead position) addresses overhead squat/jerk limitations
- **Night shift worker**: Light pre-workout rolling helps activate/prepare despite fatigue
- **OHS limiter (50 kg)**: T-spine and shoulder mobility prep essential before technique work

**NOT INCLUDED:**
- No programming principles, sets/reps, periodization
- No snatch/clean/jerk technique cues
- No exercise recommendations beyond foam rolling
