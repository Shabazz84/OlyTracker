# Weightlifting Coaching Analysis: Teaching Olympic Lifts in Group Settings

## Relevance to Athlete Profile
**Moderate relevance.** This article addresses *group program structure* and *teaching methodology* for mixed-skill cohorts, not individualized programming for this athlete's specific needs (chronic back pain, night shift, OHS limiter, push jerk-only status).

---

## Key Extracts by Category

### 1. **Programming Principles**
- **Long-term perspective required** — avoid arbitrary daily programming; plan 3+ months with sufficient detail
- **Program to priority clients** — those with consistent attendance deserve more coaching attention
- **Scaled variations by skill level** — use exercise progressions (e.g., full snatch → 1-arm DB snatch → jumping DB squat) within same class
- **Minimize Olympic lifts in conditioning** — most clients lack technical proficiency; use DB/sandbag variants instead
- **Dedicated skill work time** — allocate structured time to lifts separate from metabolic work

### 2. **Technique Cues**
None provided. Article focuses on *teaching systems*, not technical execution details.

### 3. **Exercise Recommendations**
- **Avoid medicine ball cleans** ("hopelessly lame")
- **Prefer dumbbell/sandbag variations** for conditioning (less technical demand, less interference with barbell technique)
- **Use Burgener warmup** for foundational exposure
- **Snatch drop and hang squat clean** as accessory drills
