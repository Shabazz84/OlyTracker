# Analysis: Weightlifting Technique Drills & Training Lifts (Greg Everett)

## 1. **Programming Principles**
- **Three-tier framework:**
  - *Learning drills*: Very light/no weight, high reps (PVC pipe early stage only)
  - *Technique drills*: Light weight, single technical focus, partial movements or complexes
  - *Training exercises*: Progressive loading for strength/speed/power; weight increases as proficiency improves
- **Loading rule**: Never exceed technical ability; improper execution under heavy loads reinforces bad patterns
- **Progression**: Teaching → intermediate (technique-specific) → advanced (training exercises dominant with minimal technical work)

## 2. **Technique Cues**
- Example given: Lifter opening hips early in snatch → use halting snatch deadlift (hip stop, shoulders over bar) + snatch complex to teach proper position
- Once strength adapts to poor pattern, increase load on partial (halting deadlift) to build positional strength without the full lift

## 3. **Exercise Recommendations**
- Halting snatch deadlifift + snatch complex (for technical correction)
- Snatch balance variations
- Pressing variations
- Classic lifts, squats, pulls, push presses as training exercises

## 4. **Recovery/Mobility**
- PVC pipe mentioned as stretching tool only (not training)
