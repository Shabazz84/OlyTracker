# Weightlifting Analysis: "5 Ways to Get A Better Finish in the Snatch"

## 1. **Programming Principles**
- **Hang & Block Snatches**: Reduced range improves rate of force development (RFD) and timing; hang position better for positioning/balance; blocks better for RFD with static start
- **Pull + Snatch Complex**: Snatch pull immediately before snatch to reinforce proper extension mechanics and aggression
- **Snatch Pulls**: Teach balance, timing, aggression; keep weight moderate to maintain complete extension (don't exceed threshold where extension breaks down); hold 1-count at top to reinforce full extension
- **Jumping**: Box jumps, back squat jumps, broad jumps for explosiveness

## 2. **Technique Cues (Snatch)**
- Finish = final upward extension (second pull); requires **both speed AND complete extension**
- Common timing errors: second pull initiated too early
- Common position errors: initiation too far back on heels, shoulders too far back
- **Bar proximity**: as close as possible without touching until hip contact
- Focus on leg drive and hip extension quality

## 3. **Exercise Recommendations**
- Hang snatches (knee-height or power position)
- Block snatches (static start)
- Snatch pulls (lighter weights for form)
- Snatch deadlifts (if going heavier)
- Jumping variations

## 4. **Relevant to This Athlete**
- **OHS 50kg limiter + back pain**: Emphasis on hang/block snatches improves positioning without loading bottom position; pulls strengthen extension safely
- **Push jerk only**: No split jerk noted—clean footwork/timing cues still apply
- **Night shift**: Shorter, higher-quality session structure (complexes, pulls, jumps are efficient)
- **6-week hypo block**: Jumping + complexes build RFD and power endurance without excessive volume
