# Analysis: Greg Everett Q&A on Learning Olympic Lifts

## Relevant to This Athlete:

**1. Programming & Progression**
- Start with power variations, progress to squat variations as mobility improves
- Add overhead squats, behind-neck presses, push presses, front squats to current program
- Can practice power snatch/clean immediately; introduce squat variations once comfortable in receiving positions

**2. Technique Cues**
- Power snatch/clean = same movement as full lifts, only difference is bar reception height
- Receiving position confidence builds with regular squat strength + smart training
- Focus on developing comfort in lower receiving positions

**3. Exercise Recommendations**
- Overhead squats, behind-neck presses, push presses, front squats (mobility developers)
- Foam rolling daily (or 2x daily)
- Stretching when warm, post-foam rolling

**4. Mobility/Recovery**
- **Flexibility = primary limiter** for Olympic lifts at any age
- Stretch hip extensors, adductors, ankles, thoracic spine, shoulder girdle
- See manual therapist if range-of-motion issues from past injuries (relevant: chronic back pain)
- Consistency > intensity in mobility work
- Sleep & nutrition prioritized over supplements

**5. Athlete-Specific Notes**
- Your OHS weakness (50 kg) aligns with "flexibility is biggest limiting factor"
- Back pain + night shift → prioritize recovery quality (sleep, mobility frequency)
- Push jerk only → squat variations must precede split jerk progression
- Intermediate status + coach access recommended (mentioned repeatedly in comments)
