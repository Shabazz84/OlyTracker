# Merged Weightlifting Coaching Summary

## Key Points

- **Programming structure**: Daily inclusion of snatch + clean + jerk + squats + pulls; heavy training days feature 6+ exercises plus jumps
- **Jerk emphasis**: Explicit shift toward increased jerk volume to address the athlete's weak jerk relative to clean
- **Snatch pull focus**: Prioritized with grip variation; foundational for speed and receiving position timing
- **Straps usage**: Reserved for pulls, blocks, and variations; classic snatch trained without straps to condition grip
- **Blocks-based work**: Snatch on blocks targets leg drive deficiency; use moderate weights with powerful extension cue
- **Training flexibility**: Program adjustable in-session based on athlete response; recovery/adaptation emphasis

## Technique Cues

**Snatch Pull:**
- Open grip (no straps/wraps) to strengthen wrist and fingers
- Emphasize hip power and leg drive through full extension
- Jump with margin, not into minimal space (injury prevention)

**Snatch on Blocks:**
- Narrower stance acceptable; adjust for comfortable receiving position
- Cue powerful leg drive extension with moderate loading
- Addresses athletes who don't extend effectively through legs

**Classic Snatch:**
- Train without straps; straps only for pulls/blocks/variations
- Control bar position at receipt
- Triple pause work (below knee, above knee, pull finish) addresses early back extension and forward bar drift

**Jerk:**
- Manage body position; avoid rocking/wobbling before drive
- Maintain vertical torso throughout

**Finger Taping Protocol:**
- Use light bindings (closed wrap method) for high-volume finger stress
- Light tension only (no numbness); allows full flexion
- Additional stability tape if needed

## Programming Principles

- Heavy days: 6+ exercises + jumps
- Daily snatch + clean + jerk + squats + pulls structure
- Novel/remedial exercises trained lighter for technique focus
- Session-specific days: separate snatch-focused and clean/jerk-focused sessions
- Higher-rep jump work as finisher/deload accessory
- Band-resisted paused squats for knee stability and adductor control
- Recovery adjustable per athlete response

## Athlete Relevance

**Directly Applicable:**

- **Chronic back pain**: Snatch on blocks reduces full-range load while building leg drive—ideal intermediate intensity for 6-week hypertrophy block
- **OHS limiter (50 kg)**: Wrist/finger conditioning (no-strap work) and upper-body prep implied; addresses mobility constraints
- **Weak jerk (65 kg vs. 80 kg clean)**: Explicit increased jerk volume matches stated coaching priority
- **6-week hypertrophy block**: Current technical emphasis + accessory structure sustainable before intensity phase

**Missing Context:**
Night-shift recovery (Wed–Sun) not addressed; training camp flexibility may require additional adaptation.

**Recommendation**: Prioritize snatch blocks work + increased jerk accessories (push/power jerk variations) first 2–3 weeks; add targeted OHS mobility work alongside hypertrophy block to address receiving position limitation.
