# https://torokhtiy.com/blogs/guides/elbow-pain-from-lifting-weights

This text is a general medical/injury guide about elbow pain (epicondylitis, tendinopathy, etc.) and does not contain specific programming principles, technique cues, or recovery advice tailored to the athlete's profile (hypertrophy block, back pain, night shift work, or Olympic lifting progression). It focuses on treating existing elbow injuries rather than coaching an intermediate lifter.
