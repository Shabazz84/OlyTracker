# Analysis: 2-Day Olympic Weightlifting Program

## 1. Programming Principles
- **Frequency:** 2x/week split (Snatch Day / Clean & Jerk Day)
- **Structure:** Lift-specific focus with complementary strength work
- **Intensity ranges:** 70–105% of 1RM depending on exercise
- **Rep schemes:** 2–6 reps per set; 3–5 sets per exercise
- **Progression:** Small incremental weight increases; emphasis on logging sessions
- **Recovery:** Rest days between sessions critical for muscle recovery and injury prevention

## 2. Technique Cues
- **Snatch:** Emphasize bar elevation and pulling motion; focus on "pull under the bar" explosive phase
- **Clean & Jerk:** Develop "real functional power, speed and explosiveness"; practice as complex
- **General:** Dynamic warm-up targeting shoulders, hips, ankles (Snatch Day); wrists, shoulders, hip flexors (C&J Day)

## 3. Exercise Recommendations
**Snatch Day:** Snatch High Pulls (4×6), Hang Snatch (4×3 @ 70%), Snatch Pulls (4×4 @ 90%), Front Squat (5×3 @ 90% C&J)

**Clean & Jerk Day:** Muscle Squat Clean + Thruster (3×6), Clean & Jerk (4×2+2 @ 80%), Clean Pulls (3×3 @ 100%), Back Squat (4×3 up to 105%)

## 4. Recovery/Mobility Advice
- 10-min dynamic warm-up before each session
- 10-min cooldown with static stretches post-session
- Prioritize rest days between training

## 5. Relevant to This Athlete
⚠️ **CRITICAL GAPS:**
- **No split jerk work** (athlete only push jerks) — program assumes split jerk capability
- **OHS only 50 kg** (major limiter) — no dedicated overhead stability/mobility programming
- **Chronic back pain** — program lacks spine-specific modifications or deload guidance
- **Night shift Wed–Sun** — no accommodation for sleep disruption/recovery timing
- **6-week hypertrophy block** goal — this template is strength/technique-focused, not hypertrophy-oriented

**Recommendation:** Requires customization for overhead weakness, back health, and periodization alignment.
