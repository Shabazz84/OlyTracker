# Merged Summary: Beginner OLY Program → Intermediate Athlete Application

## Key Points

**Article Content (Beginner Focus):**
- 3 days/week, non-consecutive structure; 4–6 week blocks without change
- Load zones: 60% (recovery), 70–80% (technique, 3×4–5), 80–90% (moderate volume), 90%+ (minimal)
- Volume split: 25% snatch drills, 25% C&J, 25% squats, 10–12% each pull variation
- Strength sets: 3–5 × 3–5 reps at RPE 8
- Recovery: Rest days include massage/sauna; mobility/flexibility emphasized for injury prevention

**Critical Gaps for This Athlete:**
- No hypertrophy block design (6-week stated goal)
- No night-shift accommodation (Wed–Sun schedule)
- No chronic back pain modifications
- No split jerk progression pathway (athlete limited to push jerk)
- Beginner template underutilizes intermediate strength base (BS 118 kg, Clean 80 kg)

---

## Technique Cues

**Snatch Variants:**
- Power snatch (tall catch, speed/amplitude development)
- Hang snatch (back muscle load, power position work)
- Deficit snatch (balance, pull quality, leg strength, turnover control)

**Clean Variants:**
- Power clean, clean from blocks (acceleration/explosiveness)
- Clean complexes (pull + clean, clean + squat)

**Jerk:**
- Push/power jerk (current athlete method—slight foot shift to sides)
- Split jerk (backward-forward lunge stance—**not yet trained**)
- Behind-neck jerk (COG awareness, dip-drive phase)

**Squat Variations (OHS Limiter Priority—50 kg):**
- Pause squats (3-sec pause; spine neutrality, core control)
- Front squats (core demand, vertical posture carryover to OHS)
- Narrow-stance squats (ROM improvement in 3–4 weeks; mobility benefit)
- Split squats (unilateral work; supports back health)

---

## Programming Principles

**Applicable Structure:**
- 3 days/week, non-consecutive—fits night-shift recovery needs
- Alternating heavy/medium/light day sequencing
- 4–6 week blocks; progress when form stabilizes

**Required Customization:**
1. **Hypertrophy block (6 weeks):** Article omits; recommend 8–12 reps, RPE 6–7, compound emphasis (front squat, pause squat, C&J variations)
2. **Back-safe exercise selection:** Prioritize pause squats, front squats, split squats; avoid heavy good mornings without modification
3. **Intensity scaling:** Beginner zones too conservative for intermediate C&J (80 kg clean, 65 kg push jerk); adjust load zones upward
4. **Split jerk introduction:** Embed in technique block post-hypertrophy; requires dedicated cue work
5. **Night-shift accommodation:** Consolidate sessions Mon/Tue–Thu, prioritize recovery protocols (massage, sauna, mobility)
