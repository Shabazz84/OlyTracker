# Analysis: 8-Week Power Clean Program

## 1. Programming Principles
- **Structure**: 3 sessions/week, 8-week cycle (Weeks 1-4 intensification, Weeks 5-8 power/strength)
- **Intensity Progression**: 50-65% loads Week 1 → 2-3% weekly increases → 75-85% 1RM Weeks 5-8
- **Rep Scheme**: 4-6 reps early → 2-3 reps later phases
- **Recovery Block**: Week 4 = deload (10-15% volume/intensity cut)
- **Deload/Taper**: Weeks 7-8 before maxout testing

## 2. Technique Cues (Power Clean focus)
- Emphasize **bar path** and **pulling power** (high pulls)
- Focus on **timing & catching mechanics** (hang variations above/below knee)
- Reinforces **form in all positions**—technique priority over load
- Use **variations** (blocks, deficit, hangs) to target different phases

## 3. Exercise Recommendations
**Strength/Support**: Front Squat, Back Squat, Squats Jumps, Deficit RDLs, Single-leg RDLs, Good Mornings, Pull-ups, Lat Rows, Core work  
**Mobility**: 10-15 min daily mobility + stretching (shoulders, hips, wrists, back)

## 4. Recovery & Mobility
- Dedicate time to **mobility exercises** to prevent overtraining
- Planned deload week (Week 4)
- Proper recovery strategies emphasized
- Video analysis/coaching feedback for adjustments
