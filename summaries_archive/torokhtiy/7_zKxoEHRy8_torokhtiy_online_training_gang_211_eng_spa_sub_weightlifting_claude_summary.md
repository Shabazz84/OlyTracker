# Weightlifting Coaching Analysis: Week 2 Programming

## 1. **Programming Principles**
- **3 main workouts/week** + accessory sessions between main sessions
- **Intensity zones**: 80% (push jerk from rack), 90% (snatch pulls), working toward higher % zones
- **Rep scheme**: 2 reps per movement in complexes; slow eccentric/fast concentric pattern
- **Structure**: Main lift → accessory → technique work with low weight

## 2. **Technique Cues**

**Snatch Pull (from hang/floor):**
- Bar path close to body throughout
- Generate power from legs + back
- Emphasis on pull-under position before receiving

**Snatch Split (Snatch Balance):**
- Light loading for position work
- Focus: overhead stability (fixation) + depth
- Maintain upright torso in pull

**Push Jerk (80%):**
- Slow dip, explosive drive
- Bar from rack, elbows high
- Always returns to rack (not dropped)

**Clean Complexes (Clean + Squat + Jerk):**
- 2 reps per movement
- Functional loading (not maximal)

## 3. **Exercise Recommendations**
- Back-rack bends (knees out, hips back, deep, straight spine)
- Snatch pulls: 90% snatch max
- Jerk push press: 80%
- Hyperextension (3sec hold at top, slow down)
- Clean complexes
- Snatch balance + OHS work
- Snatch splits from blocks
- Jerk pulls from hang: 90% jerk max

## 4. **Recovery/Mobility**
- Hyperextension included (posterior chain support for chronic back)
- Ample technique/low-intensity work days between main sessions

## 5. **Relevance to This Athlete**
✅ **Well-suited:** 
- OHS work directly addresses 50kg snatch limiter
- Back extension helps manage chronic pain
- Split jerk absent—aligns with push jerk only (no split jerk introduced yet)
- Light technique days manageable for night shift schedule

⚠️ **Considerations:**
- Back-loaded (squat, jerk from rack, bends) may aggravate chronic pain—monitor form
- No explicit mobility for thoracic/hip mobility despite back pain history
- Recommend regression if back pain increases
