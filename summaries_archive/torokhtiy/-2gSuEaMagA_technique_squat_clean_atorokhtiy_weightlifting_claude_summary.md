# Technique: SQUAT CLEAN  / A.TOROKHTIY (weightlifting)

# Weightlifting Analysis: Clean Technique Breakdown

## Programming Principles
- **Progression structure**: Break skill into phases, teach backwards (finish position first)
- **Volume approach**: 2-3 sets of 10 reps per drill
- **Sequence**: Pull to power position → pull + extension + catch → full clean with squat
- **Progression**: Mirror work → add light load → build full movement

## Technique Cues for Clean (Most Relevant to Athlete)

**Start Position:**
- Knees spread wide (lateral direction)
- Hips back, shoulders over bar
- Shoulders cover knees (not knees past shoulders)
- Back extended, not rounded
- Feet and knees aligned (both turned out)

**Pull Phases:**
1. **Extended pull (to power)**: Shoulder over knee, knees out, hips back, drive vertical
2. **Receiving**: Elbows HIGH and forward, NOT tight to body; "pull elbows up, bar stays close"
3. **Turnover**: Elbows rotate under as bar reaches shoulders (not neck)
4. **Squat catch**: Hips back, knees out, shoulders stacked

**Key checkpoint**: Elbow-knee-hip alignment at setup validates entire position

## Exercise Recommendations
- **Progression drills**: Receiving position → pull + extension + catch → full clean
- **Load strategy**: Start with mirror work unloaded, then add light plates
- **Mirror self-assessment**: Eliminates need for coach feedback

## Critical for This Athlete's Profile

⚠️ **CHRONIC BACK PAIN FLAG**: Extended back positioning emphasized throughout; verify tolerability. May need:
- Modified back extension cues during pull
- Pull position work to build tolerance
- Consider addressing in recovery/mobility block

✓ **Snatch OHS limiter (50 kg)**: Clean technique foundation solid; transition to snatch needs aggressive arm turn + mobility.

✓ **No split jerk**: Stay with push jerk; this clean framework doesn't address jerk directly.
