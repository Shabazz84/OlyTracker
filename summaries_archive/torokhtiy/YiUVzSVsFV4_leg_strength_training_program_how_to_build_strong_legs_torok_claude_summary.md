# LEG STRENGTH Training Program / How to build strong legs / TOROKHTIY / Session #3

**Not directly relevant to this athlete's needs.**

This is a general leg strength program (12 sessions, 4 weeks) for building strong legs, not Olympic weightlifting-specific programming.

**Potentially useful elements:**

1. **Warm-up exercises** (relevant for chronic back pain):
   - Dark walk (mobility for squat)
   - Good morning + quad (lower back/hamstring prep) — *caution needed with chronic back pain*
   - Core rotation with band (core stability)

2. **Snatch technique cue** (addresses OHS limiter):
   - "Muscle tall snatch + overhead squat": elbows high/out, bar close, catch upright (as if against wall — prevents forward lean)
   - Light weight emphasis ✓

3. **Squat variations**:
   - Narrow vs. wide stance back squats — useful for addressing strength imbalances, but **narrow stance may aggravate chronic back pain**

4. **Plyometrics**:
   - Box jumps for power development (relevant to jerk drive) — *good for night shift recovery if managed carefully*

**Not suitable for this athlete:**
- Barbell curl raises (not hypertrophy-relevant for OLY goals)
- Generic 4-week structure (athlete needs 6-week hypertrophy block + periodization plan)
- No accommodation for chronic back pain or night shift schedule

**Better approach:** Sport-specific OLY program prioritizing OHS/snatch mobility and jerk mechanics.
