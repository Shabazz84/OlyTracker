# Analysis: "Tarakhan Project" - 8-Week Training Program (Russian)

## 1. PROGRAMMING PRINCIPLES
- **Duration:** 8 weeks
- **Main structure:** 3x/week (Mon/Wed/Fri) + 2 optional sessions (Tue/Thu) for higher frequency
- **Weeks 1–2 (General Prep Block):** 
  - Intensity capped at 70% (do NOT exceed)
  - Emphasis on accessory work and body preparation
  - Focus: build posterior chain, stabilize technique
  - Rep schemes: 8–10 reps, 3–4 sets
  - Slow, controlled tempos

## 2. TECHNIQUE CUES

**Snatch:**
- Snatch pull + squat: keep bar close to body, smooth movement, 2-sec pause in hole
- Snatch grip deadlift (from hang): use straps; 1 pull + 2 snatch high-pulls per set
- Snatch high-pull (no toe rise initially): learn without plantar flexion first; progress once technical

**Clean:**
- Clean from hang: use straps; full foot, knees out, slow eccentric
- Power clean + push press: full squat descent, 2-sec overhead hold

**Jerk/Push Jerk:**
- Push jerk emphasis: full leg drive, dip deep, explosive drive leg, 2-sec overhead hold
- Jerk dip: knee drive lateral, full leg engagement, shoulder covers bar (side view projection)

## 3. EXERCISE RECOMMENDATIONS

**Main Work (Each Week):**
1. Hyperextensions: incline, slow tempo, 8–10 reps, 3–4 sets, 0–20 kg load
2. Snatch-variant complexes (pulls + high-pulls + full movements)
3. Clean-variant complexes (hang cleans, front squat + push jerk)
4. Back squat: target 105–110% of best by end of block; explosive concentric, controlled eccentric, knees out
5. Jerk dip/push jerk emphasis

**Accessory (Optional Sessions Tue/Thu):**
- Hyperextensions
- Snatch grip deadlift
- Power snatch (light, high reps, slow tempo)
- Thruster

## 4. RELEVANCE TO THIS ATHLETE

**✓ WELL-SUITED:**
- **Chronic back pain** → Hyperextension work (posterior chain strengthening) is prioritized; slow tempos reduce pain risk
- **Push jerk only (no split)** → Program emphasizes jerk dip mechanics and leg drive; supports transition
- **OHS limiter (50 kg)** → Overhead stability work (2-sec holds, jerk drills) directly addresses weakness
- **Night shift (Wed–Sun)** → Can use Mon/Tue for 3-session microcycle if scheduling allows

**⚠ CONSIDERATIONS:**
- **BS 118 kg vs. Clean 80 kg gap** → Program's squat emphasis (back squat + front squat variants) will bridge this
- **Week 1–2 cap at 70%** → Low intensity ideal for back pain management and technique consolidation before hypertrophy
- **No sport-specific periodization stated** → Confirm alignment with stated "6-week hypertrophy → technique/strength" goal
