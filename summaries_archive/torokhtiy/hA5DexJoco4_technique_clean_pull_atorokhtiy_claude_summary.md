# Technique: CLEAN PULL / A.TOROKHTIY

**This is weightlifting content in Russian.** Transcript of a coaching session on the **clean pull (тяга толчковая)** and an 8-week training project announcement.

---

## RELEVANT EXTRACTIONS FOR THIS ATHLETE:

### 1. **Programming Principles**
- **8-week training block** structure: 3 main sessions (Mon/Wed/Fri) + 2 optional accessory sessions (Tue/Thu)
- Clean pull performed at **90–100%+ intensity** (heavier than snatch pull) for base strength building
- Snatch pull uses lighter loads to develop speed; clean pull develops raw strength

### 2. **Technique Cues: Clean Pull**
- **Grip width**: Approximately bar at lower third of thigh when standing
- **Start position**: Slightly higher than snatch pull (less deep squat position)
- **Knees**: Spread outward; arms can rest lightly on knees
- **Key emphasis**: Tight lower back ("натягиваем поясницу")
- **Pull finish**: NO rise onto toes (unlike snatch pull); shorter amplitude
- **Bar break**: Aggressive "rip" from floor—not smooth acceleration; bar breaks near upper thigh (first third of thigh), not at hip
- **Center of gravity**: Maintain over midfoot or slightly toward heel; avoid forward imbalance
- **Arm mechanics**: Keep relaxed; wrist rotation happens *automatically* post-pull; do NOT forcibly flex wrists (causes forearm tension and constrains bar path)

### 3. **Exercise Recommendations**
Clean pull variations recommended:
- Clean pull from floor
- Clean pull from blocks (elevated start)
- Clean pull from hang
- Deadlift (pausing or from platform)

### 4. **Recovery/Mobility Advice**
- Practice start position work in front of a mirror to develop consistency
- Teaching cue: Knees shoulder-width, knees spread, lower back tight, chest forward, knees ≈ shoulder height in start position

### 5. **Specifically Relevant to This Athlete**
- ⚠️ **Back pain + pull emphasis**: This coach emphasizes tight lower back engagement and maintaining neutral spine position—critical for your chronic back pain. The "short amplitude" clean pull may reduce lumbar load vs. snatch pull.
- ✓ **OHS limiter (50 kg)**: Clean pull won't directly fix OHS, but base strength building could support it.
- ✓ **Hypertrophy block goal (6 weeks)**: The 8-week block described aligns with this; clean/snatch pulls at 90–100%+ are strength/hypertrophy-appropriate.
- ⚠️ **Night shift (Wed–Sun)**: Program uses Mon/Wed/Fri structure; verify compatibility with your sleep/recovery.
