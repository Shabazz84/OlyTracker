# Block 2: Pre-Evidence Outline vs. Cited Rebuild — 2026-08-12

Per-claim comparison of `PROGRAM_OUTLINE`'s eight `week:9`–`week:16` rows
(`docs/src/app.jsx:417-424`) against `2026-08-12-block2.md`, which was written
from `evidence/2026-08-12/` after the outline rows already existed.

The eight rows were written before the corpus could be queried by decision —
one line per week, no citations, no way to have been anything but a guess at
the time. That makes them a **pre-registered prediction**, and this document
scores it: the same test that, run on Block 1, found the overhead-squat dosing
in the live program to be the reverse of what the sources say.

**Neither document is modified by this one.** `PROGRAM_OUTLINE` weeks 9–16 are
not live program data — the app is currently in Block 1 — so nothing here
blocks or changes anything shipping. This is a scoring exercise.

**Handles are pack-local to `evidence/2026-08-12/`**, the same pack
`2026-08-12-block2.md` was built from, generated the same day. No regeneration
happened between that document and this one, so no handle-drift risk of the
kind found between the 2026-08-11 and 2026-08-12 packs applies here.

## Verdicts used

- **SUPPORTED** — the outline's claim is what the cited evidence rebuild
  actually prescribes.
- **CONTRADICTED** — the cited evidence says something materially different.
- **CONTESTED** — the corpus disagrees with itself on this dimension; no
  single verdict is available from evidence alone.
- **ABSENT-FROM-OUTLINE** — the evidence rebuild adds something the outline
  row never mentioned.
- **UNFOUNDED** — asserted by the outline, cited by nothing. Not
  contradicted — simply invented, usually because it is a number no corpus
  passage could plausibly contain (an individual athlete's future 1RM, for
  instance).

- **Contradicted or missing: 41%** (9/22 — 8 CONTRADICTED + 1 ABSENT-FROM-OUTLINE)
- **Unfounded: 23%** (5/22)

**Reading this against Block 1's numbers.** Block 1's diff, on the full
30-question pass, settled at 34% supported / 61% contradicted-or-missing / 5%
unfounded. Block 2's outline scores similarly on the supported share (36% vs
34%) but the shape of the misses is different: Block 1's errors were mostly
**ABSENT-FROM-LIVE** (the live program under-used what the corpus knew — 11 of
47 rows). Block 2's errors split about evenly between **CONTRADICTED** (8) and
**UNFOUNDED** (5), with only one ABSENT-FROM-OUTLINE row. The pre-evidence
outline for Block 2 didn't so much *miss* what the corpus would say — it
guessed specific numbers and mechanisms (a flat +2.5 kg/week rule, an ATW
baseline, a CNS-conservation framing, four future 1RM figures) that no corpus
passage was ever going to be able to confirm or deny, because they describe
things individual to this athlete or programming folklore this corpus simply
doesn't carry. That is a different failure mode from Block 1's, not a smaller
one.

**Where the outline got the direction right.** All four bands the outline
predicted for the accumulation weeks (9, 11, 12, 14) landed inside the cited
zone-dosing bands, floor-lift timing (week 9) was correct, the 5×3 volume
figure for week 11 was close to the cited 3×4–5 dosing, and Front Squat's
inclusion in the week-16 test list was correct. The general four-phase shape
(build volume → raise intensity → deload → test) is also directionally right,
though the corpus disputes the 8-week block length itself (row 2) rather than
confirming it outright.

**Where it went wrong specifically.** Every CONTRADICTED row clusters around
three recognizable habits: (a) treating single-week percentage bands as more
precise than the cited zones actually are (rows 5, 12 — off by only a few
points, but outside the band as written), (b) inventing a progression or
tapering **mechanism** not in the corpus — flat weekly kg jumps, daily maxing
starting on a specific week, per-set accessory trimming (rows 6, 13, 14) — and
(c) reusing Block 1's deload shape and the standalone-OHS test without
checking whether Block 1's own diff had already flagged both as unsupported
(rows 18, 19; row 19 in particular repeats the exact overhead-squat error
Block 1's diff called "the finding that matters most").

## Recommended follow-ups

Not actions taken — `PROGRAM_OUTLINE` weeks 9–16 are outline data, not the
live program, and nothing here is wired into the app.

1. **Do not carry a standalone OHS test into week 16** (row 19) — it repeats
   Block 1's dosing error inside the test protocol itself.
2. **Drop the flat weekly kg increment and the per-set accessory trim** (rows
   6, 14) — neither has a mechanism in this corpus; the zone-dosing table and
   the time-capped accessory rule already in `2026-08-12-block2.md` should
   replace them if this outline is ever rebuilt.
3. **Retire "ATW baseline" as a tracked metric for this block** (row 11) —
   `CLAUDE.md`'s Torokhtiy correlation claim has now failed retrieval twice
   (Block 1's `master_synthesis.md` review and this pack's q35) and should be
   re-checked against source before it appears in the app again.
4. **Do not predict absolute future kilos** (rows 17, 23) — the rebuild's own
   position is that percentages survive the week-16 test and kilos don't;
   any outline that names a future single is guessing at something the corpus
   structurally cannot supply.
5. **If the block length itself is revisited, treat 8 weeks as a choice, not
   a finding** (row 2) — a second cited source argues for 12–16 weeks, and the
   rebuild declines it for reasons specific to this athlete's PR frequency,
   not because the corpus agrees.
