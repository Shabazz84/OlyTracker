# Block 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Block 3 (weeks 17–24), adapted from Catalyst's General Cycle, into the OlyTracker app as per-exercise cards, with week plans, tests at weeks 20 and 23, and a 3-session week 17.

**Architecture:** All Block 3 data (week plans + per-exercise entries) lives in `docs/src/program.js`, a plain classic script with no JSX. A Node `vm` test can load it and check the spec's invariants directly. `app.jsx` gains only routing: one exercise lookup that covers both blocks, completion days per week, and catalog entries. Loads are computed from `TRAINING_MAX` when the page loads, so the post-test TM update moves the whole block.

**Tech Stack:** React 18 UMD + JSX via esbuild (`npm run build`), classic-script globals, `node --test`, the `olytracker-ui-verify` skill.

**Spec:** `docs/superpowers/specs/2026-10-17-block3-design.md`. Every number comes from `program_sources/catalyst_general_cycle.txt` (local, gitignored).

## Global Constraints

- **Never copy source text into the repo** (code, comments, commit messages, tests). Prescriptions are re-expressed as entries; provenance comments name the source *day number* (e.g. `// src d16`) or an Edit-Ledger number (`// Edit 6`), never quoted wording.
- At most **6 exercise cards** per session.
- Heavy squats: `back_squat` d1, `front_squat` d3, `pause_back_squat` d4. **None in d2.**
- Every `l1` with a load **starts with the kg number** (generateWeights takes the first two numbers). Never use the words `light`, `BW`, `band`, `cable` in an `l1`.
- `l2` = `l1` (the Block 2 convention).
- Version string → `PROGRAM v3.17.0 · <commit date>` in `app.jsx`; CLAUDE.md "Current version" line updated to match.
- Never `git add -A`. Never point a browser at the real `docs/` (prod Supabase creds); stage with `stage.cjs`.

## Source-day map (used by Tasks 2–3)

Cycle week `n = appWeek − 17` (1–6). Source day numbers: Mon `7n+1`, Tue `7n+2`, Wed `7n+3`, Thu `7n+4`, Sat `7n+6`.

| App day | From source | Cards |
|---|---|---|
| d1 Mon | Tue `7n+2` | snatch, clean_and_jerk, back_squat, trunk_static_strength (Edit 6) |
| d2 Tue | Thu `7n+4` | snatch, clean_and_jerk, push_press (Edit 6: 3×3, `${tm('pushPress',0.60)}–${tm('pushPress',0.70)} kg — add weight weekly only while it stays fast`) |
| d3 Thu | n odd: positional lift + snatch_pull from Mon `7n+1`; n even: positional lift + clean_pull from Wed `7n+3`. Jerk variant from Mon `7n+1`; snatch_balance from Wed `7n+3`; front_squat from Thu `7n+4`; one ab card (Edit 7) | 6 |
| d4 Sat | Sat `7n+6` | snatch, clean_and_jerk, pause_back_squat, stiff_legged_deadlift; n=3,6 → test cards (Task 3) |

Week 17: d1 (label **Wed**) ← src d2, d3 ← src d4, d4 ← src d6. Week 24: d1 ← d50, d2 ← d51, d3 ← d53, d4 ← d55 (src d52 dropped).

Load expression rules:
- `X% of snatch` → `tm('snatch',X)`
- C&J and jerk variants → `tm('cleanAndJerk',X)`
- `% (of clean)`, positional/power cleans, clean pulls → `tm('clean',X)` (Edit 11)
- squats → `tm('backSquat'|'frontSquat',X)`
- Snatch balance → `tm('snatchBalance',…)`. Where the source says "max for day; Y% of that × r × s", use `l1` = `${tm('snatchBalance',Y)}–${tm('snatchBalance',1.0)} kg — max for the day, then Y% of it`, with `sets` = 1 + s. In the weeks where it is max only, use `sets:'3–5', reps:'1'`.
- Pause back squat N-RM: no %. Use a judgment band — 3RM `0.70–0.80`, 2RM `0.75–0.85` of backSquat — with the rep target in `l1`.
- Source loads given "by feel" (press, row, snatch push press, good morning, SLDL) get a conservative starting kg range with a `// [JUDGMENT] load — <basis>` comment, the Block 2 precedent. SLDL basis: Block 2 RDL 75–85 kg.
- Week 24 d4 "heavy single" lifts: `${tm(lift,0.80)}–${tm(lift,0.95)} kg — heaviest clean single for today`, `// [JUDGMENT] load`.
- Thursday jerk-variant `l1` ends with `· empty-bar split jerks any day as warm-up` (spec: the drill is a note, not a card).
- Thursday front_squat `l1` ends with `— ceiling, not target: stop at the first grinding rep` (Edit 3).
- Every jerk inside a C&J is a split jerk. The source's "jerk" sets map to `split_jerk_from_rack` (Edit 5).
