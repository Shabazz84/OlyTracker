# Block 1 Sustainability Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Block 1 weeks 4–8 sustainable at 4 days/week with 3–4 movements per session, and make the app's "current week" reflect what was actually trained instead of drifting ahead on the calendar.

**Architecture:** All changes live in `docs/src/app.jsx` (source of truth). Three independent edits: (1) trim the exercise arrays that drive the logging UI, which cascades automatically into the 4-day school-term view since it's derived from the same data; (2) trim the parallel read-only program-view data for weeks 4–7; (3) replace the calendar-based `currentWeek` calculation with one derived from actual logged sessions. Rebuild `docs/app.js` via esbuild after each JSX change.

**Tech Stack:** React (JSX, no build-time type checking), esbuild bundler, no test framework in this repo — verification is build success + grep assertions on the compiled output + a manual visual pass in the browser.

## Global Constraints

- App source of truth is `docs/src/app.jsx`. Never hand-edit `docs/app.js` — it is generated by `npm run build` (esbuild).
- Version bump required on every commit touching the app: update the `PROGRAM v<X.Y.Z> · <date>` string in `docs/src/app.jsx` before committing. Current: `v3.3.2 · 2026-06-11`. This change bumps to `v3.4.0 · 2026-07-12` (minor: new behavior, not just a fix).
- No test framework exists in this repo — each task's verification step is a build + grep check on `docs/app.js`, plus a final manual browser check.
- Don't touch weeks 1–3 of `PROGRAM_B1` — they already worked at 5 days/week and are left as historical record.
- Don't build new UI for the "anytime bucket" concept (Plank/Dead Bug/Pallof/Ab Wheel/Face Pull) — it's a rationale for why those exercises were dropped from the weekly default, not a new feature to implement.

  const inferred = inferDaysFromLogs(week, DAYS_SCHOOL);
  return COMPLETION_DAY_IDS.every(id => {
    const status = inferred[id]?.status;
    return status === "done" || status === "partial";
  });
}

function computeCurrentWeek() {
  for (let w = 1; w <= 28; w++) {
    if (!isWeekComplete(w)) return w;
  }
  return 28;
}
